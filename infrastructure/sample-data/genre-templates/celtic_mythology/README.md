# 켈트 전승 · 브란의 항해

[한국어 중역 전문](source/original.md)은 쿠노 마이어1895년판 《브란의 항해》1–66절 전체다. 영어 면2–34쪽의 산문·시·결말을 포함한다. 별개 몽간 이야기와 편집자 논문을 묶은 책 전체를 번역했다고 주장하지 않는다.

[세계관 카드](source/tradition-cards.json) 25장은 이 작품의 인물·장소·물건·사건과 서술상의 규칙만 다룬다. [표시 템플릿](source/template.json)은 전문과 카드를 그대로 동기화한다. 종전12장의 아일랜드·웨일스 다작품 요약을 한 작품 자료로 교체하면서 다른 대상을 뜻하는 기존키는 재사용하지 않았다. 세계관 ID와 genre_id·order는 보존한다.

마이어(1919년 사망)의 오래된 영어 번역에서 새로 중역했으며 현대 한국어 번역을 복제하지 않았다. [영인 출처](https://archive.org/details/voyageofbransono01scuoft). 저본의 이문·불확실 구절과 실제 노래 수의 차이는 전문의 판본 안내에 명시한다. 단일 필사본의 완전 보존이나 해석의 확실성을 뜻하지 않는다.

본문 앵커66개, 절65의 마지막 시, 절66의 결말을 확인한다. 카드 근거는 해당 절의 정확한 문장이다. 상위 생성기와 단위 테스트로 템플릿·카드·런타임 일치를 확인한다. 현대 사용자 세계관의 이관·덮어쓰기는 수행하지 않는다.

## 본문 파생 항목 보강

창조주의 탄생과 정결 예언, 죄 없는 세계와 타락·구원의 노래, 몽간의 예언상 변신, 노래하는 돌, 서쪽 섬들, 줄지 않는 음식, 오검 문자 기록을 보강했다. 예언과 실제 항해 사건, 시적 장소와 확정 지도를 구분하고 훼손 구절이나 상충하는 수치를 임의로 메우지 않는다.

이번 보강은 기존 18개 키와 해당 대상·템플릿 섹션 ID·순서를 유지하고, 새 대상 7개만 뒤에 추가한다. 모든 카드에는 실제 본문 앵커 안의 정확한 인용을 붙였으며 본문은 카드당 3,000 UTF-16 코드 단위 이하다. 주요 인물·사건·장소·물건·규칙을 포괄하되 모든 문장을 별도 카드로 만들지는 않는다.

이번 단계는 tradition-cards.json·template.json·이 README만 변경한다. original.md의 전문과 template의 content_markdown, 최상위 id·genre_id·order는 보존한다. 런타임 JSON·전역 README·기존 사용자 세계관은 변경하지 않는다. 따라서 런타임 재생성 전에는 전체 리소스 일치 검사가 불일치를 표시할 수 있으며, 런타임 반영은 통합 단계에서 별도로 수행한다.
