# 마야 신화 — 포폴 부의 첫 창조

키체 마야 포폴 부 제1부 제1장의 창조 전승을 중심으로 정리한다. 다른 마야 지역의 모든 신명을 통합하지 않는다. 원전 내용의 한국어 요약이며 전체 번역·창작 소설 설정집이 아니다. 전승별 차이와 불확실성을 구분한다.

- `source/template.json`: 출처·유형·범위를 가진 설정 카드 11장.
- `source/original.md`: 같은 카드의 한국어 읽기용 문서. 파일명은 기존 경로 호환용이며 원전 전문을 뜻하지 않는다.
- 서비스 적재본: `backend/content-service/src/main/resources/genre-templates.json`.
- 사건은 `event/history`, 나머지는 의미에 맞는 유형과 `basic` 영역으로 적재한다.
- 기존 장르의 기본 템플릿·확장 설정·도입 예시 구분은 이 전승 자료에 적용하지 않는다.
- 자유롭게 편집할 수 있으나 수정한 창작 설정과 원전 요약을 구분하고 출처를 유지한다.
- 현재 운영자 소유 세계관으로만 적재된다. 일반 사용자용 선택·복제 UI는 별도 구현이 필요하다.
