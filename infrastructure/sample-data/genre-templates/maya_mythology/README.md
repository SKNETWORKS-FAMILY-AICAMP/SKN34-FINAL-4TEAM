# 마야 전승: 키체의 포폴 부

키체의 《포폴 부》 브라쇠르 1861년 프랑스어판의 머리말·45장·세 왕가 계보·맺음말을 범위로 삼는다. 창세·영웅담과 민족 이동·왕권의 역사를 다루며 저본의 결락을 복원한 것으로 가정하지 않는다.

[카드](source/tradition-cards.json) 68장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·장절을 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.
