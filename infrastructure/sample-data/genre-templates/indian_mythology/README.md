# 인도 신화: 《바가바드기타》 전문

텔랑 1882년판 《바가바드기타》 1–18장과 《리그베다》 1.1·1.32·10.90·10.129의 일부를 다룬다. 텔랑판은 700절 계통이며 701절 계통과 다르다. 특정 해석을 힌두 전통 전체로 일반화하지 않는다.

텔랑 인쇄면 77쪽 및 두 온라인 전사본은 8.1의 아디다이바 질문을 빠뜨린다. 기존 작업에서는 이 한 질문을 애니 베전트 1922년판과 대조해 보충했다. 텔랑 원문에 있던 문장으로 취급하지 않는다.

[카드](source/tradition-cards.json) 73장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. [보충 출전](source/supplementary.md)의 기존 원어 발췌와 링크는 유지한다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·장절을 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.
