# 설정 카테고리 분류

원문의 항목을 각각 독립된 설정 문서로 유지하면서 category_id를 내용에 맞게 분류했습니다. 여러 인물이나 장소를 설명하는 원문 항목을 임의로 요약·재작성하지 않습니다. 본문과 문서·버전·체크포인트 ID는 유지하며 이번 미적용 샘플의 분류만 변경했습니다.

| 카테고리 | 기준 |
|---|---|
| 인물 | 주인공, 가족, 동료, 적대자 등 인물 소개 |
| 장소 | 주요 지역, 지리, 장소 |
| 규칙 | 세계의 작동 원리, 능력의 사용법·제약, 회귀·전투 규칙 |
| 상태 | 저주, 신체 조건, 영지의 초기 상태 |
| 지식 | 숨겨진 진실, 공개할 비밀, 미래·공략·현대 지식 |
| 관계 | 관계와 감정의 흐름, 계약 결혼 조건 |
| 광물 | 기존 카테고리 유지. 독립된 광물 항목이 없는 샘플에 강제로 배정하지 않음 |
| 기타 | 기존 카테고리가 없는 역사·사건·조직·사회 배경·전개안·도입 예시, 전체 원문·기본 예시 등의 복합 자료 |

세계관 설명이라고 모두 규칙으로 넣지 않습니다. 예를 들어 무공 작동 원리는 규칙, 주요 지역은 장소, 전생 사건 연표는 기타입니다. 전체 원문은 보관 자료이며 실제 항목별 설정과 중복됩니다.

각 장르의 category-mapping.json은 모든 문서의 이름·카테고리·자료 역할·ID·원문 경로를 제공합니다.
