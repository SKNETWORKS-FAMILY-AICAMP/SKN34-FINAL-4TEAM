# 북유럽 신화: 서사에서 세계관으로

## 읽는 순서

1. [전승·작품 서사](source/original.md)를 먼저 읽습니다. 사건과 관계가 이어지는 자체 한국어 재서술이며 새 주인공의 소설 도입부나 카드의 나열이 아닙니다.
2. [카드 정본](source/tradition-cards.json)은 완성 원고에서 인물·장소·신물·집단·규칙·사건을 추출한 별도 세계관 정리입니다. 각 카드의 `narrative_refs`에는 원고 절 ID와 정확한 근거 문단을 남겼습니다.
3. [소스 템플릿](source/template.json)의 `content_markdown`은 원고 전문과 같고 `setting_bible.sections`는 카드의 제목·본문·유형·근거를 반영합니다.

## 범위와 출전

시 에다와 중세 아이슬란드의 스노리 산문 에다에 남은 전승을 중심으로 정리합니다. 기독교 시대 편찬과 번역의 해석을 고대 북유럽 전체의 단일 교리로 취급하지 않습니다.

각 서사 절의 출전에서 공개 원문 판본을 확인할 수 있습니다. 현대 번역문을 옮기지 않았으며, 서로 다른 문헌·작품의 서술과 화자의 해석을 단일한 정본이나 확정 연대표로 합치지 않습니다. 원고의 연결 문장은 편집이며 원전에 없는 인물과 사건은 추가하지 않습니다.

## 유지와 검증

기존 30개 카드의 키·제목·유형·순서와 안정된 ID를 유지합니다. 본문은 카드마다 필요한 정보만 원고에서 따로 요약합니다. 원고를 수정하면 정확한 근거 문단과 카드 내용을 재검토하고 템플릿도 함께 갱신해야 합니다. 원고의 존재·앵커·근거 문자열과 미러 일치는 자동 검증할 수 있지만 의미의 충실성은 편집 검토가 필요합니다.

최종 리소스는 상위 폴더의 `build_traditions.py`로 재생성합니다. 소스 원고와 근거 정보는 편집 자료이며, 기존 WorldStudio에 원고를 새로 노출하거나 저장된 사용자 세계관을 덮어쓰는 런타임 변경은 포함하지 않습니다.
