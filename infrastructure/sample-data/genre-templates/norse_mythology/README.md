# 북유럽 신화: 《볼루스파》 한 작품의 완역

## 읽는 순서

1. [한국어 전문](source/original.md): 《시 에다》에 실린 독립시 《볼루스파》(무녀의 예언) 한 작품을 처음부터 끝까지 읽는다.
2. [카드 정본](source/tradition-cards.json): 그 시에서 뽑은 인물·집단·장소·사물·사건·규칙 53개를 읽는다. 카드 요약은 전문을 대신하지 않는다.
3. [소스 템플릿](source/template.json): `content_markdown`은 전문과 같고 `setting_bible.sections`는 카드의 제목·본문·유형·근거를 그대로 반영한다.

## 저본과 완역 범위

- 작자 미상의 고대 노르드어 시를 헨리 애덤스 벨로스의 1923년 영어판을 통해 한국어로 중역했다. 고대 노르드어 직접 번역이나 《시 에다》 전체의 완역이라고 주장하지 않는다.
- [프로젝트 구텐베르크의 벨로스판](https://www.gutenberg.org/files/73533/73533-h/73533-h.htm#ch1.1) 제1–66연을 사용했다. [동일 번역 대조본](https://sacred-texts.com/neu/poe/poe03.htm)도 확인했다.
- 난쟁이 명단 제9–16연, 반복 후렴 제44·49·58연, 마지막 제65·66연까지 포함한다. 제30·36·55·61·63·65연에 있는 저본의 점선은 ‘……’로 보존하고 추측으로 메우지 않았다.
- 시 본문은 66연·275행이다. 이 행 수는 벨로스가 표시한 빈자리 8행을 포함하고, 제목·연 번호·편집 안내·웹페이지 쪽수·서론·학술 각주는 포함하지 않는다.
- 연의 순서와 제51연의 ‘북쪽’·‘헬의 백성’ 등은 벨로스판의 편집 선택을 따른다. 다른 에다 시나 《산문 에다》를 본문에 섞지 않았다.
- 중세 원작과 1939년 사망한 벨로스의 1923년 번역은 한국과 미국에서 보호기간이 만료된 저작물이다. 현대 한국어 번역은 사용하지 않고 이번 자료를 위해 새로 옮겼다. 저본 확인일·HTML 지문·권리 정보는 원고 앞에 기록했다.

## 카드의 범위

기존 카드 가운데 같은 대상은 키를 유지했다. 시의 실제 내용에 맞추어 제목·요약·근거를 바꾸었으며, 다른 작품에서만 얻은 티르의 손 상실, 묠니르·궁니르의 제작, 이둔의 사과, 글레이프니르의 재료, 룬 획득 의식 등은 제거했다. ‘헬’은 이 시에서 길·문·백성의 영역으로 추출하여 장소 카드 `hel-realm`을 새로 두었고, 여신 카드 `hel`과 같은 대상으로 가장하지 않았다.

별칭으로만 나오는 프레이야·프레이르·토르 등의 식별은 시 자체의 직명과 구분하고 같은 벨로스판 각주를 밝혀 두었다. 무녀의 회고와 예언을 확정된 전체 신화 연대표로 만들지 않는다.

## 유지와 검증

- `stanza-001`–`stanza-066`의 순서·유일성, 저본의 연별 행 수, 난쟁이 이름 목록과 반복 후렴, 결락 표시를 확인한다.
- 카드 53개는 모두 실제 연을 가리키는 `narrative_refs`를 가진다. 근거 문자열은 해당 연 안에 정확히 존재해야 한다.
- 전문과 `template.json.content_markdown`, 카드와 `setting_bible.sections`의 미러가 일치해야 한다.
- 기존 `build_traditions.py`의 `validate_narrative`로 이 장르만 읽기 검증할 수 있다. 이 변경은 네 편집 파일에 한정하며 런타임 JSON·다른 장르·저장된 사용자 세계관은 갱신하지 않는다.
- 전체 빌드·통합 테스트·커밋·푸시는 이 자료 교체의 범위에 포함하지 않는다.

## 전문 파생 카드 확장

카드 53개로 확장하여 기존 33개 키를 모두 보존했다. 새 대상에는 새 키를 부여하고, 기존 템플릿 식별자와 순서를 유지한 채 새 섹션을 뒤에 추가했다.

시간의 이름, 난쟁이 명단 전체, 이더볼과 놀이판, 발키리, 미미르·시귄·프리그, 북쪽 전당과 슬리드, 철의 숲과 수탉들의 징조, 가름의 반복 후렴, 후반의 거처·이름 없는 군주까지 반영했다. 예언과 회고, 별칭의 주석상 식별, 저본의 결락을 구분한다.

본문 66개 앵커를 주요 인물·집단·장소·사물·능력·사건·질문의 카드 근거에 모두 연결했다. 이름 명단은 집단 카드에 묶어 보존하므로 각 이름에 독립된 전기를 만들어 붙이지 않는다. 앵커 연결의 완전성은 의미의 자동 증명이 아니며, 원문의 문장과 카드의 진술을 별도로 대조했다.

카드 본문은 UTF-16 기준 3,000자 이하이며, 모든 근거는 해당 앵커의 실제 문자열이다. 이번 카드 확장에서 original.md와 템플릿의 전문 content_markdown은 변경하지 않았다. 런타임 JSON과 다른 장르의 생성·반영은 상위 통합 작업에서 따로 수행한다.
