# 북유럽 신화: 《볼루스파》와 에다 전승 설정집

벨로스 1923년판 「볼루스파」 1–66연과 《산문 에다》 「길피의 속임수」·「시어법」, 《시 에다》 「그림니르의 말」·「하바말」·「트림의 노래」·「히미르의 노래」의 일부를 다룬다. 작품별 서술과 이설을 구분하며 아홉 세계의 단일 목록을 임의로 확정하지 않는다.

아홉 세계에 관한 기존 시는 그 연에서 아홉 이름을 열거하지 않는다. 산문의 지명과 헬의 권한만으로 정해진 아홉 지명 목록을 만들지 않는다. 이그드라실의 뿌리 배치와 토르의 뱀 낚시 등은 작품별 차이를 남긴다. 문학 속 의례 장면을 역사적 관습 전체로 일반화하지 않는다.

[카드](source/tradition-cards.json) 80장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. [보충 출전](source/supplementary.md)의 기존 원어 발췌와 링크는 유지한다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·장절을 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.
