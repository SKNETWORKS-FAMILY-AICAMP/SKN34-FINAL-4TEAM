# 북유럽 신화: 《볼루스파》 완역과 에다 전승 설정집

## 읽는 순서와 범위

1. [한국어 전문](source/original.md): 《시 에다》의 독립시 《볼루스파》 66연을 읽는다. 원고는 이 한 작품만 포함한다.
2. [카드 정본](source/tradition-cards.json): 기존 《볼루스파》 카드 53개와 다른 에다 작품을 확인한 추가 카드 26개를 읽는다. 작품별 서술과 이설을 구분하며 신화 전체를 망라한 목록은 아니다.
3. [추가 원어 근거](source/supplementary.md): 추가 카드마다 고대 노르드어 원전의 직접 URL, 장·연, 확인한 짧은 발췌를 기록한다. 카드의 한국어는 해당 대목을 새로 요약한 문장이다.
4. [소스 템플릿](source/template.json): `content_markdown`은 기존 《볼루스파》 전문과 같고 `setting_bible.sections`는 카드의 제목·본문·유형·근거를 순서대로 반영한다.

## 전문의 저본

- 작자 미상의 고대 노르드어 시를 헨리 애덤스 벨로스의 1923년 영어판을 통해 한국어로 중역했다. 고대 노르드어 직접 번역이나 《시 에다》 전체의 완역이 아니다.
- [프로젝트 구텐베르크의 벨로스판](https://www.gutenberg.org/files/73533/73533-h/73533-h.htm#ch1.1) 제1–66연을 사용했고 [동일 번역 대조본](https://sacred-texts.com/neu/poe/poe03.htm)도 확인했다. 난쟁이 명단 제9–16연, 반복 후렴 제44·49·58연, 마지막 제65·66연과 제30·36·55·61·63·65연의 저본 점선을 보존했다.
- 시 본문은 66연·275행이다. 행 수는 벨로스가 표시한 빈자리 8행을 포함하고 제목·연 번호·편집 안내·웹페이지 쪽수·서론·학술 각주는 포함하지 않는다. 연의 순서와 제51연의 ‘북쪽’·‘헬의 백성’ 등은 벨로스판의 편집 선택을 따른다.
- 중세 원작과 1939년 사망한 벨로스의 1923년 번역은 한국과 미국에서 보호기간이 만료된 저작물이다. 현대 한국어 번역은 사용하지 않았다. 저본 확인일·HTML 지문·권리 정보는 원고 앞에 기록했다.

## 추가 카드의 출전과 한계

- 《산문 에다》의 [「길피의 속임수」](https://www.heimskringla.no/wiki/Gylfaginning) 5–9·13–15·23–27·34·38·41–42·48–49·51·53장과 [「시어법」](https://www.heimskringla.no/wiki/Sk%C3%A1ldskaparm%C3%A1l) 43장을 확인했다. 아스가르드·바니르와 거인 혈통, 창세, 운명과 서약, 묠니르·궁니르, 종말과 재생 등을 보충한다.
- 《시 에다》의 [「그림니르의 말」](https://www.heimskringla.no/wiki/Gr%C3%ADmnism%C3%A1l) 31연, [「하바말」](https://www.heimskringla.no/wiki/H%C3%A1vam%C3%A1l) 138–139·144–145연, [「트림의 노래」](https://www.heimskringla.no/wiki/%C3%9Erymskvi%C3%B0a) 30–32연, [「히미르의 노래」](https://www.heimskringla.no/wiki/Hymiskvi%C3%B0a) 22–24연을 확인했다.
- 아홉 세계에 관한 기존 시는 그 연에서 아홉 이름을 열거하지 않는다. 산문의 지명과 헬의 권한만으로 정해진 아홉 지명 목록을 만들지 않는다. 이그드라실의 뿌리 배치와 토르의 뱀 낚시 등은 작품별 차이를 남긴다. 문학 속 의례 장면을 역사적 관습 전체로 일반화하지 않는다.
- 기존 카드의 별칭 식별은 벨로스판 각주를 밝혀 두었다. 예언과 회고를 모든 전승의 확정된 연표로 만들지 않는다. 추가 카드는 `supplementary.md`를 가리키므로 기존 단일 원고 기준 검증기의 다중 문서 지원과 런타임 생성은 통합 작업에서 확인해야 한다.

## 유지와 검증

- `original.md`의 `stanza-001`–`stanza-066`, 저본의 연별 행 수·난쟁이 명단·후렴·결락 표시와 `template.json.content_markdown`은 그대로 보존한다.
- 기존 53개 카드의 키·본문·순서를 유지하고 새 카드를 뒤에 붙였다. 각 새 카드의 근거 문자열은 보충 문서의 해당 앵커 아래 실제 원문 발췌와 일치해야 한다.
- 템플릿 섹션의 본문·유형·근거는 카드와 일치하고 본문은 UTF-16 기준 3,000자 이하여야 한다. 런타임 JSON과 다른 장르의 반영은 상위 통합 작업에서 수행한다.
