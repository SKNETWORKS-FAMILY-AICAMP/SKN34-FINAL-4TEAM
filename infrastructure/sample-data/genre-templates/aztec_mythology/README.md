# 아즈텍 신화: 그림으로 전한 멕시코인들의 역사

16세기 익명 문헌 「그림으로 전한 멕시코인들의 역사」의 1882년 게재본을 다룬다. 창조·태양·이주·왕조·정복·법·계보·달력·제복과 이명·연대 모순을 포함하며 식민기 서술을 현대 사실로 승인하지 않는다.

[카드](source/tradition-cards.json) 72장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·장절을 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.
