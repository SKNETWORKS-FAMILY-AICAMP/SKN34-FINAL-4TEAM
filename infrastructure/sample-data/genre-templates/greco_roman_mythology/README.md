# 그리스 전승 서사와 세계관 정리

한 전승을 먼저 이어지는 글로 작성하고, 그 글에서 세계관을 정리한 대표본입니다. 그리스 전승을 중심으로 다루며 기존 `greco_roman_mythology` 식별자는 유지합니다. 로마의 아이네아스 전승은 그리스 신화와 동일시하지 않고 별도 부록으로 읽습니다.

## 읽는 순서

1. [전승 서사](source/original.md): 창세와 신권 계승에서 올림포스의 질서, 인간과 신의 관계, 영웅들의 과업, 트로이 전쟁과 귀환으로 이어지는 한국어 재서술입니다. 신화를 소재로 지어낸 소설이나 새 주인공의 도입부가 아닙니다.
2. [세계관 정리](source/template.json): `content_markdown`은 위 원고 전문이고, `setting_bible.sections`는 그 원고에서 추출한 인물·장소·신물·집단·규칙·사건입니다. 원고와 세계관은 별도의 결과물입니다.
3. [카드 데이터](source/tradition-cards.json): 각 카드의 `narrative_refs`에서 원고 절 ID와 정확한 근거 문장을 확인합니다. 원고에 없는 설정을 카드에서 새로 만들지 않습니다.

## 출전과 이설

원고의 각 절에 고전 문헌명·권/행과 공개 판본 링크를 표시합니다. 현대 번역문을 옮기지 않은 자체 한국어 요약이며, 모든 고대 전승을 망라한 완역이 아닙니다. 아프로디테의 출생 계보, 명계 설명, 영웅 사건의 배치처럼 문헌이 다른 부분은 차이 자체를 남깁니다. 서사의 편집 순서를 모든 고대 작품이 합의한 연대표로 읽지 않습니다.

## 데이터와 검증

- 기존 그리스 세계관·카드의 안정된 ID와 순서를 유지합니다. 다른 전승 자료와 기존 창작 장르 11종은 이 교정에서 변경하지 않습니다.
- 사건은 `event`/`history`, 나머지는 해당 유형/`basic`입니다. 카드 정본을 `build_traditions.py`로 최종 리소스에 반영하며 v1 동결본을 추가하지 않습니다.
- 원고를 수정하면 근거 문장을 재검토하고 `template.json`의 `content_markdown`과 `setting_bible`도 함께 갱신합니다. 생성기는 카드를 서사에서 자동 추론하지 않으며 최종 리소스만 재생성합니다.
- `python -m unittest test_traditions -v`와 `python build_traditions.py --check`를 상위 폴더에서 실행합니다. 모든 카드의 근거 절과 인용이 원고에 있는지 검사합니다. 의미상 충실성은 별도 편집 검토가 필요합니다.
- 원고 전문과 `narrative_refs`는 소스 자료입니다. 현재 WorldStudio 적재기는 최종 카드만 읽으므로 원고 전문을 UI에 새로 노출하거나 DB에 등록하는 기능 변경은 포함하지 않습니다. 이미 저장된 사용자 세계관도 덮어쓰지 않습니다.

북유럽·러브크래프트 원작·서유기 등 다른 전승도 같은 두 단계로 구성하지만, 각 전승의 원고와 출전·세계관은 서로 독립적으로 보존합니다.
