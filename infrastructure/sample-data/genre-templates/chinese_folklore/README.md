# 중국 고대 신화·설화: 《천문》과 보충 전승

《천문》의 질문과 《태평어람》에 인용된 《삼오력기》·《열자》·《풍속통》, 《회남자》 권6 남명훈의 대표 전승을 다룬다. 시의 질문을 확정된 답으로 바꾸거나 서로 다른 문헌을 단일 연표로 합치지 않는다.

[카드](source/tradition-cards.json) 58장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. [보충 출전](source/supplementary.md)의 기존 원어 발췌와 링크는 유지한다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·장절을 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.
