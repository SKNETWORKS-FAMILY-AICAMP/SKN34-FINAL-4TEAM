# 중국 고대 신화·설화: 《천문》 한 작품의 완역

## 읽는 순서

1. [한국어 전문](source/original.md): 굴원에게 귀속되는 독립시 《천문》의 7문단 전체를 읽는다. 《초사》 전체나 중국 신화 전체의 완역이 아니다.
2. [카드 정본](source/tradition-cards.json): 시의 물음과 진술에서 뽑은 카드 50개를 읽는다. 질문을 답으로 바꾸거나 시에 없는 사건을 추가하지 않는다.
3. [소스 템플릿](source/template.json): `content_markdown`은 원고 전문과 같고 `setting_bible.sections`는 카드의 제목·본문·유형·근거를 반영한다.

## 저본과 번역 범위

- [위키문헌 《천문》 고정 판본 2639576](https://zh.wikisource.org/w/index.php?title=天問&oldid=2639576)의 첫머리부터 마지막 질문까지, 한문 본문 7문단을 직접 한국어로 새로 번역했다. 현대 한국어 번역의 복사나 영어 중역이 아니다.
- 저본의 마침표·물음표 기준 190개 단위가 번역과 일대일 대응한다. 문단별 단위 수는 23·22·13·36·35·52·9개이다. 이는 검증용 구분이며 통상 논의되는 시의 질문 수나 고대 행 수와 혼동하지 않는다.
- 꺾쇠 덧글 15개와 둥근 괄호 덧글 1개는 모두 한국어 편집 주에 보존하고 선택한 독법을 밝혔다. 주석의 일화를 새로운 시구로 넣지 않았다.
- 왕일·홍흥조의 공개 고전 주석은 해석 참고 자료로만 사용했다. 주석서의 서문·후서와 현대 웹사이트 문구는 시 본문에서 제외했다.
- 고대 원작과 고전 주석은 보호기간이 만료된 저작물이다. 출처·번역 방식·난해 구절의 선택·저본 HTML 지문은 원고에 기록했다.

## 카드의 범위와 키

기존 대상 중 `nuwa`·`gonggong`·`kunlun`·`yi`의 키를 유지했다. 여와의 보천, 오색돌, 부주산 충돌, 서왕모, 청조, 정위, 과보 등 다른 작품에서 끌어온 카드는 제거했다. 해를 쏘는 물음은 남아 있지만 이 시구에는 열이라는 수가 없으므로 기존 `ten_suns` 카드를 그대로 유지하지 않았다.

강회를 공공으로 읽는 것과 같은 주석상의 식별은 본문의 직접 진술과 구분한다. 해·항·혼미의 계보, 생략된 주어, 왕조의 전승을 임의의 단일 연표로 정리하지 않는다. 카드의 `event` 유형도 해당 질문의 주제를 분류할 뿐 그 내용이 확정 사실이라는 뜻은 아니다.

## 검증과 갱신

- 저본 7문단을 분할한 190개 단위를 다시 합치면 모든 문구가 원래 순서대로 복원되는지 확인한다.
- `tianwen-001`부터 `tianwen-190`까지 중복·누락 없이 존재해야 하며 각 단위에 한국어 번역이 있어야 한다.
- 카드 50개는 해당 본문의 정확한 문자열을 `narrative_refs`로 갖고, 소스 템플릿의 카드와 전문 미러는 일치해야 한다.
- 기존 `build_traditions.py`의 `validate_narrative`로 이 장르만 읽기 검증할 수 있다. 이 변경에서는 런타임 JSON·다른 장르·저장된 사용자 세계관을 수정하지 않는다.
- 전체 빌드·통합 테스트·커밋·푸시는 실행하지 않는다. 단위·앵커·미러 검증은 의미의 충실성을 자동 보증하지 않으므로 저본과 주석에 대한 편집 검토를 함께 수행한다.

## 전문 파생 카드 확장

카드 50개로 확장하여 기존 38개 키를 모두 보존했다. 새 대상에는 새 키를 부여하고, 기존 템플릿 식별자와 순서를 유지한 채 새 섹션을 뒤에 추가했다.

우주 구조와 지리의 세부 물음, 기이한 동식물·기상·몸, 난해한 계보, 소왕·유왕·제환공, 백림과 말미의 여러 전승까지 보완했다. 모든 질문과 생략된 주어를 유지하고 답·왕조 연표·능력 법칙을 새로 만들지 않는다.

본문 190개 앵커를 주요 인물·집단·장소·사물·능력·사건·질문의 카드 근거에 모두 연결했다. 이름 명단은 집단 카드에 묶어 보존하므로 각 이름에 독립된 전기를 만들어 붙이지 않는다. 앵커 연결의 완전성은 의미의 자동 증명이 아니며, 원문의 문장과 카드의 진술을 별도로 대조했다.

카드 본문은 UTF-16 기준 3,000자 이하이며, 모든 근거는 해당 앵커의 실제 문자열이다. 이번 카드 확장에서 original.md와 템플릿의 전문 content_markdown은 변경하지 않았다. 런타임 JSON과 다른 장르의 생성·반영은 상위 통합 작업에서 따로 수행한다.
