# 게르만 설화 · 홀레 부인

그림 형제의 「홀레 부인」 **한 작품의 한국어 완역**과 그 본문에서 추출한 세계관 자료다. 다른 동화의 줄거리나 고대 게르만·북유럽 신화의 설정을 함께 넣지 않는다.

## 수록 판본과 완역 범위

- 《어린이와 가정의 동화》 제1권, 대판 제7판(최종 생전판), 제24편. 괴팅겐, 디터리히, 1857년, 133~136쪽.
- [독일어 전사본과 원판 네 쪽 영인본](https://de.wikisource.org/wiki/Frau_Holle_(1857))을 확인하고 직접 번역했다. 1922년 영어 선집의 재서술이나 현대 한국어 번역 전재가 아니다.
- 원판 산문 4문단과 수탉의 2행 노랫말 2블록을 `holle-p001`~`holle-p006`에 대응시켰다. 134쪽의 헤센 지방 관련 작가 각주 한 개도 `holle-note-001`에 완역했다. 문단 안의 페이지 경계는 별도 문단으로 세지 않는다.
- 원전은 저작권 보호기간이 만료된 공공 영역 작품이다. 새 한국어 번역만 수록하며 사이트의 현대 해설·편집 문구는 포함하지 않는다. 판본·번역·권리·대조 정보는 원고 앞의 편집 안내에 명시했다.

## 자료 구조

- `source/original.md`: 처음부터 마지막 문장까지의 완역. 작품 본문과 편집 안내·원판 각주를 구분한다.
- `source/tradition-cards.json`: 이 작품에서만 추출한 14개 카드. 각 `narrative_refs`는 실제 본문 앵커와 정확한 근거 문장을 가리킨다.
- `source/template.json`: `content_markdown`은 원고 파일과 동일하며, `setting_bible.sections`는 카드의 내용·유형·근거와 일치한다.
- 같은 대상인 `holle`, `holle-well`, `holle-bed`, `holle-reward`의 key와 템플릿 세계관 식별자는 유지했다. 다른 작품의 항목은 삭제하고 이 작품에 새로 필요한 대상에는 새 key를 부여했다.
- 이 변경은 위 세 원본 파일과 이 README에 한정한다. 런타임 JSON·v1 동결본·DB·앱은 갱신하지 않는다. 통합 반영 시 원본 검증을 거쳐 런타임 자료를 별도로 재생성해야 한다.

## 본문 파생 항목 보강

홀레의 집, 말하는 빵과 사과나무를 별도 대상으로 구분했다. 첫 소녀의 향수와 귀향 선택, 친딸의 의도적 모방, 황금 때문에 이루어진 환대, 평생 지워지지 않는 역청을 기존 인물·사건 카드에 보강했다. 두 소녀의 상대적 나이나 이름은 창작하지 않는다.

이번 보강은 기존 11개 키와 해당 대상·템플릿 섹션 ID·순서를 유지하고, 새 대상 3개만 뒤에 추가한다. 모든 카드에는 실제 본문 앵커 안의 정확한 인용을 붙였으며 본문은 카드당 3,000 UTF-16 코드 단위 이하다. 주요 인물·사건·장소·물건·규칙을 포괄하되 모든 문장을 별도 카드로 만들지는 않는다.

이번 단계는 tradition-cards.json·template.json·이 README만 변경한다. original.md의 전문과 template의 content_markdown, 최상위 id·genre_id·order는 보존한다. 런타임 JSON·전역 README·기존 사용자 세계관은 변경하지 않는다. 따라서 런타임 재생성 전에는 전체 리소스 일치 검사가 불일치를 표시할 수 있으며, 런타임 반영은 통합 단계에서 별도로 수행한다.
