# 퓨전 판타지 전용 샘플

작품: 《무림에서 돌아온 마법 아카데미의 낙제생》

## 자유롭게 고쳐 쓰는 퓨전 판타지 시작 예시

이 샘플은 빈 화면에서 시작하기 어려운 사용자를 위한 **자유롭게 수정·삭제하는 예시용 디폴트 템플릿**입니다. 퓨전 판타지의 익숙한 클리셰를 참고해 자기 이야기를 만드는 출발점으로 사용하세요. 작품 제목·인물·세계관·규칙·도입 장면은 모두 바꿀 수 있습니다.

### 기본 템플릿

이 장르에는 별도 **기본 템플릿**이 있습니다. `source/template.json`의 `basic_template`와 전체 원문의 “최초 기본 템플릿”에서 확인할 수 있습니다.

### 확장 설정

`source/template.json`의 `setting_bible` 소개와 항목별 설정을 참고하세요. 마지막 “첫 화 도입 예시”는 아래의 도입 예시로 구분합니다. 설정을 전부 채택할 필요는 없으며, 기본형과 내용이 다르면 원하는 쪽을 선택해 일관되게 정리하세요.

### 도입 예시

설정집의 **첫 화 도입 예시**와 미발행 **1화 도입 예시** 원고는 같은 예시입니다. 문체·장면 전개의 참고 자료이며, 반드시 이어 써야 하는 정해진 첫 화가 아닙니다. 수정·삭제하거나 다른 장면으로 시작할 수 있습니다. 사용자가 채택하기 전에는 실제 작품에서 이미 일어난 사건으로 취급하지 않습니다.

전체 원문 문서는 위 자료를 모아 둔 보관본입니다. 항목별 문서와 중복되므로 별도의 새 설정으로 취급하지 않습니다. [공통 사용 안내와 서비스 표시 문구](../TEMPLATE_GUIDE.md)를 참고하세요.

## 패키지 구성과 Flyway 적용

이 디렉터리는 작품 1개와 세계관 1개만 포함합니다. 다른 장르와 설정을 병합하지 않습니다.

- `migrations/content/V24__genre_template_fusion_fantasy.sql`: 이 장르만 적재하는 Flyway 버전 마이그레이션.
- `core/*.csv`, `content/*.csv`: 데이터 확인용 스냅샷. 적용 시 Python으로 변환하지 않습니다.
- `category-mapping.json`: 문서별 카테고리와 원문 위치. 기존 분류가 없는 항목은 기타입니다.
- `source/`: 수정하지 않은 전체 원문과 구조화 데이터.
- `source-inventory.json`: 원문 해시, ID, 카테고리 및 마이그레이션 경로.

전체 원문과 기본 예시는 복합 자료이므로 기타로 보존하고, 개별 설정 항목은 내용별로 분류했습니다. 상세 매핑은 [카테고리 안내](../CATEGORY_MAPPING.md)를 확인하세요.

먼저 [Flyway 적용 순서](../FLYWAY.md)에 따라 공통 계정과 기타 카테고리를 준비한 뒤 이 장르의 SQL만 선택합니다. 샘플은 로그인 비활성 소유자의 비공개 작품이며 예시 1화는 미발행입니다. 체크포인트는 초기 저장 상태를 위한 content_only 자료입니다.

DB 적재·실제 사용자 소유권 연결·템플릿 선택 UI는 수행하지 않았습니다. 이전 준비본이 이미 적재된 DB에는 그대로 중복 적용하지 않습니다.
