# 이집트 신화 · 라와 이시스의 전설

버지 1912년 「라와 이시스의 전설」과 우나스 피라미드 문서 장송 주문 23·213·219·252 일부를 다룬다. 주문을 역사적 문헌으로 다루고 의학적 처방으로 제시하지 않는다.

[카드](source/tradition-cards.json) 19장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. [보충 출전](source/supplementary.md)의 기존 원어 발췌와 링크는 유지한다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·확인된 위치를 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.

「라와 이시스의 전설」의 출전 위치는 작품 단위 링크와 편집 식별자만 제공하므로 카드별 원전 구절을 특정하지 못한다. 보충 출전은 별도로 표시된 위치를 따른다.
