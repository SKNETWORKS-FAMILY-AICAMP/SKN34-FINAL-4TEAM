# 이집트 신화 · 라와 이시스의 전설

[원고](source/original.md)는 버지 1912년 영어 번역에 실린 고대 독립 주술 서사 「라와 이시스의 전설」의 한국어 중역 전문이다. 이집트 신화 전체나 버지의 선집 전권이 아닌 한 작품이다. 19개 본문 문단과 마지막 주문 적용 지시를 모두 포함하며, 현대 영어 서론과 역자의 해설 각주는 작품 본문에서 제외한다.

[세계관 카드](source/tradition-cards.json)는 이 작품에서 추출한 15장이다. 단일 작품 전환 때 종전 여러 작품 구성의 15장 가운데 오시리스 부활·사후 심판 등 다른 전승 카드를 제거했다. 같은 대상과 사건인 ra, isis, horus, secret_name, isis_ra 키는 보존한다. 다른 문헌의 뱀이나 신계 체계를 임의로 합치지 않는다.

[템플릿](source/template.json)의 content_markdown은 원고와 같으며 setting_bible.sections는 카드·근거에 대응한다. 각 narrative_refs는 문단 앵커와 정확한 번역문을 가리킨다. 저본 URL·권리·중역 여부·수록 범위·취득 HTML 해시는 원고 안내에 명시한다.

주문은 역사적 신앙 문헌으로 다루며 실제 의학적 처방으로 사용하지 않는다. 기존 사용자 세계관의 저장 데이터를 덮어쓰는 작업은 하지 않는다. 상위 build_traditions.py로 런타임 JSON을 재생성하고 test_traditions.py 및 --check로 대응 관계를 검증한다.

## 본문 파생 항목 보강

라의 창조와 하루의 세 호칭, 자식 신들의 소집, 두 눈의 맹세 요구, 두 땅의 길, 마지막 네 신의 형상 위에서 하는 낭송 지시까지 보강했다. 맹세 요구를 실제 눈 양도의 완료로 바꾸거나 주문을 실제 치료법으로 제시하지 않는다.

이번 보강은 기존 10개 키와 해당 대상·템플릿 섹션 ID·순서를 유지하고, 새 대상 5개만 뒤에 추가한다. 모든 카드에는 실제 본문 앵커 안의 정확한 인용을 붙였으며 본문은 카드당 3,000 UTF-16 코드 단위 이하다. 주요 인물·사건·장소·물건·규칙을 포괄하되 모든 문장을 별도 카드로 만들지는 않는다.

이번 단계는 tradition-cards.json·template.json·이 README만 변경한다. original.md의 전문과 template의 content_markdown, 최상위 id·genre_id·order는 보존한다. 런타임 JSON·전역 README·기존 사용자 세계관은 변경하지 않는다. 따라서 런타임 재생성 전에는 전체 리소스 일치 검사가 불일치를 표시할 수 있으며, 런타임 반영은 통합 단계에서 별도로 수행한다.
