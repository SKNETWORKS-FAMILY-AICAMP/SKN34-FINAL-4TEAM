# 로맨스 판타지 전용 샘플

작품: 《악녀는 북부 대공과 계약한다》

## 자유롭게 고쳐 쓰는 로맨스 판타지 시작 예시

이 샘플은 빈 화면에서 시작하기 어려운 사용자를 위한 **자유롭게 수정·삭제하는 예시용 디폴트 템플릿**입니다. 로맨스 판타지의 익숙한 클리셰를 참고해 자기 이야기를 만드는 출발점으로 사용하세요. 작품 제목·인물·세계관·규칙·도입 장면은 모두 바꿀 수 있습니다.

### 기본 템플릿

이 장르에는 별도 **기본 템플릿**이 있습니다. `source/template.json`의 `basic_template`와 전체 원문의 “최초 기본 템플릿”에서 확인할 수 있습니다.

### 확장 설정

`source/template.json`의 `setting_bible` 소개와 항목별 설정을 참고하세요. 마지막 “첫 화 도입 예시”는 아래의 도입 예시로 구분합니다. 설정을 전부 채택할 필요는 없으며, 기본형과 내용이 다르면 원하는 쪽을 선택해 일관되게 정리하세요.

### 도입 예시

설정집의 **첫 화 도입 예시**는 문체·장면 전개의 참고 자료이며, 반드시 이어 써야 하는 정해진 첫 화가 아닙니다. 수정·삭제하거나 다른 장면으로 시작할 수 있습니다. 사용자가 채택하기 전에는 실제 작품에서 이미 일어난 사건으로 취급하지 않습니다.

전체 원문 문서는 위 자료를 모아 둔 보관본입니다. 항목별 문서와 중복되므로 별도의 새 설정으로 취급하지 않습니다. [공통 사용 안내와 서비스 표시 문구](../TEMPLATE_GUIDE.md)를 참고하세요.

- `source/template.json`: 구조화 데이터(`basic_template`, `setting_bible`).
