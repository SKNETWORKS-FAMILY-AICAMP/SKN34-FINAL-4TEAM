# 역사·신화 설정 카드 검토 자료

이 디렉터리는 역사 7개 세계관의 후보 12,618개(`full-history/`)와 신화·전승 15개 세계관의 후보 1,243개(`full-myth/`), 총 13,861개의 검토 산출물이다. 수량은 구조상 후보 수이며 중복을 포함한다. 각 디렉터리의 `index.json`에 출처·검수 제한과 입력·출력 정보를, `cards-NNN.json`에 후보를 나누어 담았다.

읽음 표시는 추출자의 자기보고이며 미독·접근 실패와 구분한다. 의미적 중복, 역사·전승·번역·근거의 정확성과 누락 없는 전수 여부는 확인되지 않았다. 입력·출력 검사의 수량은 모두 대응하지만 본문이 모두 바이트 단위로 같은 것은 아니다. 미국 21장 후보 100건의 출처·라이선스 고지 추가와 한국·이탈리아·수메르·아즈텍 표본 대조에 따른 정정 등을 포함해 이번 작업에서 기록한 본문 차이는 총 114건이다. 독립 감수와 권리 승인은 완료되지 않았다. 자세한 변경 및 근거는 각 인덱스를 확인한다.

원전·판본별 권리와 재배포 조건은 미확인이며 전사·번역 및 제3자 자료에도 별도 조건이 있을 수 있다. [이탈리아](full-history/italy/index.json)의 Google Oxford OCR은 개인적·비상업적 이용을 요청하며 법적 허용과 재배포 조건은 미확인이다. [수메르](full-myth/sumerian_mythology/index.json)의 제3자 Scribd OCR에는 All Rights Reserved 표시가 있으며 발췌 재사용 권리는 미확인이다. Scribd 직접 발췌 56개는 로컬 원본에 보존하고 공개 예정 검토 파일에는 생략 표시했으며 카드와 출처 URL·열·행은 보존했다. 다른 원전과 요약의 재사용 권리도 여전히 미확인이다. [미국](full-history/usa/index.json)의 The American Yawp 자료는 CC BY-SA 4.0의 출처, 장별 기여자, 변경 및 동일조건 정보를 카드와 미국 인덱스에 표시하며 일부 카드는 인덱스·원문 링크에 상세 정보를 위임한다. 최종 배포 경로에서 CC BY-SA 조건을 충족하는지는 검증되지 않았다. 이 기록은 권리 승인이나 법적 판단이 아니다.

주요 출처 한계는 다음과 같으며 상세 범위와 미확인 사항은 각 인덱스를 따른다.

- [그리스·로마](full-myth/greco_roman_mythology/index.json): 지정 신통기 전사에는 992행이 독립 표기되지 않으며 대응 본문과 판본 확인이 남았다.
- [인도](full-myth/indian_mythology/index.json): 지정 revision에 접근하지 못해 대체 전사와의 일치 여부가 미확인이다.
- [마야](full-myth/maya_mythology/index.json): OCR 오독과 판독 불확실성이 있으며 저본 결락 위치와 범위의 대조가 남았다.
- [아즈텍](full-myth/aztec_mythology/index.json): 본문 인쇄 결락을 복원하거나 확인된 내용으로 단정하지 않는다.
- [수메르](full-myth/sumerian_mythology/index.json): 원문 결락과 판독 한계가 있고 수메르어 전사 전체의 독립 판독·번역은 완료되지 않았다.

원문 직접 발췌는 사용자 선택에 따라 공개본에서 생략 표시하고 로컬 원본에 보존한다. 공개본의 구조화된 `excerpt` 필드는 0개이며 인덱스의 종전 발췌 수와 검증 내용은 당시 기록이다. 출처 URL·행·쪽은 유지하되 원전과 한국어 요약의 재배포 권리, 판독과 독립 감수는 여전히 미확인이다.

`미게시-임시자료:history/`와 `미게시-임시자료:myth/`는 공개 URL이 아니며 공개된 파일이나 재현 가능한 원본도 아니다. 입력 해시는 당시 임시 입력의 식별 정보일 뿐 원전의 해시가 아니다. 원전 commit URL 또는 출처 URL과 장·절을 확인하고, 각 인덱스의 미확인·접근 제한과 권리 조건을 함께 검토한다. 저장소 내 공개 소스는 저장소 상대경로로 표시한다. 일부 인덱스의 과거 통합 기록 해시는 해당 당시 파일을 가리킨다.

검토 전용 자료이며 앱이나 DB 시더에 연결되지 않았다. 기존 런타임 세계관 26종과 SOUL 문서는 보존한다. 현재 브랜치 변경은 세계관당 활성 카드 10,000개, 요청당 카드 1,000개와 편집 요청 2MB 제한이며 아직 배포되지 않았다. #425의 안전한 최초 적재 계약은 별도 설계·구현이 필요하다. 실제 적용이나 자동 적재를 하지 않으며 기존 세계관·사용자 편집·공개 설정·관계·저장 이력과 공유 DB를 승인 없이 자동 수정하거나 덮어쓰거나 초기화하지 않는다. 이 자료는 완전 추출, 사실 감수 또는 권리 해결을 뜻하지 않는다.
