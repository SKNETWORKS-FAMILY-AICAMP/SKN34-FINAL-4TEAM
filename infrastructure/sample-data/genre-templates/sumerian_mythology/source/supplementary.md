# 별도 전승 카드의 원어 근거

아래는 별개 문헌의 짧은 원어 전사 인용이다. 한국어 설명은 카드에서 따로 작성했으며 기존 원고의 전문에 삽입하지 않는다.

<a id="inana-descent"></a>
## 이난나의 저승 하강

- 원문: [ETCSL c.1.4.1, 1–5, 73–89](https://etcsl.orinst.ox.ac.uk/section1/c141.htm)
- 원어 전사: `kur-ra ba-e-a-ed_{3}`

<a id="ereshkigal-ganzer"></a>
## 에레시키갈과 간제르

- 원문: [ETCSL c.1.4.1, 90–128](https://etcsl.orinst.ox.ac.uk/section1/c141.htm)
- 원어 전사: `abul kur-ra 7-bi ^{jic}si-jar-bi he_{2}-eb-us_{2}`

<a id="inana-lapis-rod-variant"></a>
## 청금석 측량 막대와 문에서의 이설

- 원문: [ETCSL c.1.4.1, 25, 129A–B, 154–158; 번역 https://etcsl.orinst.ox.ac.uk/section1/tr141.htm](https://etcsl.orinst.ox.ac.uk/section1/c141.htm)
- 원어 전사: `gi 1 ninda ec_{2}-gana_{2} za-gin_{3}`

<a id="underworld-gates"></a>
## 간제르의 일곱 문

- 원문: [ETCSL c.1.4.1, 114–163](https://etcsl.orinst.ox.ac.uk/section1/c141.htm)
- 원어 전사: `abul kur-ra 7-bi ^{jic}si-jar-bi he_{2}-eb-us_{2}`

<a id="dilmun-enki-ninhursanga"></a>
## 엔키와 닌후르상가의 딜문

- 원문: [ETCSL c.1.1.1, 1–4, 11–39; 번역 https://etcsl.orinst.ox.ac.uk/section1/tr111.htm](https://etcsl.orinst.ox.ac.uk/section1/c111.htm)
- 원어 전사: `kur dilmun^{ki} sikil-am_{3}`

<a id="ninshubur-aid"></a>
## 닌슈부르의 구원 요청

- 원문: [ETCSL c.1.4.1, 26–67, 273–281; 번역 https://etcsl.orinst.ox.ac.uk/section1/tr141.htm](https://etcsl.orinst.ox.ac.uk/section1/c141.htm)
- 원어 전사: `sukkal-a-ni ^{d}ga-ca-an-cubur-ra`

ETCSL은 여러 필사본을 모은 복합 전사와 별도 영역이다. 첫 문 추가 구절은 편집자가 명시한 한 필사본의 이설이며 원문 154–158행의 여섯째 문 기록을 지우지 않는다.

<a id="inana-lapis-cdli-witness"></a>

## 우르 출토 점토판의 파손된 첫째 문 구절

- 원문: [CDLI P346462, 앞면 1′–3′](https://cdli.earth/artifacts/346462)
- 원어 전사: `[... esz2]-GAN2# za-gin3 [... 1(disz)]-kam#-ma [...]`
- CDLI 현재 판독은 훼손된 행을 막대와 줄을 쥔 장면으로 번역한다. ETCSL 추가 구절의 벗겨짐을 이 판독만으로 확정하지 않는다.
