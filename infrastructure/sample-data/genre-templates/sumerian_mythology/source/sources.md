# 출전 위치

각 앵커는 기존 편집 식별자다. 문단 번호는 원전의 공식 장절 번호가 아니다. 각 링크와 위치를 직접 대조해야 하며 카드 설명의 사실 관계를 자동 증명하지 않는다.
