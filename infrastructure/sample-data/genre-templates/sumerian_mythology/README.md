# 수메르 신화: 구데아의 신전 건립 찬가 · 원통 A와 B

에닌누 건립과 봉헌을 노래한 한 작품인 구데아 원통 A·B의 현존 저본 전체를 한국어로 중역한다. A 30열과 B 24열을 모두 포함하며, 물리적 결락과 1905년 미해독 부분을 보존한다. 이난나 하강 등 별개 작품을 합치지 않는다.

1905년 Thureau-Dangin 프랑스어 해석을 중역했다. [저본](https://archive.org/details/lesinscriptionsd00thuruoft). 54열 전체의 행 번호와 반복·종결문을 보존했다. 이는 현존 저본 전체이지 소실 없는 원작 복원이 아니다. 결락·미해독과 당시의 보충 읽기는 original.md에서 구별한다. 현대 번역 복사 없이 공공영역 저본을 사용했다.

53개 카드는 이 작품에서만 추출했다. 이전 이난나 하강·엔키와 닌후르사가·권능 이전 자료는 별개 작품이므로 제거했으며, 다른 인물을 이전 key에 덮어씌우지 않았다. 본문 앵커와 카드 인용, template 본문·카드를 동기화했다.

## 전문 기반 파생 설정 확장

기존 24개 카드의 key와 순서를 보존하고 29개를 더한 53개 카드다. 본문의 54개 장·절·열 단위를 주요 서사·계보군에 연결했다. 개별 인물의 모든 자손과 모든 지명을 독립 카드로 만들지는 않으며 자세한 목록은 원문 근거에서 확인한다.

본문 인용 앵커는 기존 19/54에서 확장 후 54/54로 늘었다. 이는 근거 추적 가능성의 수치이며, 카드 설명에 원문의 모든 사실이 재현되었다는 뜻은 아니다. 관계와 사건은 본문에서 확인되는 범위만 설명한다. exact evidence와 UTF-16 본문 길이(최대 197)를 검증했다.

설정 카드와 전문은 별개다. template의 content_markdown에는 기존 전문 전체를 그대로 유지하고, setting_bible.sections에 확장 카드를 반영한다.
