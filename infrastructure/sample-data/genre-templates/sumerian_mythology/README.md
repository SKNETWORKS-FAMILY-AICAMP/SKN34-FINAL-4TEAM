# 수메르 신화: 구데아의 신전 건립 찬가 · 원통 A와 B

구데아 원통 A·B의 1905년 프랑스어 저본과 ETCSL의 《이난나의 저승 하강》·《엔키와 닌후르상가》 일부를 다룬다. 원통의 결락·미해독과 당시 해석을 완전한 원작 복원으로 취급하지 않는다.

[카드](source/tradition-cards.json) 59장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. [보충 출전](source/supplementary.md)의 기존 원어 발췌와 링크는 유지한다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·장절을 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.
