# 한국 신화 · 동명왕편

## 읽는 순서

1. [한국어 완역](source/original.md): 이규보의 독립 작품 「동명왕편」 한 편을 서문·시·작가자주까지 모두 옮겼다. 『동국이상국집』 전체 번역이 아니다.
2. [세계관 카드](source/tradition-cards.json): 이 작품에서 추출한 41장이다. 서문과 시의 화자, 자주가 전하는 이야기, 편집자의 설명을 구분한다.
3. [소스 템플릿](source/template.json): content_markdown은 완역 파일과 같고 setting_bible.sections는 카드 및 근거와 대응한다.

## 저본·권리·대응

[국사편찬위원회 한국사데이터베이스의 한문 전사본](https://db.history.go.kr/id/mudg_005_0010_0010)을 직접 번역했다. 연결된 현대 국역은 읽거나 전재하지 않았다. 원작은 보호기간이 만료된 고전이며 현대 국역과 데이터베이스의 권리는 별개다. 정확한 수록 위치, 취득 HTML 해시, 교감 2건의 처리, 원전 결손과 난해한 표현의 원칙은 완역 첫머리에 밝힌다.

서문 1문단, 시 40묶음과 작가자주 39개, 합계 80개 원전 대응 앵커를 둔다. 시는 저본의 구두점 기준 280개 구문 단위를 280개 한국어 행으로 옮겼다. 자주 번호는 원문의 소자 주석 순서이고 시 묶음은 자주가 끼어드는 위치에 맞춘 편집 구분이다. 원전의 결손 표지와 원전 자체의 ‘운운’도 보존한다.

## 범위와 식별자

종전 여러 전승의 15장을 한 작품의 41장으로 재구성했다. 같은 대상을 나타내는 jumong, yuhwa, river_crossing 키와 템플릿 id·genre_id·order를 유지한다. 단군·바리공주·제주 본풀이에만 해당하는 카드는 제거하고 그 키를 다른 인물에게 재사용하지 않는다. 이미 저장된 사용자 세계관을 덮어쓰는 이관 작업은 하지 않는다.

## 검증과 생성

각 narrative_refs는 원고 안의 실제 앵커와 해당 번역 문구를 가리킨다. 원고·근거·소스 템플릿은 함께 갱신한다. 원전 단위의 대응 검사와 JSON·앵커·인용문·동기화 검사를 수행하며, 상위 test_traditions.py의 관련 데이터 계약으로 확인할 수 있다. 한문 표현의 해석 검토와 기계적 일치 검사는 별개다.

이 작업은 이 폴더의 README와 source/original.md, source/tradition-cards.json, source/template.json에 한정한다. 서비스 실행용 리소스와 다른 장르의 소스는 여기서 생성하거나 수정하지 않는다. 전체 장르의 생성·검증은 상위 작업에서 진행한다.

## 전문 파생 카드 확장

카드 41개로 확장하여 기존 22개 키를 모두 보존했다. 새 대상에는 새 키를 부여하고, 기존 템플릿 식별자와 순서를 유지한 채 새 섹션을 뒤에 추가했다.

서두·결말의 중국 성왕 비교, 이주와 혼인 예법, 구리 집과 가죽 수레, 유화의 유배·구출, 어린 주몽의 활, 세 동료, 부분노와 낡은 기둥, 유리의 유년까지 보완했다. 시·작가자주·화자의 논증을 구분하며 자주의 단어 풀이와 운율 설명은 해당 사건 카드에서 편집적 설명으로 명시한다.

본문 80개 앵커를 주요 인물·집단·장소·사물·능력·사건·질문의 카드 근거에 모두 연결했다. 이름 명단은 집단 카드에 묶어 보존하므로 각 이름에 독립된 전기를 만들어 붙이지 않는다. 앵커 연결의 완전성은 의미의 자동 증명이 아니며, 원문의 문장과 카드의 진술을 별도로 대조했다.

카드 본문은 UTF-16 기준 3,000자 이하이며, 모든 근거는 해당 앵커의 실제 문자열이다. 이번 카드 확장에서 original.md와 템플릿의 전문 content_markdown은 변경하지 않았다. 런타임 JSON과 다른 장르의 생성·반영은 상위 통합 작업에서 따로 수행한다.
