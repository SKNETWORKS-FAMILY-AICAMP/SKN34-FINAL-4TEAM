# 서유기 · 백회본

현행 중국어 위키문헌 100회본 한 작품을 새로 한국어로 직접 완역한 자료입니다. 제1~100회의 산문·운문 3,782블록을 같은 순서로 옮겼으며 본문은 1,446,106자입니다. 시·대화·반복·명단·주문·회말 및 마지막 귀의와 회향문을 포함합니다. 현대 번역문을 복사하지 않았습니다.

## 판본과 범위

진광예 일화를 독립 제9회로 둔 청대 증보 계통의 현행 배열을 따릅니다. 1592년 초판 자체의 번역이라고 주장하지 않습니다. [중국어 저본](https://zh.wikisource.org/wiki/西遊記)의 회별 고정 리비전 링크와 원문 HTML 해시는 원고 부록에서 확인합니다. 역사적 현장의 여행과 소설을 구별하며, 본문의 모순과 당대 종교·성별·신분 관념을 현대 사실이나 실천 지침으로 제시하지 않습니다.

## 읽는 순서

1. [한국어 전문](source/original.md): 한 작품의 100회 전체. 편집 주석과 번역자 설명은 서사와 구별합니다.
2. [세계관 정리](source/template.json): content_markdown은 전문과 동일하고 setting_bible.sections는 별도로 추출한 설정입니다.
3. [카드 데이터](source/tradition-cards.json): 기존28개 key를 유지하고 주요 인물·장소·도구·능력·규칙·사건을 보완한76카드입니다. 151개 narrative_refs가 실제 본문 앵커와 정확한 인용으로 연결됩니다.

100회 주요 사건 묶음을 검토했으며, 이는 모든 명사와 문장에 별도 카드를 붙인 백과사전이라는 뜻은 아닙니다. 등장인물의 추측·가르침·변신과 실제 서술을 구별합니다.

## 검증과 적재

원문100개·번역100개 해시, 원문HTML 재추출 순서,3,782개 블록 일대일 대응과 고유앵커,번역 문자열의 왕복 일치를 확인했습니다. 원고 변경 시 카드 요약·근거·template와 생성 runtime JSON을 함께 갱신합니다. 상위 build_traditions.py와 test_traditions.py로 재생성과 형식 검사를 수행합니다. 이는 전문의 모든 해석을 자동으로 입증하는 검증은 아닙니다.

원고 전문은 기존 카드 적재 대상이 아닙니다. DB·UI에 전문 표시를 연결하거나 이미 저장된 사용자 세계관을 덮어쓰는 런타임 변경은 포함하지 않습니다. v1동결본을 새로 만들지 않습니다.
