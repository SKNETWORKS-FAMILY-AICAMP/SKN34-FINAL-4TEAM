# 서유기 · 백회본

중국어 위키문헌의 현행 《서유기》 백회본을 다룬다. 진광예 일화를 제9회로 둔 청대 증보 계통의 배열을 따르며 1592년 초판 복원이나 역사적 현장의 여행 기록으로 표기하지 않는다.

[카드](source/tradition-cards.json) 76장과 [템플릿](source/template.json), [출전 위치](source/sources.md)를 제공한다. 한국어 번역 전문과 그 문단의 복제는 보관하지 않는다. 카드의 출전·이설은 각각 구분한다. 이 자료는 해당 전승 전체를 망라하지 않는다.

출전 위치는 기존 편집 앵커와 원전 URL·장절을 기록한다. 편집 앵커는 외부 원전의 공식 문단 번호가 아닐 수 있다. 생성기는 링크·앵커와 보충 발췌 해시를 검사하지만 번역 문단의 정확 일치나 원전에서 카드의 사실 관계를 자동 검증하지 못한다. 원전 대조와 해석은 편집 검토가 필요하다.
