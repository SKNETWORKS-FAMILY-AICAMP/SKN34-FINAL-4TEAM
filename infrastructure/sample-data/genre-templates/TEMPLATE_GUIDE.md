# 샘플 사용 안내

모든 샘플은 사용자가 자유롭게 편집할 수 있습니다. 장르 11종과 신화 14종은 목적이 다르므로 구분해서 선택합니다.

## 기존 장르 11종

- **기본 템플릿:** 작품의 주인공·목표·갈등을 정하는 출발점입니다.
- **확장 설정:** 인물·장소·세력·능력·사건 등을 더 구체적으로 만드는 선택 자료입니다.
- **도입 예시:** 첫 장면의 서술 예시입니다. 그대로 사용할 의무가 없습니다.

기존 원문과 카드 내용은 유지합니다. 장르별 세계관을 서로 섞어 자동 적용하지 않습니다.

## 신화·설화 14종

**전승 요약**을 신·존재, 장소, 신족, 권능, 신물, 규칙·금기·의례, 사건, 기타 문헌 안내로 나눕니다. 창작 작품명·새 주인공·도입 원고는 없습니다. 원전의 주역을 소개하는 인물 카드는 새 소설의 주인공을 지정하는 기능이 아닙니다.

각 카드 끝의 근거 문헌과 대목을 확인합니다. 서로 다른 전승과 판본은 이설로 구분하고, 빈 부분을 창작해 원전 사실처럼 기록하지 않습니다. 크툴루는 러브크래프트 원작의 문학 설정이며 후대 게임 수치와 작가의 추가 설정은 제외합니다. 서유기와 산해경은 중국 설화 폴더 안에서도 제목과 출처로 구분합니다.

한국어 요약은 수정 가능한 참고 자료이며 학술 감수본·원전 전체 번역·신화권 전체 백과사전이 아닙니다. 자신의 창작 설정을 더할 때에는 원전 요약과 새 해석의 경계를 표시하고 출처를 남깁니다.

## 화면에서 가능한 일

현재는 운영자가 자기 세계관 목록에서 자료를 열어 카드 순서대로 읽고 수정·저장할 수 있습니다. 일반 회원의 장르 선택 → 미리 보기 → 내 세계관으로 복사 흐름은 추가 구현이 필요합니다. DB 시더가 존재한다는 이유만으로 해당 UI가 완성됐다고 설명하지 않습니다.

전체 적재 방식·계정 한계·기존 DB 처리 범위는 [README](README.md)를 따릅니다.
