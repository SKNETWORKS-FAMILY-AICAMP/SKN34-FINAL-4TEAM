# 예시용 디폴트 템플릿 사용 안내

## 서비스에 표시할 안내 문구

아래 문구는 화면에 사용할 수 있는 제안입니다. 이번 변경에서 실제 UI를 연결하거나 DB의 원문을 바꾸지는 않았습니다.

**선택 화면 제목**

장르 예시로 시작하기

**선택 화면 설명**

무엇부터 써야 할지 막막한가요? 장르별로 익숙한 주인공, 세계관, 갈등과 첫 장면을 준비했습니다. 마음에 드는 예시를 골라 나만의 이야기로 바꿔 보세요.

**선택 후 공통 안내**

자유롭게 수정·삭제할 수 있는 예시용 디폴트 템플릿입니다. 이름, 배경, 관계와 규칙까지 원하는 대로 바꾸세요. 모든 항목을 사용하거나 예시 원고를 이어 쓸 필요는 없습니다.

| 영역 이름 | 영역 안내 문구 |
|---|---|
| 기본 템플릿 | 주인공·배경·핵심 갈등을 살펴보고, 이야기의 뼈대부터 바꿔 보세요. |
| 확장 설정 | 이야기를 더 구체화하고 싶을 때 필요한 설정만 골라 사용하세요. |
| 도입 예시 | 첫 장면을 쓰는 방법을 참고해 보세요. 그대로 이어 쓰거나, 고치거나, 새로 시작해도 됩니다. |

**별도 기본 템플릿이 없는 장르의 안내**

이 장르는 확장 설정집부터 제공합니다. 주인공과 배경, 핵심 갈등에서 마음에 드는 요소를 골라 시작해 보세요.

## 자료 구분과 표시 기준

- 기본 템플릿: `source/template.json`의 `basic_template`. 무협·로맨스 판타지·현대 판타지·SF·대체역사·게임 판타지·퓨전 판타지에 있습니다.
- 영지물·아포칼립스·스포츠 판타지·연예계물은 `basic_template`이 null입니다. 별도 기본형이 있는 것처럼 표시하지 않고 위의 대체 안내를 사용합니다.
- 확장 설정: `setting_bible.introduction_markdown`과 `setting_bible.sections`의 설정 항목. 마지막 “첫 화 도입 예시”는 도입 예시 영역으로 구분합니다.
- 도입 예시: 마지막 “첫 화 도입 예시” 항목.
- 전체 원문: `content_markdown`과 `source/original.md`는 보관본이며 WorldStudio 카드로 적재하지 않습니다. 기본·확장·도입에 더해지는 별도의 설정이 아닙니다.

기본형과 확장형의 차이는 선택·수정할 참고 재료로 안내합니다. 사용자가 채택한 내용으로 작품의 설정을 정리하고, 두 안을 무조건 함께 적용하지 않습니다. 각 장르는 독립된 예시이므로 다른 장르의 문서를 자동으로 합쳐 적용하지 않습니다.

## LLM 보조 작성에 사용할 때

LLM이 사용자의 아이디어 구체화와 초안 작성을 도울 때 참고하는 자료입니다. 모든 설정을 자동으로 확정하거나 장편의 생성 품질을 보장하는 프롬프트가 아닙니다. 선택한 장르와 사용자가 수정·채택한 설정을 중심으로 전달하세요. 도입 예시는 문체 참고인지 이어 쓸 원고인지 사용 의도에 맞게 구분하고, 전체 원문과 항목별 내용을 중복 전달하지 않습니다.

## 초기 저장 상태의 의미

WorldStudio에 적재된 카드의 저장 버전은 예시를 시작 가능한 초기 상태로 제공하기 위해 서버가 시작할 때 운영 관리자 계정(임시 할당)으로 저장해 둔 합성 데이터입니다. 실제 사용자의 작성·Fork·발행 활동 이력이 아닙니다. 예시 안의 “확정 설정”은 초기 저장 상태를 뜻하며, 사용자가 수정할 수 없는 규칙이라는 뜻이 아닙니다. ID는 내부 식별용이므로 사용자 안내에서는 제목과 역할을 중심으로 보여 주세요.
