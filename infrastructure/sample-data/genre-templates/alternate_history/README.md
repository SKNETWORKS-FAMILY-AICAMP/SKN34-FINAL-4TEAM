# 대체역사 전용 샘플

작품: 《눈 떠 보니 몰락 예정 왕자》

## 자유롭게 고쳐 쓰는 대체역사 시작 예시

이 샘플은 빈 화면에서 시작하기 어려운 사용자를 위한 **자유롭게 수정·삭제하는 예시용 디폴트 템플릿**입니다. 대체역사의 익숙한 클리셰를 참고해 자기 이야기를 만드는 출발점으로 사용하세요. 작품 제목·인물·세계관·규칙·도입 장면은 모두 바꿀 수 있습니다.

### 기본 템플릿

이 장르에는 별도 **기본 템플릿**이 있습니다. `source/template.json`의 `basic_template`와 전체 원문의 “최초 기본 템플릿”에서 확인할 수 있습니다.

### 확장 설정

`source/template.json`의 `setting_bible` 소개와 항목별 설정을 참고하세요. 마지막 “첫 화 도입 예시”는 아래의 도입 예시로 구분합니다. 설정을 전부 채택할 필요는 없으며, 기본형과 내용이 다르면 원하는 쪽을 선택해 일관되게 정리하세요.

### 도입 예시

설정집의 **첫 화 도입 예시**와 미발행 **1화 도입 예시** 원고는 같은 예시입니다. 문체·장면 전개의 참고 자료이며, 반드시 이어 써야 하는 정해진 첫 화가 아닙니다. 수정·삭제하거나 다른 장면으로 시작할 수 있습니다. 사용자가 채택하기 전에는 실제 작품에서 이미 일어난 사건으로 취급하지 않습니다.

전체 원문 문서는 위 자료를 모아 둔 보관본입니다. 항목별 문서와 중복되므로 별도의 새 설정으로 취급하지 않습니다. [공통 사용 안내와 서비스 표시 문구](../TEMPLATE_GUIDE.md)를 참고하세요.

## 패키지 구성과 적재 안내

이 디렉터리는 작품 1개와 세계관 1개만 포함합니다. 다른 장르의 CSV를 병합하거나 설정을 같은 world_id에 넣지 마세요.

- `core/*.csv`, `content/*.csv`: 기존 sample-data의 31개 테이블과 편집 원고 episode_draft를 포함한 CSV 32개.
- `sql/core.sql`, `sql/content.sql`: 이 장르만 적재하는 준비 SQL.
- `source/`: 이 장르의 전체 원문과 구조화 데이터. 축약 없음.
- `source-inventory.json`: 해당 장르의 ID와 원문 해시.
- 작품·설정은 비공개, 1화는 미발행 저장 원고입니다.
- 샘플 소유 계정은 로그인 비활성이고 다른 장르와 같은 샘플 계정을 사용하지만, 작품·세계관·설정·회차 ID는 독립적입니다.
- 설정은 일반 규칙 카테고리로 보존하며 rich 상세와 관계를 자동 생성하지 않습니다.
- 원문 보관 문서와 항목별 문서는 내용이 중복되므로 AI에 둘을 동시에 전부 넣지 마세요.

선택한 장르만 패키지 루트 load.py의 `render_sql(service, 이_디렉터리)` 입력으로 사용하세요. 기존 적용 migration을 수정하지 말고 실제 적재 시 해당 서비스의 새 migration 번호를 선택해야 합니다. DB 적재·공개 발행·기본 템플릿 UI 연결은 수행하지 않았습니다.

저장 흐름 보완: `episode_draft`, `content_only` 체크포인트, 회차 및 전체 확정 설정 버전 연결, 1화부터 적용되는 비공개 설정 범위를 포함합니다. 스냅샷은 소유자 기준으로 비공개 설정도 포함합니다. 자세한 계약 및 한계는 루트 SAVE_FLOW.md를 확인하세요.
