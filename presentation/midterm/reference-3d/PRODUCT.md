# STORYFORK 발표용 3D 영상

## Platform
web

## Purpose
중간발표 슬라이드에 삽입할 1920×1080 MP4 2종 및 대표 PNG. 실행 가능한 별도 React/Three.js 프로토타입.

## Confirmed constraints
서비스 소스·DB 변경 금지. 인디고·퍼플·블루. 영상 1은 vasturiano/react-force-graph 3D, 12–15초. 영상 2는 Three.js, 10–12초. 원작의 허용 회차에서만 Fork A/B가 시작되며 재Fork 없음.
사용자가 기존 홍길동전 자료 사용을 선택함. 기존 로컬 원문을 복사해 근거로 제공. 실제 서비스 기능을 구현했다는 주장을 하지 않음.

## Open decisions / assumptions
실제 작품의 Fork 허용 회차 설정은 확인되지 않음. 영상에서 허용 회차 EP.02·EP.03은 명시적으로 발표용 설정 예시이며 서비스 설정과 연결하지 않음.
