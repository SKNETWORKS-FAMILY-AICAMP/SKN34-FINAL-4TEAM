# Fork 생성 준비 (기능 54)

- 리더에서 포크를 누르면 원작과 기준 회차를 정책·저작권 안내로 전달한다. 비회원은 로그인 후 같은 안내로 돌아오며, 동의를 마치면 눌렀던 회차가 선택된 생성 화면을 연다. 작품 상세에서 시작하면 원작만 전달해 첫 허용 회차를 선택한다.
- 서버 작품은 공개 작품 응답의 `forkableEpisodes`를 사용한다. 목록은 공개 중인 회차와 최신 원작 정책(all/from/selected)의 교집합이다.
- 선택한 회차는 기존 공개 세계관 API에 전달한다. 응답의 작품 ID·회차가 일치해야 하며 공개 조건·회차를 통과한 설정·인물·사건 이름을 보여 준다. 재조회 중에는 이전 회차의 자료를 숨긴다.
- 원작에 연결된 세계관이 있으면 미리보기는 선택 기준 회차의 독자 설정 위키 카드(`GET /public/works/{id}/world-cards?upto=`)로 세어 Fork가 이어받는 카드와 같은 집합(DEC-53)을 보인다. 연결된 세계관이 없으면 위의 기존 공개 세계관 API를 쓴다. [계약](public-world-contract.md#fork가-이어받는-원작-세계관-dec-3237-365)
- 기준 회차 선택 영역에서 해당 회차까지의 원작 내용이 포함된다는 스포일러 경고를 표시한다. 서버 작품은 같은 공개 작품 응답의 `allowForkPublication`으로 현재 원작의 Fork 작품 공개 조건을 안내한다. 두 경우 모두 포크는 비공개로 생성한다.
- 선택 회차가 허용 목록에서 빠지면 첫 허용 회차와 그 미리보기를 함께 표시한다. 허용 회차가 없으면 생성 화면에서 원작으로 돌아간다.
- 관계의 과거 상태와 권한 밖의 정보는 표시하지 않는다.
