# Fork 생성 준비 (기능 54)

- 서버 작품은 공개 작품 응답의 `forkableEpisodes`를 사용한다. 목록은 공개 중인 회차와 최신 원작 정책(all/from/selected)의 교집합이다.
- 선택한 회차는 기존 공개 세계관 API에 전달한다. 응답의 작품 ID·회차가 일치해야 하며 공개 조건·회차를 통과한 설정·인물·사건 이름을 보여 준다. 재조회 중에는 이전 회차의 자료를 숨긴다.
- 선택 회차가 허용 목록에서 빠지면 첫 허용 회차와 그 미리보기를 함께 표시한다. 허용 회차가 없으면 생성 화면에서 원작으로 돌아간다.
- 관계의 과거 상태와 권한 밖의 정보는 표시하지 않는다.
