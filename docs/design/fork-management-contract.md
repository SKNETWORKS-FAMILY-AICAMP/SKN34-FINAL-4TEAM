# Fork 관리 (기능 14)

- 내 서재의 서버 작품은 소유 작품 응답에서 Fork의 원작 이름, 기준 회차·버전과 분기 방향을 보여 준다. 비공개·삭제된 원작도 저장된 기준은 확인할 수 있다.
- 기본 정보 저장은 기존 작품 수정과 revision 검사를 사용한다. 후속 원고는 기존 집필실에서 편집하며 상속 회차는 읽기 전용이다.
- 삭제는 기존 작품 소프트 삭제(DEC-42)를 사용한다. 삭제된 Fork도 한 원작당 한 번 제한에 포함한다.
- `DELETE /api/v1/works/{id}/fork-publication`은 소유자만 호출할 수 있다. 공개 중이면 비공개 이력을 한 건 추가하고 같은 작품의 대기 중인 예약 발행을 모두 취소한 뒤 204를 반환한다. 이미 비공개이면 204이며 예약은 그대로 둔다. 회차·발행 이력은 보존하고 이후 새 발행은 기존 절차를 따른다. 최초 공개만 원작의 현재 허용 여부를 확인한다.
