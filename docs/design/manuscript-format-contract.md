# 원고 기본 서식 계약 (DEC-48)

집필실 본문 편집기를 Toast UI Editor 3으로 바꾸고, 원고에 **기본 서식**(굵게·기울임·소제목·인용·구분선)을 둔다. 이 문서가 서식 문법의 정본이다. 프런트(TypeScript)와 서버(Kotlin, EPUB 내보내기)가 같은 규칙을 따로 구현하므로 아래 문법과 [검증 표](#검증-표)를 그대로 따른다.

## 결정 (2026-11-12 사용자 확정)

1. 집필실 본문 편집기는 Toast UI Editor 3의 **마크다운 쓰기 모드**다. 툴바는 `굵게 · 기울임 · 소제목 · 인용 · 구분선 · 이미지`이고 `쓰기 | 미리보기`로 바꿔 본다.
2. **저장 형식은 그대로 문자열**이다. 서버 스키마, 40,000자 한도(공백·줄바꿈·기호·이미지 표식 포함), 이미지 표식 `[[image:<UUID>]]`는 바뀌지 않는다. 기존 원고는 한 글자도 바꾸지 않는다(데이터 이전 없음). 편집기가 낸 글과 저장한 글은 늘 같다(왕복 무손실).
3. 서식 기호는 **그릴 때만** 해석한다: 집필실 미리보기·저장 버전 보기·독자 화면·EPUB 내보내기가 아래 문법으로 같은 결과를 낸다.
4. 지원하는 서식은 아래 문법뿐이다. 표·목록·코드·링크·취소선·원시 HTML 등 그 밖의 마크다운은 **글자 그대로** 보인다(Toast 편집 화면의 구문 강조가 달리 보여도 미리보기와 독자 화면이 기준이다).
5. 이 결정은 UC-10의 "굵게·기울임 등 글자 서식은 제공하지 않습니다"를 대체한다.

## 문법

본문은 `\n`으로 나눈 **줄**의 나열이다. 줄마다 위에서부터 처음 맞는 규칙 하나로 판정한다.

| 순서 | 종류 | 줄의 모양 | 비고 |
|---|---|---|---|
| 1 | 빈 줄 | 길이 0 | 공백만 있는 줄은 빈 줄이 아니라 문단 줄이다(기존과 같다) |
| 2 | 이미지 | 줄 전체가 `[[image:<UUID>]]` | 기존 규칙 그대로(`imageMarker(id) === 줄`, 소문자 `image`, 앞뒤 공백 없음) |
| 3 | 구분선 | `^(-{3,}|\*{3,})$` | 같은 문자 3개 이상만 있는 줄. 앞뒤 공백이 있으면 문단 줄 |
| 4 | 소제목 | `^#{1,6} (.*\S.*)$` | `#` 1~6개 + 공백 1개 + 비어 있지 않은 글. `#`의 개수는 구분하지 않는다(모두 같은 소제목). 툴바는 `## `을 넣는다. `#태그`처럼 공백이 없으면 문단 줄 |
| 5 | 인용 | `^> ?(.*)$` | `>` 다음의 공백 하나는 버린다. 내용이 빈 인용 줄(`>`)도 인용이다 |
| 6 | 문단 줄 | 그 밖 | |

### 줄 안의 서식 (소제목·인용·문단 줄의 내용)

- `**글**` → 굵게, `*글*` → 기울임. 서로 안에 넣을 수 있다(`***글***` = 굵게 + 기울임, `**굵게 *둘 다* 굵게**`).
- 여는 기호 바로 뒤와 닫는 기호 바로 앞은 공백이 아니어야 한다(`2 * 3 * 4`는 서식이 아니다). 안의 글은 한 글자 이상이다.
- 서식은 **한 줄 안에서만** 닫힌다. 줄을 넘는 `**…\n…**`는 글자 그대로다.
- 짝이 맞지 않는 `*`는 글자 그대로다.
- `\*`는 별표 글자다(백슬래시는 그리지 않는다). 줄 맨 앞의 `\#`·`\>`·`\-`·`\*`는 그 줄을 문단 줄로 만들고 백슬래시는 그리지 않는다. 그 밖의 백슬래시는 글자 그대로다.

판정 순서(구현 기준): 한 줄의 내용에서 왼쪽부터 다음 두 패턴 중 **먼저 시작하는 것**을 고르고(같은 자리면 굵게 먼저), 맞은 부분의 안쪽을 같은 방법으로 다시 처리한다.

```
굵게    (?<!\\)\*\*(?=\S)(.+?)(?<=\S)(?<!\\)\*\*(?!\*)
기울임  (?<![\\*])\*(?=[^\s*])(.+?)(?<=[^\s*])(?<!\\)\*(?!\*)
```

- 닫는 `**` 뒤에 `*`가 더 있으면 닫는 기호가 아니다(그래서 `***글***`의 굵게는 맨 끝 두 개로 닫히고 안쪽 `*글*`이 기울임이 된다).
- 공백(`\s`·`\S`)은 **유니코드 공백** 기준이다(전각 공백 U+3000 포함). JavaScript의 `\s`가 기준이며 Kotlin은 `(?U)`로 맞춘다.
- 글자를 그릴 때 `\*`의 백슬래시와, 줄 맨 앞 `\#`·`\>`·`\-`의 백슬래시를 뺀다.

### 블록

연속한 줄을 블록으로 묶는다(그리는 쪽이 간격을 정한다).

| 블록 | 묶는 규칙 |
|---|---|
| 문단 | 연속한 문단 줄. 빈 줄이나 다른 종류의 줄에서 끊긴다. 문단 안의 줄바꿈은 줄바꿈으로 보인다 |
| 인용 | 연속한 인용 줄 |
| 소제목 · 구분선 · 이미지 | 한 줄이 한 블록 |
| 빈 줄 | 연속한 빈 줄 n개. 블록 사이의 간격이며 n − 1줄만큼의 빈 간격을 더 둔다(빈 줄 하나는 보통의 문단 간격) |

## 화면·서버별 동작

| 곳 | 동작 |
|---|---|
| 집필실 쓰기 | Toast 마크다운 편집 영역. 기호는 보인 채로 강조된다. 이미지 표식 줄은 실제 이미지로 보인다. 이미지는 툴바 `이미지`·붙여넣기·끌어다 놓기로 넣고 기존 업로드 경로(PNG·JPEG, `vm.addImage`)를 쓴다 |
| 집필실 미리보기 · 저장 버전 보기 · 버전 비교 · 작품 관리의 '원고 보기' | 공용 `ManuscriptBody`가 위 문법으로 그린다 |
| 독자 화면 | 같은 문법으로 그리고 이미지도 보인다. 문장 선택(댓글·피드백·수정 제안)은 지금처럼 문장 단위다 |
| 문장 인용·수정 제안 | 보내는 글(`quote`·`beforeText`)은 **원문 그대로의 조각**(기호 포함)이다. 서버가 `beforeText`를 발행본에서 글자 그대로 찾기 때문이다([계약](feedback-report-suggestion-contract.md)) |
| 글자 수·공개 분량 | 지금과 같다(저장 문자열 길이, 기호 포함) |
| TXT 내보내기 | 지금과 같다(이미지 표식만 빼고 원문 그대로). 다시 가져오면 서식이 유지된다 |
| EPUB 내보내기 | 위 문법으로 그린다: 소제목 `<h2>`, 인용 `<blockquote>`(줄마다 `<p>`), 구분선 `<hr/>`, 굵게 `<strong>`, 기울임 `<em>`, 문단 줄마다 `<p>`(지금과 같음), 빈 줄은 내지 않는다(지금과 같음) |
| TXT·EPUB 가져오기 | 지금과 같다(글자만 가져온다). 가져온 글에 위 모양의 줄이 있으면 서식으로 보인다 |
| AI·검색·버전 비교의 글 | 원문 그대로 쓴다 |

## 검증 표

두 구현(TypeScript·Kotlin)의 단위 테스트가 아래 행을 모두 담는다. `B{…}` = 굵게, `I{…}` = 기울임.

| 입력 줄 | 종류 | 내용 |
|---|---|---|
| `비가 그친 새벽이었다.` | 문단 줄 | `비가 그친 새벽이었다.` |
| `**그는 돌아오지 않았다.**` | 문단 줄 | `B{그는 돌아오지 않았다.}` |
| `그는 *분명히* 말했다.` | 문단 줄 | `그는 I{분명히} 말했다.` |
| `***끝***` | 문단 줄 | `B{I{끝}}` |
| `**굵게 *둘 다* 굵게**` | 문단 줄 | `B{굵게 I{둘 다} 굵게}` |
| `2 * 3 * 4` | 문단 줄 | `2 * 3 * 4` |
| `**짝 없음` | 문단 줄 | `**짝 없음` |
| `별표 \*글자\*` | 문단 줄 | `별표 *글자*` |
| `** 공백 **` | 문단 줄 | `** 공백 **` |
| `## 1장 새벽` | 소제목 | `1장 새벽` |
| `# **굵은** 제목` | 소제목 | `B{굵은} 제목` |
| `#태그` | 문단 줄 | `#태그` |
| `## ` | 문단 줄 | `## ` |
| `\# 소제목 아님` | 문단 줄 | `# 소제목 아님` |
| `> 그가 말했다.` | 인용 | `그가 말했다.` |
| `>붙여 쓴 인용` | 인용 | `붙여 쓴 인용` |
| `>` | 인용 | (빈 글) |
| `---` | 구분선 | |
| `*****` | 구분선 | |
| `--` | 문단 줄 | `--` |
| ` ---` | 문단 줄 | ` ---` |
| `[[image:11111111-2222-3333-4444-555555555555]]` | 이미지 | id `11111111-2222-3333-4444-555555555555` |
| `앞 [[image:11111111-2222-3333-4444-555555555555]]` | 문단 줄 | 글자 그대로 |
| `- 목록 아님` | 문단 줄 | `- 목록 아님` |
| `1. 목록 아님` | 문단 줄 | `1. 목록 아님` |
| `` `코드 아님` `` | 문단 줄 | `` `코드 아님` `` |
| `<b>태그 아님</b>` | 문단 줄 | `<b>태그 아님</b>` (글자로, 이스케이프해서 그린다) |

| `a*b*c` | 문단 줄 | `aI{b}c` |
| `끝에 별표*` | 문단 줄 | `끝에 별표*` |

| `\---` | 문단 줄 | `---` |
| `\> 인용 아님` | 문단 줄 | `> 인용 아님` |
| `***` | 구분선 | |

## 한계

- 서식은 한 줄 안에서만 닫힌다. 여러 줄을 골라 굵게를 누르면 Toast가 기호를 선택 범위 양 끝에만 넣으므로 서식으로 보이지 않는다(미리보기가 글자 그대로 보여 준다).
- Toast 편집 화면의 구문 강조는 표준 마크다운 기준이라 목록·코드처럼 지원하지 않는 문법도 강조해 보일 수 있다. 실제 모양은 미리보기와 독자 화면이다.
- 기존 원고에 우연히 위 모양의 줄(`***`, `# …`, `> …`)이나 `*글*` 짝이 있으면 이번부터 서식으로 보인다.
- 피드백함·제보 목록의 인용 글은 원문 조각이라 기호가 그대로 보인다.
- EPUB 가져오기는 굵게·제목을 서식으로 되살리지 않는다(글자만).
