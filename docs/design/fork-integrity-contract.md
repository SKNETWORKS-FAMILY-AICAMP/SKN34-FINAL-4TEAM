# Fork 정합성 운영 점검 (기능 83)

- 운영 작품 목록에서 Fork의 점검을 요청한다. `GET /api/v1/operations/works/{id}/fork-integrity`는 기존 운영자 인증과 `works` 권한을 검사하고 Content 내부 API에 위임한다.
- Content는 `GET /internal/v1/works/{id}/fork-integrity`로 읽기 전용 결과만 반환한다. 원작의 현재 발행본 대신 Fork를 만들 때 고정한 원작 체크포인트의 원고 버전과 Fork의 상속 원고 버전을 SHA-256으로 비교한다.
- 회차 번호, 콘텐츠 버전 ID, 원고 버전 번호, 제목·본문·작가의 말을 비교한다. 원고 자체는 응답에 포함하지 않는다. 결과는 기준 회차, 두 해시, 일치 여부, 인물 상태 비교 상태다.
- 저장된 회차별 인물 상태가 없으므로 현재는 비교 불가다. 관계의 과거 상태, 독립 이후 설정 변경, 자동 보정은 이 점검 범위 밖이다.
