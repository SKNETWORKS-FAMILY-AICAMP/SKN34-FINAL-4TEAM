# STORYFORK ERD 문서 목차

> **논의용 초안 · 업무 DB 미구현.** 이 폴더는 기존 ERD를 전체와 업무 영역별로 읽기 쉽게 나눈 문서입니다. 세계관 공개 범위와 Fork의 업무 원칙은 [DEC-36~40](../decisions.md#결정-목록)으로 확정했으며, 그림의 테이블·속성·관계와 물리 구현은 후보입니다.

## 전체와 서비스 경계

- [전체 MVP 업무 ERD](overview.md): 회원부터 작품·Fork·AI 작업·피드백까지 연결 관계와 공통 미결 사항.
- [업무 테이블별 설명](tables.md): 전체 ERD에 그린 27개 테이블 후보의 역할·주요 항목·예시·한계.
- [AI Service 참고 — LangGraph PostgresSaver](ai-service/postgres-saver.md): 외부 라이브러리의 조사된 테이블. 도입 여부와 DB 배치는 미정.
- Frontend는 DB 정본을 소유하지 않으므로 별도의 업무 ERD가 없습니다. 관계 그래프 DB의 모델·제품은 아직 정하지 않아 이 PostgreSQL ERD와 별도로 후속 설계합니다.

## Core 업무 영역별 ERD

| 업무 영역 | 문서 | 중심 개념 |
|---|---|---|
| 회원·인증 | [회원](core/account.md) | 회원, 약관 동의 |
| 세계관·설정 | [세계관](core/world.md) | 세계관, 설정 카테고리, 설정 문서·초안·버전, 태그·현재 이미지와 공개 범위 |
| 작품·집필·발행 | [작품과 집필](core/work-and-writing.md) | 작품, 회차·원고 버전, 스토리 계획 |
| 기준점·분기 | [체크포인트와 Fork](core/fork-and-checkpoint.md) | 업무 체크포인트, 회차·설정별 버전 연결 후보, Fork |
| 독자 피드백 | [피드백](core/feedback.md) | 댓글·제보와 대상 회차 버전 |
| AI 사용의 업무 연결 | [AI 작업과 대화](core/ai-work.md) | AI 작업 기록, 제안 및 대화 소유·작품 연결 후보 |

각 업무 영역 그림은 **전체 업무 ERD의 부분 뷰**입니다. 함께 표시된 다른 영역의 엔티티는 연결을 이해하기 위한 참조이지 같은 테이블을 중복 생성한다는 뜻이 아닙니다. 공통 속성·관계를 바꾸면 전체도와 해당 부분 뷰를 함께 갱신합니다. 업무 영역 이름은 독립 배포 서비스나 실제 서비스 클래스 구성을 확정하지 않습니다.
