# 이미지 일관성 적용안과 프롬프트 예시 (#332)

2026-11-16 사용자 요청에 대한 제안이다. 모델·규격은 기존 결정을 유지한다. 아래 템플릿·참조 이미지·합성·평가 기능을 제품에 자동 적용한 것은 아니다.

## 판단

프롬프트는 그림체·소재·구도 방향을 맞추는 데 유용하지만 인물의 얼굴, 건축물의 세부 형상, 정확한 여백과 문구를 항상 같게 만드는 보장은 아니다. 공식 가이드도 반복 등장 요소의 일관성과 정밀한 배치의 한계를 명시한다. [공식 이미지 생성 가이드](https://developers.openai.com/api/docs/guides/image-generation#limitations)

이번 실검증의 초반 이미지들은 같은 텍스트 프롬프트·모델·품질·규격을 사용했다. 육안으로 비교한 작품 표지와 세계관 표지는 남청색 하늘·황동 천문탑·밝은 석조 항구라는 방향은 유사했지만, 탑의 비례·고리 구조·항구 배치가 달랐다. 이는 소수 샘플의 관찰이며 템플릿의 품질 향상률이나 동일성 보장에 대한 정량 평가가 아니다.

권장 조합은 **고정 API 규격 + 세계관별 시각 설정 + 승인된 기준 이미지 + 결과 검사 + 사용자 선택**이다. 텍스트·로고·정확한 테두리 등 픽셀 단위 규칙은 별도 합성이 적합하다.

## 현재 구현과 추가 제안

| 목표 | 현재 | 추가 적용 제안 |
|---|---|---|
| 픽셀 크기·PNG·5MiB 한도 | 서버 목적별 고정값과 실제 디코딩 검사 | 유지. 프롬프트로 용량을 보장하려 하지 않는다. |
| 모델·품질·입력의 추적 | 접수 시 모델·high·템플릿 v1·입력 스냅샷 | 시각 설정 버전·참조 이미지 식별자/해시도 접수 시 고정한다. |
| 세계관의 그림체·색상 | 사용자 장면 설명을 전달 | 고정 시각 설정과 이번 장면을 구분한 템플릿을 조립한다. |
| 반복 인물·건물의 동일성 | 텍스트 생성만 구현 | 최초 승인된 인물 시트·랜드마크 기준 이미지를 edits 입력으로 활용한다. |
| 정확한 제목·폰트·배치 | 이미지 원화만 생성 | 승인 원화 위에 정해진 폰트·좌표로 합성한다. |
| 부분 수정 후 주변 보존 | 편집 API 미구현 | 참조 이미지 편집과 마스크/markup을 검토한다. 정확히 보존할 영역은 원본과 결정적으로 합성한다. |
| 시각 품질 판정 | 규격 검사와 사용자 선택 | OCR·필수 요소 점검·기준 이미지 비교를 보조 신호로 추가하고 최종 선택은 사용자에게 둔다. |

우선순위는 ① 고정 템플릿·설정 버전 ② 기준 이미지 한 장과 편집 연결 ③ 필요한 경우만 제목 합성·품질 보조 검사다. 별도 학습이나 모델 교체는 현재 단계에서 먼저 도입하지 않는다. 새 서비스·의존성·과금 정책을 이번 문서로 확정하지 않는다.

## API 설정 경계

| purpose | size |
|---|---|
| character_profile | 1024x1024 |
| world_cover | 1152x1536 |
| work_cover | 1152x1536 |
| illustration | 1536x1024 |

공통은 `model=gpt-image-2.6-flare`, `quality=high`, `output_format=png`, `n=1`이다. 현재 코드가 이 값을 적용한다. 프롬프트의 화면비 문장은 구도를 설명하며 실제 크기는 API 설정과 서버 검증으로 정한다. 5MiB 초과 시 현재 계약대로 오류로 처리하고 자동 재생성·자동 크롭을 하지 않는다.

공식 문서상 Flare 2.6의 `complexity` 기본값은 high다. 현재 설치된 OpenAI Python SDK의 `images.generate` 명시적 인수에는 complexity가 없으므로 이번 예시는 현재 호출 코드를 유지한다. 추후 명시적으로 고정하려면 SDK 지원 또는 공식 HTTP 필드 전달 방식을 검증하고 접수 스냅샷에도 반영한다. 최신 모델로 자동 변경하지 않는다. [공식 모델 파라미터](https://developers.openai.com/api/docs/guides/image-prompting#model-parameters)

같은 요청을 다시 보여줄 때는 이미 저장한 결과 바이트를 재사용해야 한다. 같은 프롬프트를 다시 생성해 같은 그림이 나온다고 가정하지 않는다. 현재 SDK와 확인한 API 문서에서 seed 기반 재현성 계약은 확인하지 못했으므로 seed 고정을 설계 근거로 삼지 않는다.

## 고정 시각 설정 예시

아래 내용은 예시 세계관 ‘별바다’에만 적용한다. 다른 장르까지 같은 그림체로 강제하지 않는다. 사용자가 한 번 승인한 설정을 버전으로 보관하고 장면별로 임의 변경하지 않는 방식이다.

```text
설정 ID: starsea-visual-v1
매체: 회화적인 디지털 일러스트. 부드러운 붓질, 사실적인 금속·돌 질감.
색 방향: 남청색 하늘, 청록색 구름 바다, 따뜻한 황동색 조명, 밝은 석조 건물.
핵심 랜드마크: 원통형 황동 천문탑, 세 겹의 동심원 관측 고리, 흰 석조 항구.
제외 요소: 사진풍, 셀 채색, 현대 도로·자동차, 이미지 안의 글자·로고·워터마크.
표지 구도: 핵심 피사체는 중앙 아래. 상단 약 20%는 비교적 단순한 하늘.
검수: 탑 형태·색 방향·제목을 둘 공간·잘린 중요 요소를 확인한다.
```

‘20%’ 같은 위치 지시는 목표이며 보장값이 아니다. 정확한 여백이 필수이면 템플릿 캔버스 합성이나 승인된 배치 도면을 사용하고 결과를 검사한다. 특정 색상 코드 역시 이미지의 모든 조명·재질에서 동일한 RGB를 보장하지 않는다.

## 바로 입력할 수 있는 세계관 표지 프롬프트

아래는 이번 실제 생성에 사용한 예시다. 반복 생성마다 고정 블록은 유지하고 `[이번 장면]`만 바꾸는 방식으로 시작할 수 있다.

```text
[용도]
판타지 세계관의 세로 표지 원화. 글자를 합성하지 않은 그림 한 장.

[고정 시각 설정: 별바다 v1]
남청색 밤하늘과 청록색 구름 바다, 따뜻한 황동색 조명.
회화적인 디지털 일러스트, 부드러운 붓질, 사실적인 금속과 돌의 질감.
중앙의 원통형 황동 천문탑에는 세 겹의 동심원 관측 고리가 있다.
탑 아래 흰 석조 항구와 작은 비행선이 있다.

[구도]
세로 3:4 구도. 탑과 항구를 중앙 아래에 배치한다.
위쪽 약 20%는 복잡한 물체가 없는 밤하늘로 남긴다.
외곽 약 8%에는 중요한 물체가 잘리지 않게 여백을 둔다.

[이번 장면]
구름 바다 위 하늘섬의 천문항을 멀리서 바라보는 넓은 전경.
여명이 시작되는 수평선, 작은 비행선 세 척.

[제약]
사진풍이나 만화 셀 채색으로 바꾸지 않는다.
글자·제목·로고·워터마크·테두리를 넣지 않는다.
사람의 얼굴 클로즈업은 넣지 않는다.
```

## 목적별 변형 예시

다음 예시는 문안만 작성했으며 별도 인물·삽화 유료 생성이나 저장 UI 적용을 검증한 것은 아니다.

현재 화면에서 사용할 때는 위의 고정 시각 설정 내용을 실제 문장으로 함께 붙여 넣는다. `별바다 v1` 같은 이름만으로 모델이 저장된 설정을 찾아 읽지는 않는다. 추후 템플릿 조립을 구현하면 서버가 승인된 버전의 전체 문구를 삽입한다.

### 작품 표지

위 세계관 표지 프롬프트의 고정 시각 설정을 유지하고 용도·구도·장면을 다음으로 대체한다.

```text
[용도] 소설 ‘별바다의 항해사’의 세로 표지 원화.
[구도] 세로 3:4. 화면 중앙 아래에 항해사의 뒷모습, 중경에 천문탑.
상단 약 20%는 제목을 나중에 넣을 수 있는 단순한 하늘로 남긴다.
[이번 장면] 남청색 외투의 항해사가 석조 부두 끝에서 출항하는 비행선을 바라본다.
세계관 표지와 같은 새벽빛·금속 질감·색 방향을 유지한다.
[제약] 제목과 작가명은 그리지 않는다. 항해사의 외형을 임의로 새로 확정하지 않는다.
```

외형을 확정하지 않은 인물은 뒷모습 등으로 처리하거나 먼저 인물 기준 이미지를 승인하는 편이 낫다.

### 인물 프로필

```text
[용도] 성인 가상 인물 아린의 정사각형 프로필 초상. 한 명만 등장한다.
[고정 시각 설정] 별바다 v1의 붓질·재질·색 방향을 유지한다.
[인물 고정 설정: arin-v1]
23세의 성인 여성 항해사. 짧은 은회색 단발, 청록색 눈, 남청색 높은 깃 외투.
외투 중앙에 작은 황동 나침반 브로치. 담담한 표정.
[구도] 1:1, 눈높이의 정면 흉상. 머리 전체와 양쪽 어깨를 포함한다.
배경은 단순한 남청색과 청록색의 부드러운 그라데이션.
[이번 장면] 시선을 정면에 둔 기본 프로필.
[제약] 이름·문자·추가 인물·추가 장신구를 넣지 않는다.
```

이 텍스트는 첫 기준 초상 후보용이다. 다른 장면에서도 같은 얼굴이어야 한다면 이 묘사만 반복하지 말고 사용자가 승인한 초상/인물 시트를 실제 이미지 입력으로 전달한다.

### 원고 삽화

```text
[용도] 소설 한 장면을 묘사하는 가로 삽화. 말풍선과 캡션 없는 그림 한 장.
[고정 시각 설정] 별바다 v1의 붓질·재질·색 방향을 유지한다.
[인물 고정 설정] 아린은 arin-v1의 은회색 단발·청록색 눈·남청색 외투·나침반 브로치를 유지한다.
[구도] 3:2 가로. 왼쪽에는 아린의 상반신, 오른쪽 중경에는 천문탑과 비행선.
[이번 장면] 아린이 석조 부두에서 펼친 해도를 바라본다. 해도에는 읽을 수 있는 글자를 넣지 않는다.
카메라는 눈높이, 조명은 부드러운 새벽 역광.
[제약] 승인된 설정에 없는 인물·장신구·사건을 추가하지 않는다. 회차 이후의 장면을 암시하지 않는다.
```

## 기준 이미지를 활용할 때의 편집 프롬프트

현재 구현은 `images.generate`의 텍스트 입력이다. 아래 문구만 붙여도 참조 이미지가 전달되는 것은 아니다. **실제 이미지 입력을 지원하는 `images.edit` 경로와 소유권 검증이 추가돼야 한다.** 참조 1은 승인 인물, 참조 2는 승인된 그림체/배경처럼 역할을 구분한다. [공식 참조 이미지·편집 가이드](https://developers.openai.com/api/docs/guides/image-generation#create-a-new-image-using-image-references)

```text
[입력 이미지 역할]
이미지 1은 승인된 아린의 얼굴과 복장 기준이다.
이미지 2는 별바다 세계관의 색 방향과 천문항 배경 기준이다.

[유지할 것]
이미지 1의 얼굴 비례, 헤어라인, 머리 길이, 눈 색, 외투 형태와 브로치를 유지한다.
이미지 2의 천문탑 구조와 회화적 질감을 유지한다.

[바꿀 것]
아린의 자세만 해도를 펼쳐 내려다보는 모습으로 바꾼다.
이미지 2의 석조 부두에 인물을 배치하고 새벽 조명에 맞춘다.

[출력 제약]
가로 3:2 삽화. 새 인물·장신구·글자·로고를 추가하지 않는다.
```

Flare 2.6 편집에는 `input_fidelity`를 생략한다. SDK에 그 인수가 있어도 모든 모델이 사용하는 설정은 아니다. 마스크/markup도 주변 픽셀 보존을 보장하지 않으므로, 엄밀한 보존이 필요하면 승인한 편집 부분만 원본에 합성한다. [공식 프롬프팅 가이드](https://developers.openai.com/api/docs/guides/image-prompting)

## 최소 적용·평가 방법

1. 승인된 시각 설정 한 버전과 대표 기준 이미지부터 정한다. 장면 텍스트와 고정 설정의 충돌은 접수 전에 확인한다.
2. 템플릿 버전, 설정 버전, 허용된 참조 이미지 ID/해시, 모델·품질·규격을 작업 입력에 고정한다. 임의 외부 URL 대신 소유권을 검증한 첨부를 사용한다.
3. 대표 장면 5개를 같은 조건으로 각 3회 생성하는 소규모 평가안을 별도 비용 범위로 잡는다. 이번 부하 검증의 생성 시도 6회(성공 4회·중단 2회)가 이 평가를 대신하지는 않는다.
4. 규격은 자동 검사한다. 인물 특징·랜드마크·제목 여백·불필요한 글자는 체크리스트와 사람의 확인을 함께 쓴다. 이미지 유사도나 비전 모델의 점수 하나만으로 동일 인물이라고 확정하지 않는다.
5. 채택률·허용 불가 오류·응답 시간·채택된 이미지당 비용을 비교한다. 실패할 때 무제한 자동 재생성하지 않고 기존 명시적 재생성 계약을 유지한다.

이 단계에서 권장하는 제품 변경은 템플릿 조립·시각 설정 버전·승인 기준 이미지 연결까지다. 추가 검사·합성은 실제 요구가 있는 항목부터 적용하며, 본 문서에서는 코드나 운영 정책을 확정하지 않았다.
