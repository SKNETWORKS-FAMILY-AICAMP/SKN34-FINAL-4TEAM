Refs #48. 실제 인증, PostgreSQL, 고정 카테고리 정책, 항목·회차 공개 범위, 이미지·URL, 초안 자동저장, 이력 복원 UI는 미구현입니다. #48 전체 해결로 표시하지 않습니다. #49의 작품 생성과 세계관 단일 선택 정책은 범위 밖입니다.
