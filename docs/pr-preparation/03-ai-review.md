# feat: 선택적 세계관 분석과 후보 승인 분리

확정 저장과 AI 제안을 분리합니다. 저장한 원문을 선택적으로 분석하고 후보를 수정·선택·승인해야 확정 설정에 반영합니다.

- 변경·동작: 기존 initial-content-4-minimal 전처리 경계·검증 계약을 재사용한 Core client, 후보/확정 데이터 분리, 명시적 승인, ID 연결, 실패 진단·원응답 보존과 중단 복구.
- 결정: 기본 AI 비활성화이며 동의가 있어야 요청합니다. 작가 분류·태그와 LLM topics는 구분합니다. 실패를 성공 후보로 바꾸지 않습니다.
- 한계·남은 일: 신규 유료 호출은 실행하지 않았습니다. Core client와 DTO 스텁 검증을 실제 모델/AI 전처리의 품질 검증으로 표현하지 않습니다. Wiki·관계·시간선 표시는 다음 PR입니다.
- 검증: 성공 후보 수정/승인, 422 검증 실패, 기존 확정 데이터 보존, 중복 승인·충돌·중단 분석 복구 테스트. 전체 구현에서 Core 관련 11개·프런트 42개 테스트와 Aside 성공/실패 시나리오 검증. 이 분리 중간 단계 자체 빌드는 미실행이며 후속 공유 전 필요합니다.
- 한 줄 요약: AI는 후보를 제안하고 작가가 확정합니다.

AI 후속 단위는 최신 AI Service에 opt-in 라우트도 연결했다. 기존 semantic/knowledge/minimal/minimal_validation 모듈을 변경 없이 재사용하고 초기 세계관 endpoint만 등록했다. 라우트 on/off·실제 전처리·SDK HTTP mock·422 오류·Health 관련 테스트 13개가 통과했다. 실제 제공사 호출은 0회이며 브라우저는 별도 DTO 스텁, AI 프로세스 내부 계약은 pytest HTTP mock으로 검증한 범위를 구분한다. 직접 저장 요청의 임의 AI 출처는 작가 입력으로 정규화하도록 추가 회귀 테스트를 넣어 Core 최종 11개가 통과했다. 첫 단위의 코드·검증 결과에는 이 AI 변경이 포함되지 않는다.

현재 독립 검증: 진행 중. 이전 통합본 결과는 이 단위의 독립 빌드/테스트 통과로 대체하지 않습니다. 원격 CI는 아직 확인하지 않았습니다.
