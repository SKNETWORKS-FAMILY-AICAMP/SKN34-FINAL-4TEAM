# feat: 확정 세계관 설정집·관계·시간선 표시

작성 중 편집과 AI 후보를 확정 데이터와 분리하여 설정집·관계 목록·초기 역사 시간선에 표시합니다. 부정 관계는 `적대 아님`처럼 부정 여부를 표시합니다. 승인 전 후보가 보이지 않고 승인 후 표시되며, 이후 분석 실패에도 기존 설정이 남는 회귀 테스트를 포함합니다.

관계는 목록 표시이며 그래프 DB나 물리 스키마를 확정하지 않습니다. 회차별 공개·상태·지식·Fork 동기화는 미구현입니다. 01·02·03 이후 적용하는 순차 PR입니다.

검증 상세와 남은 조건은 [독립 검증 보고](../world-studio-validation.md)를 참고합니다. 원격 Required CI는 미실행이며, PR 생성·병합은 하지 않았습니다.

최신 develop 기준 해당 단계만 구성한 독립 소스에서 관련 프런트 44개·Core 67개·AI 13개 테스트와 타입 검사·린트·빌드를 통과했습니다. 기존 develop 목업 테스트 4개 실패는 별도 보고에 기록합니다.
