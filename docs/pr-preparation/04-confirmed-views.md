# feat: 확정 세계관 Wiki와 관계·시간선 표시

저장 중인 편집과 미확정 AI 후보를 확정 화면에 섞지 않고, 작가가 확정 저장한 설정만 Wiki·관계·시간선에 표시합니다.

- 변경·동작: 확정 settings 기반 원본 이름의 설정집·인물 관계도·초기 역사 시간선 탭과 읽기 화면 세 개을 추가합니다. AI 결과 수신만으로 표시하지 않습니다.
- 결정: 관계는 확정 관계 목록으로 표시합니다. 관계 그래프 DB 제품·물리 스키마는 확정하지 않습니다.
- 한계·남은 일: 그래프 DB, 회차별 상태·지식·공개 시점·Fork 동기화 미구현. 관계 양성 자료와 픽셀 QA는 미검증입니다. Aside screenshot이 CDP timeout으로 실패했습니다.
- 검증: 전체 구현에서 승인 전/후 settings 분리, Wiki의 실패 후 보존, 승인 사건의 시간선 표시와 관계 빈 상태를 확인했습니다. 단독 분리 빌드는 후속 공유 전 필요하며 원격 CI는 검증 대기입니다.
- 한 줄 요약: 확정한 세계관만 읽기 화면에 표시합니다.

현재 독립 검증: 진행 중. 이전 통합본 결과는 이 단위의 독립 빌드/테스트 통과로 대체하지 않습니다. 원격 CI는 아직 확인하지 않았습니다.
