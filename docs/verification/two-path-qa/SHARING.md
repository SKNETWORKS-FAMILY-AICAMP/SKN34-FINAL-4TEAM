## 구현 범위

- 최초 구축 요청의 전체 회차·원문 버전·해시 고정.
- AI 추출·정체 통합·구조화와 Content 저장 연결.
- 기존 WorldStudio PostgreSQL의 V9 job/result/load_step, 성공 회차 결과 재사용, 동일 요청 복구.
- 기존 카드/인물 문서/Neo4j DEC-51 관계의 초안 적재와 원문 출처 보존.
- 첫 등장 회차와 독자 공개 회차 분리, 자동 생성 결과 기본 비공개.
- 작품 관리의 명시적 동의·시작·상태·재개, 기존 WorldStudio 수정·확정 화면 연결.

AI 제공사 대역으로 검증했다. 유료 모델 호출·신규 회차 자동 증분 갱신·운영 DB 수정은 수행하지 않았다. 제품 실행 플래그는 기본 비활성이며 QA에서만 활성화했다.

## 검증 자료 읽기

보고서에 실제 실행한 테스트와 미검증 범위를 구분했다. 이전 실행 XML과 Red 단계 XML도 있으므로 전체 디렉터리 합계를 최신 테스트 수로 사용하지 않는다.
HTTP/DB JSON과 브라우저 스냅샷은 합성 QA 데이터다. 인증 토큰/쿠키/실제 비밀번호는 담지 않는다. Compose의 자격 값은 격리 QA용 고정값이다.
자동 생성 Gradle HTML 보고서 및 binary 결과는 공유에서 제외하고 로컬에 보존했다. 코드·Fixture·실행 스크립트·JUnit XML·HTTP/DB 증거는 포함했다.

## 검토할 경계

- 최초 구축 이후 신규 회차 자동 갱신은 제외.
- 기존 카드가 있는 세계관의 자동 정체 병합은 지원하지 않음.
- 다른 브라우저에서 원래 요청 key가 없는 작업 재개는 제한.
- 실행 중 강제 종료, 실배포, 실모델 품질, 모바일 시각 QA 및 장편 성능은 별도 검증 필요.
- 작가 확정은 별도 동작이며 자동 적재가 공개·발행을 대신하지 않음.

이번 공유에서는 PR 생성·병합·배포하지 않는다.
