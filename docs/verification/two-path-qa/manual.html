새 이름에 수동QA-1117-을 붙이세요. 기존 QA 작품·세계관은 지우거나 덮어쓰지 마세요. 이 안내는 등록·분석·승인·확정을 자동 실행하지 않습니다.

1. 직접 등록

  1. 세계관 작업실에서 빈 세계관을 만들고 인물 홍길동, 조직 활빈당, 장소 율도국을 각각 하나씩 등록합니다.
  2. 홍길동의 본문(IDENTITY)에 아래 원문을 그대로 넣습니다. 다른 카드나 세계관 설명에 같은 문장을 반복해서 넣지 마세요. 조직·장소 설명은 짧은 별도 문장으로 작성합니다.
  3. 초안을 저장한 후 AI 후보 검토에서 저장된 초안을 분석합니다. 별도의 설정집 AI 검토·집필 AI 채팅은 이번 대역 대상이 아닙니다.
  4. 7종 후보를 검토합니다. 수정본은 다시 승인해야 합니다. 보류·거절한 후보는 반영할 수 없습니다.
  5. 반영할 후보를 모두 검토한 뒤 승인 후보를 선택해 초안에 함께 반영합니다. 일부 반영 후 나머지 분석은 stale이 될 수 있습니다.
  6. 서버 재조회 결과를 확인하고 카드를 편집·저장합니다. 확정 버전 생성은 별도로 누릅니다. 확정은 작품 공개가 아닙니다.

2. 원고 기반 최초 구축

  1. 별도의 빈 QA 작품을 만듭니다. 아래 4개 TXT를 회차 일괄 업로드로 1화부터 순서대로 저장합니다. 발행하지 않습니다.
  2. 작품 관리의 세계관 만들기에서 직접 시작합니다. 업로드만으로 분석은 시작되지 않습니다.
  3. 진행 상태를 확인합니다. 실패·미확인 상태는 화면의 동일 작업 재개로 처리하고 중복 새 작업을 만들지 않습니다.
  4. 완료 후 세계관 초안을 열어 인물 문서·카드·관계를 확인하고 직접 수정·저장·확정합니다.
