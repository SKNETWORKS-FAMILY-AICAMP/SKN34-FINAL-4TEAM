|---|---|---|---|---|---|---|

Fork 작품은 원작에서 받은 고정 세계관도 5개에 포함하고, Fork 전용 세계관은 분기 이후 첫 회차 발행 뒤에도 5개 안에서 추가 가능(v7 확정). | [UC-24](usecase-spec/UC-24.md), [UC-05](usecase-spec/UC-05.md) | 기획 초안 / 개발 계약 미확정 | 미구현 |
| <a id="f-wld-04"></a>F-WLD-04 | 회차 구성 및 관리 | 작품을 회차별로 구성하고 각 회차의 원고와 관련 인물·장소·사건을 등록·수정할 수 있어야 합니다. | 회차 원고와 작품별 회차 기록(설정 유효·독자 공개·인물별 인지 회차, 작품별 인물 상태, @ 연결)은 DB에 저장하고 세계관 항목 ID를 참조, 커밋 ID 고정은 Fork·이용 허가 철회 시점에만(v7 확정). | [UC-24](usecase-spec/UC-24.md), [UC-10](usecase-spec/UC-10.md), [UC-13](usecase-spec/UC-13.md) | 기획 초안 / 개발 계약 미확정 | 미구현 |

| <a id="f-wld-06"></a>F-WLD-06 | 원고 기반 설정 추출 | AI는 권리 제한이 없는 회차 원고에서 세계관·장소·인물·관계·사건·규칙 후보와 근거, 공개 전환 후보를 제시하고 불명확하거나 충돌하는 항목을 구분해야 합니다. 작가 요청 시(수동, 기본값) 실행합니다. 작품 설정이 자동이면 새 회차 발행 때 자동 반영하고, 이미 발행한 회차를 작가가 다시 발행하면 추출 후 작가가 확인한 항목만 반영합니다. 피드백 수정안 반영에 따른 재발행은 실행 대상이 아닙니다. | 자동 모드 크레딧은 작품 소유자 부담.
