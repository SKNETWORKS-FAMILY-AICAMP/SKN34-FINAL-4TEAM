# 펜시브 조사 출처와 검증 범위

조사일: 2026년 11월 2일, 한국 시간. 공개 홈페이지·공식 문서·블로그·변경 이력을 Aside로 읽었다. 아래는 공식 출처 색인이며, 앱 동작을 실행해 검증한 결과와 구분한다.

## 확인 범위

- 한국어 공식 문서 목차 100개 URL을 수집하고 영역별 본문을 조사했다. 영어 공식 문서 100개 본문도 대조했다.
- 공식 변경 이력의 공지 53건, 블로그 목록에 노출된 12편 전체, 공개 플러그인 14개 상세를 조사했다.
- 블로그의 페이지 이동·더보기는 관찰하지 못했다. 비노출 글까지 없다는 뜻은 아니다.
- 웹 앱·대시보드는 로그인 화면까지 확인했다. 로그인·가입·결제·설치·원고 편집·AI 실행은 하지 않았다.
- 홈페이지 움직이는 제품 화면은 홍보 시연이다. 회사의 기능·보안·성능 주장은 독립 검증으로 표현하지 않는다.
- 원문 전체 덤프·개인 작업 경로·브라우저 세션 기록은 팀 공유본에서 제외했다. 문서별 근거는 아래 공식 링크에서 확인할 수 있다.
