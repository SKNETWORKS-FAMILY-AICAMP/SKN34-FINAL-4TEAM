# 펜시브 기능 조사와 STORYFORK 적용 제안

조사일: 2026년 11월 2일. 펜시브의 원고·설정·플롯·AI 기능을 살펴보고 STORYFORK에 참고할 사용자 흐름과 우선순위를 정리했다. 경쟁제품 조사 자료이며 MVP 범위나 확정 정책을 변경하지 않는다.

## 팀에서 검토할 핵심

- 원고 옆에서 설정 검색·참고 → AI 문맥 확인 → 변경안·근거 비교와 채택 → 확정 버전 관리 → 플롯 연결 순서로 검토한다.
- 펜시브 블로그는 자동 모순 감지·등장 기록 자동 추적·관계 변화 추적을 제품 기능으로 설명한다. 실제 실행 방식·정확도는 미검증이므로 제공 주장과 실측 결과를 구분한다.
- 세계관·AI·그래프·모순 검사 자체를 STORYFORK만의 기능으로 설명하지 않는다. 기준 회차·공개 범위·인물 지식과 독자 Fork의 독립·원본 변경 선택 반영을 함께 비교한다.
- [최신 MVP 설계](../../design/design.md)와 [결정 기록](../../design/decisions.md)이 제품 범위의 기준이다. 이 조사에서 나온 아이디어를 자동으로 구현 계약에 추가하지 않는다.

로그인 이후 편집·생성·복원은 실행하지 않았다. 가격·모델·플랜과 문서 내용은 조사 이후 바뀔 수 있다. 기능별 출처와 제한을 함께 읽는다.
