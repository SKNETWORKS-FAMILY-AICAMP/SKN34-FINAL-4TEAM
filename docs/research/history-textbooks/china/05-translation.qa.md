## 인명·지명과 역사적 주장 검토 대기

아래는 원문 대조 중 별도 검증이 필요하다고 판단한 항목이다. 외부 현대 사료를 확인해 사실 판정을 마친 목록이 아니다. 원문의 주장과 번역상의 결정을 분리하기 위해 적었으며 본문에서 연대·지명·계보를 몰래 교정하지 않았다.

1. **기원·계보·어원(02–06):** “몽골=용감한 사람들”, 몽골·흉노·아틸라의 혈연, 칭기즈 출생 일화와 13세/4만 가구, 칭기즈 칸의 의미·한자·하늘의 새 등은 현대 언어학·사료 검증이 필요하다. 부단차르·쿠툴라/쿠블라이와 후대 쿠빌라이를 혼동하지 않도록 원문 음역을 병기했다.
2. **초원·중국 지리(02, 06, 09, 12):** 오논과 케룰렌을 모두 아무르의 지류/상류로 서술한 부분, 나이만의 톈산·중가리아 배치, 케룰렌강의 카라코룸, 금 수도 둥징과 옌징의 관계 등은 검토 대기다. Shensi와 Shansi는 서로 다른 지명이나 한국어 표기가 “산시”로 겹치므로 해당 문단에서 원문 철자를 병기했다. 현대 좌표·행정구역으로 임의 확정하지 않았다.

10. **티베트 불교(30–31):** 중국인의 종교적 불신, 동아시아의 유일하게 활력 있는 종교, 인도 브라만교와 티베트 불교 중심지 관계, Sanpou·Pakba 및 종교 권위 수립 설명은 종교사 검토가 필요하다. 당대 시점의 “현재”를 오늘날 사실로 읽지 않는다.
11. **송 말기 전쟁(32–38):** 1263년 전쟁 포고와 이탄·이종 사망의 순서, 1268년 출전/3년 경과/1270년 보급 원정의 연대 관계, 160파운드 투석기와 페르시아 기술자, 장구이·장순의 역할, 공종·섭정 황후의 관계, 창저우 학살, 타이섬과 통킹 지원 등은 원사료 대조가 필요하다. 연대 충돌처럼 보이는 대목을 임의로 정리하지 않았다.
12. **결말(39):** “반세기”와 “70년 전”은 저자의 기간 계산을 보존한 것이지 현대적으로 재계산한 수치가 아니다. 중국인들의 저항을 칭찬하면서도 “활력 없는 대중”, 무능한 장군 등으로 일반화하는 원문의 상충하는 관점도 그대로 두었다.

## 번역 원칙과 남은 검수

- 일부 널리 쓰이는 인명은 칭기즈·쿠빌라이·몽케·여문환·가사도·장세걸·육수부 등으로 옮기고 첫 출현에 옛 철자를 병기했다. 식별이 불확실한 이름은 원문 중심 음역을 유지했다. 동일 인물·다른 음역의 통일 여부는 전문 검수 때 재확인해야 한다.
- 원문 직접 인용은 한국어 인용으로 유지했다. 이는 인용 발언의 실제 역사적 진위를 보증하지 않는다. 정크선·투석기·형구 등 용어도 문맥 기준 초안이다.
- 절·문장 내부의 정보는 자연스러운 한국어 어순으로 옮겼으나 원문의 문단 경계를 합치거나 나누지 않았다. 인용 속 괄호 설명은 인용의 바로 옆 또는 같은 문단에서 풀어 썼다.
- 독립 검수자는 원문 39문단을 다시 문장 단위로 대조하고, 인명 대응·날짜·계보·항복과 학살 묘사·종교 관련 표현·옛 단위와 무기 명칭을 점검해야 한다. 본 초안은 교육용 현대 통사의 정본으로 승인된 자료가 아니다.
- 변경 범위는 신규 번역 파일과 이 신규 QA 파일뿐이다. 영어 원문, 기존 번역, 세계관 후보, README, 앱·데이터베이스는 이 작업에서 수정하지 않았다. 커밋·푸시도 하지 않았다.
- 이 환경의 `git status`는 “this operation must be run in a work tree”로 실패했다. Git 차이 검증이 통과했다고 주장하지 않는다. 지정 파일 경로 직접 읽기·쓰기 및 원문 해시 재확인으로 작업 범위를 점검했다.
