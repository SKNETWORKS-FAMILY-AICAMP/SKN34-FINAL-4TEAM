# 11장 통합 대조초안 · 반영 및 보존 검증

검증일: 2026-11-13. 대상: [integrated-11-chapters.ko.collated-draft.md](integrated-11-chapters.ko.collated-draft.md). 이 작업은 기존 이미지 판독 복구기록을 엄격하게 병합한 단계이며, 새 역사 감수나 전 페이지 이미지 재검수를 수행한 단계가 아니다.

## 결과

- 11장 157절: 1장 12절 / 2장 14절 / 3장 15절 / 4장 12절 / 5장 15절 / 6장 15절 / 7장 17절 / 8장 13절 / 9장 14절 / 10장 14절 / 11장 16절. 번호·순서·장 개요를 보존했다.
- 제2~9장 본문 추정 63곳을 기록별 1:1 치환했다. 내부 판독 불가 1곳(05-10)은 63곳에 포함된다. 제6장 제10절 표제는 동일 문구 그대로이며 직접 판독 확인만 추가했다.
- 입력 복구 audit의 원문·복구파일·기존 번역·기존 QA 해시와 종전 manifest의 장별 파일 해시가 모두 일치했다. 입력 43개 파일은 작업 전후 SHA-256 동일성을 검사한다. README와 manifest만 현재 상태에 맞게 수정하며 보호 파일 목록에서 제외한다.
- 원문 바이트열에서 번역 구간을 추출했다. 제1장의 작업 머리말·중간 검토 메모, 제2~3장의 번역 범위 종료문, 각 장의 과거 상태 설명은 새 안내로 정리했다. 삭제한 것은 번역 본문이 아닌 작업 메타데이터이며 원본 파일에서 그대로 확인할 수 있다.
- 모든 비변경 구간의 UTF-8 바이트 해시와 문자열 동일성을 검사했다. 63개 치환을 역적용하면 추출된 기존 번역 구간과 정확히 같아진다. 기존 혼합 줄바꿈도 비변경 구간에서는 유지했다. 원래 절 제목의 Markdown 수준 차이도 보존했다.
- 제2장 기존 집계 12는 머리말의 예시 표지를 포함했다. 본문은 11곳이며 manifest는 11로 정정하고 근거를 기록했다.
- 연대표 4쪽·91행은 원파일 전체를 부록에 바이트 동일하게 붙였다. 원서 표제·별도 목차·지도목록은 [별도 대조초안](frontmatter-and-map-list.ko.draft.md)에, 인쇄 색인 550항목은 [영문·한국어 대조초안](printed-index.en-ko.draft.md)에 작성되어 있다. 실제 지도 도판과 내부 전체 지명·범례, 출판사 광고는 이 통합본에 포함하지 않았으며 내부 문자와 광고는 미번역이다.
- UTF-8 엄격 디코딩, 대체문자(U+FFFD) 0개, NUL 0개를 확인한다. 기계 검증 상세와 SHA-256은 [integrated-11-chapters-audit.json](integrated-11-chapters-audit.json)에 있다.
- 원본 제1~9장에 남아 있는 과거 상태와 제2~9장의 손상 표지는 지우지 않았다. 통합본의 지정 복구 구간에서 미해결 손상 표지는 0개이지만, 이 결과는 전체 무오류·역사 정본·확정 완역 판정이 아니다. 전문 역사 감수, 독립 문장별 번역 검토, 최종 교열은 미완료다.

## 머리말 상태 안내 갱신 (2026-11-13)

완료된 [원저 표제·목차·지도목록](frontmatter-and-map-list.ko.draft.md)과 [550항목 색인](printed-index.en-ko.draft.md)을 안내하도록 통합본의 머리말 한 문장만 바꾸고 링크를 추가했다. 지도 도판 이미지·내부 전체 지명·범례와 광고는 제외 상태를 유지한다. 부속 파일, 11장 본문, 63개 복구 문단과 연대표를 수정하지 않았다.
제1장 앵커부터 파일 끝까지 564,418바이트가 수정 전후 완전히 같다. 이 보존 구간의 SHA-256은 `2A16183A573995FDF9FF4C889EB625BB4A2CADABEF8C05B180C06BB1CE6621C6`이다. 각 장 본문 해시 11개, 복구 구간 해시 63개, 비변경 구간 해시 74개와 연대표 원파일 일치도 다시 확인했다.
머리말 길이 변화로 파일 전체 기준 UTF-16 좌표는 +221만큼 이동했다. audit의 장별 절대 좌표 11쌍과 연대표 좌표만 이동하고, 장 내부 상대 좌표·본문 해시는 유지했다. 통합 파일·QA·audit의 현재 크기와 SHA-256은 manifest에 갱신했다. 앞선 부속 번역 audit의 통합 파일 해시는 당시 작업 전후의 보존 증거이며 이번 머리말 수정 이전 상태를 기록한다.

## 63개 본문 복구 전후

각 항목의 “변경 전”은 실제 기존 번역의 정확한 치환 범위이며 “변경 후”는 복구기록의 수정 한국어 첫 문단과 동일하다. 복구기록의 영문, 판독 결과, 변경 요점과 남은 불확실성은 근거 링크에서 확인한다. 제3장 이전 표시가 생략형인 경우 고유 접두어·장·절·출현 순서를 함께 검증했다.

변경 전:

## 범위와 한계

476~1870년 및 1874년 당시 평가를 다루는 19세기 원저의 연구 초안이다. 현대사는 없고 원저 편향·사실 오류 가능성을 보존한다. 문자 결손 해소와 역사 정본은 다르다. 전면 양 스캔 교정, 전문 역사 감수와 최종 한국어 교열은 미완료다. 원서 표제·목차·지도목록 및 인쇄 색인 550항목은 별도 대조초안으로 제공한다. 실제 지도 이미지·지도 내부 전체 지명·범례와 출판사 광고는 제외하며 내부 문자와 광고는 미번역이다. 파생 창작 세계관 두 파일은 역사 서술과 구분하고 본문에 병합하지 않았다. 외부 업로드·커밋·푸시·앱·DB 통합을 하지 않았다.
