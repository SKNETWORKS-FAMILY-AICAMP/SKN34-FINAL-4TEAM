# 『History of Italy』 연대표 한국어 번역 초안

William Hunt, 1883년 제2판. 원서 앞부분 CHRONOLOGICAL TABLE 전체, 토론토 스캔 PDF11–14쪽을 직접 시각 대조했다. 날짜와 사건 배치는 원저 그대로이며 현대 역사학의 검증된 연대표로 제시하지 않는다. 여러 사건을 하나의 중괄호로 묶은 행은 같은 연도 칸에 함께 옮겼다. 본문 11장과 별개인 부속자료다. 역사 감수와 최종 교열은 미완료다.

## 번역과 검수 경계

- ‘바빌론 유수’는 교황청의 아비뇽 시기를 가리키는 원저의 명칭이다. 고대 유대인의 사건과 혼동하지 않는다.
- ‘예속시킴’, ‘해방’, ‘성상파괴자’, ‘침입’ 등은 원저의 제목 표현이다. 현대 연구로 동일한 평가를 확정했다는 뜻이 아니다.
- 1154·1376·1415·1684·1718·1833 등은 사건의 정확한 날짜, 시작과 종결, 책 본문과의 관계를 별도 검토해야 한다. 표의 숫자를 임의로 현대 연표에 맞추지 않았다.
- PDF12의 1310년 행은 OCR에서 Henry가 빠졌으나 이미지에 Henry VII.가 있어 ‘하인리히7세’로 옮겼다. OCR에서 빠지거나 위치가 흐트러진 1409·1509·1684·1713년은 이미지의 중괄호와 연도 칸으로 판독했다.
- 행 번호나 날짜를 새로 보충하지 않았다. 중괄호를 세미콜론으로 펼친 것 외에는 사건 순서를 바꾸지 않았다. 원본 PDF와 텍스트는 보존했다.
