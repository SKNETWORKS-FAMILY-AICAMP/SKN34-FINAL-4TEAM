## 구조·수치 검증 결과

실제 파일을 다시 읽어 아래 조건을 검사했으며 모두 통과했다.

- 색인 원문 블록 1,212개와 EN 1,212개가 순서대로 일치한다. EN은 물리적 줄바꿈·연속 공백만 하나의 공백으로 합친다. 철자·구두점·밑줄·참조 숫자는 바꾸지 않는다.
- KO도 1,212개이며 모두 한국어 텍스트가 있다. 식별자는 I0001부터 I1212까지 중복·누락 없이 연속이다.
- 숫자 및 숫자 범위 토큰 2,623개가 각 EN/KO 쌍에서 순서·중복·범위 표기까지 일치한다. I1180의 728-31 같은 축약 범위도 확장하거나 누락하지 않았다.
- 로마숫자 토큰 393개가 각 쌍에서 일치한다. 계속 항목에 편집자가 보충한 부모 왕호는 비교에서 제외했다.
- ---- 반복 표제어 235개를 모두 EN과 KO에 보존했다. KO에는 반복 대상의 이름·칭호도 보충했으므로 다른 인물의 항목과 합치지 않았다.
- 교차참조가 있는 50개 블록의 참조 지시 51회를 모두 보존했다. 한국어 대상명과 원래 영어 표제어를 병기했다. 왕들의 이름을 보라는 포괄 참조도 유지했다.
- 세미콜론 1,154개가 각 쌍에서 일치한다. 이는 하위항목 분절을 빠뜨리지 않았는지 확인하는 보조 검사이지 의미 정확성을 보증하는 시험은 아니다.
- 앞부분의 원목차 45개, 지도·도면 30개, 계보표 9개에 EN/KO 대조행이 각각 정확히 대응하며 쪽수·연도·범위를 대조했다. EIGHTH→8, EIGHTEENTH→18의 표기 변환만 정규화한 뒤 검사했다.
- 표제지 영어 블록이 원문 52–80행과 일치하는지 검사했고 저자 소개·저서·판수·발행지·발행사·발행연도·인쇄사·인쇄지를 한국어에 모두 넣었다.
- 원문 파일은 1,881,002바이트, SHA-256 74C6692775FDD51D7E8F2814C5FE0C26D41221E6DA790108DD895E6CD3E314A4로 작업 시작 때의 값과 동일하다.
- UTF-8로 저장하고 다시 읽었다. 새 파일 외의 본문·기존 QA에 대한 변경은 하지 않았다. 문서만 추가했으므로 앱 단위테스트·빌드·브라우저 테스트는 실행 대상이 아니며 실행하지 않았다.

## 번역 자체 점검·표기

- 각 항목을 원문 전체와 대조해 설명구와 하위항목을 옮겼다. 일반명사·직함·동작·다른 항목 참조를 표제어 음역만으로 대신하지 않았다.
- 국왕의 이름 뒤에는 원문의 로마숫자를 그대로 사용했다. 이는 본문에서 쓰는 아라비아숫자 왕호와 편집 형식이 다르지만 왕의 식별값을 보존하기 위한 대조용 선택이다.
- 현재 제1·12장 파일 및 초기 왕국·중세·근현대 관련 장을 읽어 고유명을 참고했다. 특히 장로왕 에드워드, 앨프레드, 앨프스리스, 에아드가·에아드위그·에아드레드·에아드위네·에아드리크, 체르디치, 스벤, 모르카르, 하랄드 하르드라다 등은 기존 본문 표기를 반영했다.
- 프랑스의 Henry는 앙리, 스페인의 Henry는 엔리케로 옮기되 EN에 원철자를 남겼다. Charles·Philip도 국가별로 찰스/샤를/카를/카를로스, 필리프/펠리페 등을 구별했다.
- 고유명 전체의 단일 표준화나 인물 식별을 확정한 것은 아니다. 영문 표제어를 모든 항목에 보존했으므로 아직 검토가 필요한 음역도 원문으로 추적할 수 있다.
- 식민지 시대 명칭 Kaffir wars, ‘잔학행위’·‘정복’·‘해적 같은 습격’ 등 평가적 서술은 원저의 말이다. 현대의 공식 명칭이나 번역자의 판단이라고 제시하지 않는다.

## 남은 범위와 사용 제한

- 원저의 역사 서술 종점은 1902년이다. 현대 영국사의 공백은 번역 누락이 아니라 원저의 범위 밖이며 별도 자료가 필요하다.
- 독립적인 전문 번역·역사 감수, 원인쇄본 이미지와의 위치·쪽수 대조, 고유명 전권 통일은 미완료다.
- 지도·삽화 이미지와 지도 내부 문자, 계보표 도형 자체를 이번에 새로 편집하거나 번역하지 않았다. 해당 본문 파일의 표·캡션 처리와 이 부속 목록 번역을 구별한다.
- 출판사 광고와 전사자 주·PG 배포 고지의 한국어 번역은 제외했다. 원문에서 삭제하거나 원저 색인과 합치지 않았다.
- 앱 DB 반영, Git 조회·커밋·푸시, README 변경은 하지 않았다.
