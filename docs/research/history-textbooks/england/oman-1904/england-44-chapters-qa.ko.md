# Oman 1904 서문·44장 통합 QA

- 작성일: 2026-11-13 (UTC).
- 대상: [england-44-chapters.ko.draft.md](england-44-chapters.ko.draft.md). 서문 두 편과 제1–44장 단독 번역 파일을 보존한 연속 읽기용 초안이다.
- 결론: 입력 45개 모두 전체 문자열이 정확히 1회 포함되고 각 원본 바이트와 대응 구간이 동일하다. 순서는 서문 파일 1개, 제1–44장이다. 전수 의미 감수나 현대 역사적 사실 인증이 아니다.
- 통합본: 1986614바이트. SHA-256: 68C5DBD3943F0E946C13B7613477194BC3063FB6E6C33C4CD5741FA12153A5D9.
- 상세 입력·구간·해시·장별 개수·불변 파일: [england-44-chapters.manifest.json](england-44-chapters.manifest.json).

## 입력 고정과 제외 범위

원문 source-en.txt는 1,881,002바이트, SHA-256 74C6692775FDD51D7E8F2814C5FE0C26D41221E6DA790108DD895E6CD3E314A4 로 통합 전후 전체 바이트가 같다. source-manifest.json, 단독 초안 45개, 기존 장별 QA 41개, 독립 표본 검토·교정 기록, 기존 후보 1, revisions의 수정 전 백업도 전후 바이트 전체를 비교했다. 보존 대상 합계는 94개다. 별도 작업 중인 frontmatter-index 계열 부속파일은 입력·편집·불변 주장 대상에서 제외했다.

제1장 38,239바이트·제12장 24,058바이트와 적용된 두 교정 문장을 직접 확인하고 통합했다. 수정 전 백업이나 독립 검토의 교정 전 인용을 현재 번역으로 넣지 않았다. source-manifest.json의 초기 translation_complete 값은 보존했으며 현재 완료 범위와 구분한다.

역사 본문 마지막 문장은 원문 30220행, 마지막 각주 [71]은 30229행, INDEX 시작은 30234행임을 직접 확인했다. 뒤 색인·출판사 광고·전사자 주·Gutenberg 고지·실제 지도 영상은 통합 범위와 44장 집계 밖이다. 원목차·지도/계보 목록·색인 번역은 별도 파일에 저장되었으며 이 본문 통합에는 넣지 않았다. TXT 캡션은 각 장에 실린 대로 보존한다.

## 수행한 기계적 검증

1. 입력과 출력은 예외를 발생시키는 엄격 UTF-8 디코더로 읽었다. 단독 초안 45개와 새 출력에 U+FFFD 대체문자가 없다.
2. 결합은 원본 byte[]를 직접 사용했다. 앞 안내·목차·구획 머리말·경계 주석만 새로 작성했다. 원본 파일 안의 줄바꿈·공백·문장·반복 머리말은 정규화하거나 수정하지 않았다.
3. manifest의 0부터 시작하는 시작 바이트와 끝 바이트(미포함)로 각 구간을 잘라 원본 전체와 Base64의 일대일 표현으로 비교했다. 각 구간의 SHA-256도 원본 단독 해시와 같다. 구간은 오름차순이며 서로 겹치지 않는다.
4. 엄격 UTF-8로 읽은 각 입력의 전체 문자열을 Ordinal 검색하고 첫 위치 이후 다시 검색했다. 45개 모두 첫 위치가 있고 두 번째는 없다. 머리말이나 일부 문장의 반복과 전체 파일 중복은 구분한다.
5. oman-prefaces·oman-ch01–oman-ch44 앵커 45개의 유일성·순서를 확인했다. 목차의 해당 앵커와 단독 파일·QA·manifest 상대 링크를 확인했다. 기존 제7장→제6장 상대 링크도 보존했다. 외부 URL의 현재 응답과 Markdown 뷰어별 렌더링은 검사하지 않았다.
6. 본문 P 표지는 각 장 P01부터 끝까지 연속·유일하다. 제4–44장의 실제 개수는 각 QA의 선언과 일치한다. 별도 QA가 없는 제1–3장은 각 단독 초안의 내부 범위 기록과 비교했다. 합계 **1,735개 산문 대응 단위**, 서문 PR01–PR03·N01–N03은 **6문단**이다. 운문 앞뒤를 나눈 산문 블록 등 장별 단위를 합한 수이고 문장 수가 아니다. 방주·각주·계보·독립 운문·캡션을 더하지 않았다.
7. README 기존 본문은 제1장 38,201→38,239와 제12장 24,040→24,058의 바이트 수 두 곳만 바꾸고 마지막에 통합·교정 링크 안내를 추가했다. 나머지 기존 내용은 그대로다. 단독 초안과 기존 QA는 수정하지 않았다.

## 재현 방법

manifest의 components를 순서대로 읽어 통합본의 [byte_start_zero_based, byte_end_exclusive) 구간을 원본 file 전체와 비교하고 SHA-256을 계산한다. 구간 순서·비중복, 전체 문자열 출현 횟수 1, 장별 P 표지의 연속성과 count_evidence_file의 개수를 다시 확인한다. protected_files는 이번 작업 전후의 관찰 결과이며 이후 변경까지 보증하지 않는다. 상대 링크는 문서가 있는 폴더를 기준으로 해석한다.

## 검증의 한계와 남은 일

바이트 동일성은 번역 의미의 정확성을 증명하지 않는다. 독립 의미 표본은 기존 12문단 검토와 그중 두 문장의 후속 교정이며 이를 전 장 감수로 확대하지 않았다. 전수 영한 문장 대조, 용어 통일, 원저의 오류·연대·수치·인과의 현대 전문사료 검증, 지도 영상 확인은 남아 있다.

범위는 1902년까지여서 20세기 대부분과 21세기의 공백이 있다. 제국주의·인종·민족/혈통·종파적 서열과 인물 평가는 당시 저자의 주장으로 보존한 것이며 현대 사실이나 번역자의 판단으로 승인하지 않는다. 제44장 마지막 문단은 제국 연방과 인종에 관한 저자의 전망이다.

문서 구성 작업으로 코드·로직 변경은 없다. 코드 단위·통합 테스트나 빌드, 앱·DB 작업, Git 조회·커밋·푸시는 실행하지 않았다. 이 QA의 ‘통합’은 문서 결합 검증이며 소프트웨어 통합 테스트가 아니다.

## 부속자료 완료 안내 갱신

원목차·지도/계보 목록과 색인 완료에 따라 통합 맨앞의 미래형 안내와 링크만 갱신했다. 입력45개 번역은 모두 불변이며 바이트 범위45개를 헤더 차이만큼 보정하고 원파일 전체가 각각1회 포함되는 것을 재확인했다. 색인 표제어1208개·계속블록4개·대조블록1212개는 부속 QA의 집계이며 이번에 독립 전수 번역검수를 새로 한 것은 아니다. 별도 부속 파일을 본문에 합치거나 바꾸지 않았다.
