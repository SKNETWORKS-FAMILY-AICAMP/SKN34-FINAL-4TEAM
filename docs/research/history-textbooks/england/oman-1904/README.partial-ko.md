## 마지막 본문과 부속자료의 경계

- 제40–44장 마지막 묶음은 `source-en.txt` 26027–30233행이다. 합계 본문 247문단, 방주 205개, 지도 캡션 3개, 각주 13개를 번역하고 P 번호·각주 호출/정의·UTF-8 대체문자 0개를 확인했다.
