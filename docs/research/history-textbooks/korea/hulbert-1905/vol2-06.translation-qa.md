## 수치·구조 점검 방법과 한계

- 원문 빈 줄 기준 산문 블록에 P01부터 P25까지 순서대로 대응했다. P14의 긴 상소 전체와 왕의 답변, P16 포고, P21의 통첩과 편지를 생략하지 않았다.
- 각 문단의 아라비아 숫자를 정규식으로 추출하여 값과 등장 순서를 비교했다. 천 단위 쉼표만 수치의 일부로 보아 문장 끝 쉼표와 구분했다. 번호는 중복·누락 없이 연속한다.
- 영어로 풀어 쓴 수량·서수·거리·기간은 한국어 어휘로 옮겼다. 이들은 위 아라비아 숫자 자동 대조 대상이 아니며 번역 자체 점검 대상이다. 자동 대조만으로 모든 의미·수량·역사적 정확성을 보장하지 않는다.
- P01: 음력 넷째 달 초열흘 → 이틀 뒤 → 마흔 살 미만/열다섯 살 초과 → 삼 년(첫해·둘째·셋째) → 700,000명 → 열다섯–마흔 살 → 열 명(앞 다섯/뒤 다섯)이라는 순서를 유지했다.
- P04: 스물네 고을 → 300파운드 → 일흔 장 → 다섯 명. P06: 300,000명 뒤 원저의 의심 표시 (!) 보존. P07: 200명 → 300리 → 100마일. P08: 1,000온스 → 세 형제. P09: 20,000명 → 200자루 → 400명.
- P11: 금 10,000온스 → 은 10,000온스 → 삼베 10,000,000필, 이어 비단·삼베·모시·무명 각 800필 → 호피 60장 → 해달피 300장 → 종이 800첩. 단위와 품목 순서를 유지했고 현대 단위로 환산하지 않았다.
- P20: 궁수 10,234명 → 총수 700명. P21: 음력 열째 달 → 다음 달 스무엿새 → 다음 달 스무닷새. 통첩에서 서로 다른 날짜를 임의 통일하지 않았다.
- P22: 십 리에서 백 리. P23: 열두째 달 → 열이튿날 → 140,000명 → 다음 날. P24: 열나흗날 → 120리 → 다음 날 정오 → 닷새 → 500명 → 소 열 마리/술 열 통 → 밤 일곱 시 → 수행원 여섯 명 → 자정 전. P25: 전 병력 삼분의 일 → 세 조건.

## 역사·표기·편향 검토 대기

- P01의 700,000명은 저자가 ‘훈련했다고 한다’고 적은 수치다. 저자의 인구 추정 단서라는 논평까지 옮겼으나 실제 병력·인구의 검증치가 아니다. 군역 연령의 부등호 의미도 원문대로 옮겼다.
- P03의 Yi In-jo, Hŭ Chŭk, 폐왕의 처 친족과 왕의 숙부 관계 등은 사료·왕계 대조가 필요하다. 번역으로 왕대비의 공모 또는 무죄를 확정하지 않았다.
- P06의 모문룡 만주 내통·자칭 천자·병력에 관한 서술과 Wŭn Sung-han의 표기를 보존했다. 앞 장의 Wŭn Sung-whan과 일치하는 인물인지 별도 확인해야 한다.
- P07의 인조 시기 노론·소론 서술은 당파 형성 연대와 대조가 필요한 핵심 검토 항목이다. Chŭl-lang을 ‘절랑’, Mu-hak을 ‘무학’으로 음역하고 원어를 병기했으며, 특정 관직·제도로 확정하지 않았다. 원저의 300리=100마일이라는 환산도 보존했다.
- P08의 유해 및 세 형제 사건, P10의 1631년·남경·Jean Niouk·리치의 동료라는 서술은 외교사·천주교 전래사 자료와 검증해야 한다. ‘대포는 권총의 오기일 것’은 헐버트의 추측이지 번역자의 교정 결론이 아니다.
- P11의 엄청난 공물 요구량은 원저 수치 그대로다. ounces와 quires를 온스·첩으로 옮겼고 전통 중량·종이 단위의 실제 환산은 하지 않았다.
- P13의 두 사신이 청 황제 앞에서 겪었다는 일, 황제 아들에게 보내는 서신, P15 장례 장소와 속임수는 원저 서술로 보존했다. P23의 Sin Keui-wŭn 역시 신기원으로 옮기고 원어를 붙였다.
- P18의 징조가 ‘지어낸 것’이고 조선인의 ‘미신’을 보여준다는 판단은 저자의 평가다. P14 상소 속 ‘야만인·도적·늑대·호랑이’는 인용문의 적대적 수사이며 번역자의 민족관이 아니다.
- P21의 출병 기한 스무엿새/스무닷새, P23–P24의 진격 일수·도착 시각·전란 경로는 별도 연표와 대조해야 한다. 원문 내부 모순을 조용히 고치지 않았다.
