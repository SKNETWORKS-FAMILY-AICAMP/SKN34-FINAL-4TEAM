# 한국 연구자료 공개 범위 정정

2026-11-15. 고전 원문에 기반한 번역 초안·역사 세계 1개와 24카드다. 약 1904년까지의 지정 범위이며 현행 교과서·현대사 완결본·전문 역사감수 완료본이 아니다. 별도 창작 후보와 역사 연구 세계를 구별한다.

## 검증
원문 및 43 건 발췌 SHA-256 재계산 통과. 전수 역사학적 검증이 아니며 원저의 편향·연대 오류 가능성은 남는다. 이전 부분 검수와 교정 기록은 보존했다. Git 자동 줄바꿈 변환을 비활성화하여 해시를 보존한다.

## 공개 범위
문자 연구자료만 공개하며 스캔 이미지·PDF와 임시 렌더 파일은 제외했다. 관련 파일을 가리키는 기존 경로는 로컬 검수 기록이며 공개 첨부가 아니다. 원저와 배포 이용고지는 보존한다. 앱·DB·기존 장르 템플릿·공개 정책은 변경하지 않는다. 서비스 등록 및 전문 감수는 별도 작업이다.
