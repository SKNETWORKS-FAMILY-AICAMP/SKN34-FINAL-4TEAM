## 사용 한계와 검수 기준

1882년 저작의 민족·문명 위계 관점과 왕조·전쟁 중심 설명을 현대의 합의로 취급하지 않는다. 본문에 나오는 'Teutonic race', 'barbarism' 등은 저자의 시대적 표현이다. 역사적 오류 가능성과 현대 연구와의 차이는 별도 편집 주석으로 기록하고, 원문의 주장을 번역자가 조용히 고치지 않는다. 원문을 읽지 않은 부분의 번역이나 시대 배경을 완성본처럼 생성하지 않는다.

## 파생 세계관 예비 아이디어: 이름보다 먼저 존재한 나라

상태: 첫 두 문장에서 착안한 창작 아이디어. 역사 사실이나 완성된 세계관 카드가 아니다.

해협·산맥·내해에 둘러싸였지만 지역마다 서로 다른 이름으로 불리는 나라를 설정한다. 새 왕실은 공동 국호를 보급하려 하고, 각 지방의 지도 제작자와 상인들은 기존 이름을 유지한다. 갈등의 중심은 누가 경계를 지도에 그리는가, 어느 이름으로 관세와 통행증을 발급하는가이다. 국호의 점진적 형성만 원문에서 착안했으며, 왕실의 정책·지도 제작자·관세·통행증은 창작으로 추가한 요소다. 실제 프랑스의 제도나 사건을 재현했다고 주장하지 않는다.
