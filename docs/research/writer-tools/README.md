# 작가 도구 조사: 읽기·질문·시연 안내

> **조사 기준:** 2026-11-01, 한국 시간. 화면과 가격, 계정 권한은 바뀔 수 있으므로 실제 시연이나 비용 발생 전 현재 화면을 다시 확인한다. **Plottr는 사용자의 요청으로 이번 범위에서 제외했다.**
>
> 이 문서는 경쟁 서비스를 이해하기 위한 조사 자료다. 제품의 모든 기능을 실행해 검증한 전수조사는 아니다. STORYFORK의 구현 또는 확정 정책을 변경하지 않는다.

## 문서 읽는 순서

펜시브는 별도의 [기능 조사와 STORYFORK 적용 제안](../pensiv/README.md)에 정리했다. 블로그의 자동 모순 검사·등장 기록·관계 변화 추적 주장과 실제 검증 범위를 구분해 읽는다.

| 문서 | 이런 질문에 사용 |
|---|---|
| [Novelcrafter 명세서](novelcrafter.md) | Codex, 장면 구조, 설정 추적과 Progression, 문맥 선택, 집필과 Chat |
| [Sudowrite 명세서](sudowrite.md) | Story Bible, 이어쓰기·재작성, Quick Edit, Chat, 크레딧 |
| [스토라이즈 명세서](storize.md) | 세계관 만들기, 인물·도입부, 플레이·전개·공개와 샤프심 |
| [세 서비스와 STORYFORK 비교](comparison.md) | 기능별 차이, MVP 반영 여부, 관찰한 점과 제안의 구분 |
| [직접 관찰·시험 근거](evidence.md) | AI 응답·실패·저장·사용량의 증거 화면과 미확인 범위 |

각 문서에는 입문 순서, 화면·버튼별 목적과 경로, 입력과 결과, 제약, 시험 여부 및 출처를 담는다. **[실측]**은 당시 직접 조작·화면 확인, **[실행]**은 생성 요청과 결과 확인, **[공식문서]**는 문서로만 확인, **[미검증]**은 확인하지 못한 범위다. 앱에 표시된 AI 문맥이 실제 요청 내용 전체와 서버의 접근 통제를 보장하는 것은 아니다.

## 먼저 보는 요약

- **Novelcrafter:** Act·Chapter·Scene과 Codex 항목을 연결해 장편 원고와 설정을 관리한다. Scene Beat에 문맥을 지정하는 화면, 이름 등장 추적과 장면에 연결된 Progression을 관찰했다. Chat의 실제 GPT 응답은 별도로 시험했다. 설정 변화를 앞뒤 장면의 AI 요청에 반영하는지 여부는 별도 검증이 필요하다.
- **Sudowrite:** Story Bible로 작품 정보를 모으고 Write·Rewrite·Quick Edit·Chat으로 집필한다. Quick Edit에서 원문과 수정안을 비교하고 Reject로 원문을 유지하는 동작을 직접 시험했다. 시험 중 일부 결과에서 사실의 불확실성이 달라지거나 입력에 없는 이름이 생성됐다. 소수 사례이므로 전체 품질을 단정하지 않는다.
- **스토라이즈:** 세계관·인물·도입부와 플레이가이드를 만들고 사용자별 전개를 읽는 흐름을 관찰했다. 조사용 세계관을 비공개로 임시저장하고 불러왔다. AI 텍스트 생성 시도에서는 응답과 오류가 화면에 나타나지 않았다. 네트워크 관찰 장치가 검증되지 않아 서버 요청 여부와 원인은 미확인이다.

## 나중에 질문하거나 Aside로 직접 시연할 때

1. 사용자가 가리킨 **서비스·화면·버튼**을 확인하고 해당 서비스 문서에서 먼저 찾는다. 정보가 오래됐을 가능성이 있거나 실제 화면과 다르면 현재 화면을 우선 확인한다.
2. 직접 시연을 요청하면 `aside-browser` 스킬과 `aside guide`를 확인하고, 기존 탭을 보존하면서 해당 서비스의 기존 탭이나 별도 탭을 사용한다. 사용자가 직접 로그인해야 하는 경우 비밀번호·API 키·인증 코드는 받지 않는다.
3. 사용자가 보고 있는 요소의 **현재 이름·상태·위치**와 조작 목적을 말하고, 필요한 클릭·입력만 수행한 뒤 **실제 나온 화면과 결과**를 설명한다. 같은 버튼도 요금제·작품·상태에 따라 다를 수 있다.
4. 수정·저장·생성은 조사용 비공개 가상 작품에서만 진행한다. 사용자 작품이나 설정을 무단 변경·삭제하거나 공개·발행하지 않는다. 단순 화면 전환과 비용 발생이 없는 확인은 진행하되, 삭제·발행·결제·유료 전환 등은 별도 승인을 받는다.
5. AI 호출 전 현재 모델·요금·잔액·한도와 허용 범위를 확인한다. 무료체험과 외부 API 과금은 다르다. 이미 허용한 예산이라도 자동 충전·구매를 켜거나 한도를 임의 변경하지 않는다.
6. 결과가 없는 경우 기다린 시간, 화면상 오류, 비용 변화와 확인하지 못한 부분을 구분한다. 네트워크 관찰 장치가 검증되지 않았으면 요청 발생 여부를 단정하지 않는다.

## 계정과 조사 데이터 보존

- 세 서비스에 **별도의 가상 조사용 작품 또는 비공개 임시저장본**을 남겼다. 삭제하거나 공개하지 않았다. 별도의 스토라이즈 공개 회차를 열람해 읽기 이력이 생겼다.
- Sudowrite 기본 프로젝트에 가상 설정·원고, Novelcrafter에 가상 원고·Codex·시험 채팅이 남아 있다. 앱의 저장 여부와 계정 상태는 나중에 다시 확인해야 한다.
- 자격 증명, 원고나 개인정보를 이 문서에 기록하지 않는다. 실제 화면의 결제·샤프심·API 잔액은 당시 값일 뿐 이후 값을 보장하지 않는다.

## 우리 제품과 비교할 때의 기준

STORYFORK의 목표는 작가의 설정·집필과 독자의 허용된 원작 Fork, 기준 회차 및 인물별 지식에 따른 다중 인물 시뮬레이션이다. [MVP 설계](../../design/design.md)는 설정 추출 후 작가 채택, 회차별 세계관 갱신, 인지 회차, 시뮬레이션, 독자 Fork 및 AI 집필 제안을 포함한다. **설정 충돌 검사와 저장 버전 복원 등은 MVP 제외**다. [현재 아키텍처](../../architecture.md)는 인증·일부 콘텐츠·첨부 API와 데모 화면이 공존하는 상태다. 목표 서비스 분리는 [DEC-41](../../design/service-boundaries.md)을 따르며 전체 업무 완료와 구분한다. 경쟁 서비스에서 발견한 기능은 참고 의견이지 우리 제품의 구현 완료나 새로운 팀 결정이 아니다.
