# 회차 삭제 정책 확정 이슈 초안

## 현재 구현 (팀 정책 확정 전의 임시 기준)
- 순서 변경은 후보 구간 조회만 제공하며 실제 번호 변경은 하지 않습니다. 저장 버전·설정 공개 범위·AI·Fork 참조가 있는 회차를 넘는 후보는 제외합니다.
- 초안 삭제는 episode_draft 행을 실제 제거합니다. 회차·저장 버전·발행본·이미지 원본은 보존합니다.
- 삭제된 초안의 revision은 episode.draft_revision_floor에 보존하여 오래된 자동저장을 409로 거절합니다. 새 조회 이후 입력 또는 기존 버전 복원으로 재개합니다.
- 회차 삭제는 참조 없는 마지막 회차로 제한합니다. FK 위반도 삭제 거절이며 cascade를 추가하지 않습니다. work.deleted_episode_revision은 삭제 번호 재사용 시 오래된 편집 요청을 구분합니다.
- 이미지 기능 활성화 상태에서는 회차 삭제를 제한합니다. 이미지 연결이 별도 DB의 작품+회차번호이며 트랜잭션이 다르기 때문입니다. 기존 이미지 데이터가 있는 환경에서 기능만 끄고 삭제하는 운영은 지원하지 않습니다. 이미지 참조 조회/잠금의 공통 계약은 후속 확정이 필요합니다.
- V9는 동시성 토큰 두 필드만 추가하며 기존 ERD 관계·기존 Flyway 이력은 보존합니다. 별도 삭제 요청/승인 테이블은 만들지 않습니다.
- 소유권은 기존 WorkAccessService와 작품 잠금을 사용합니다. 상속 회차 삭제는 거절합니다.
- 병합 충돌 표시와 삭제된 ContentService/DTO를 참조하던 이미지 연결·테스트를 현재 서비스에 맞췄습니다.

## 확정할 정책
- 초안 삭제 후 빈 초안으로 재개할지, 저장 버전에서만 복원할지.
- 저장 버전·발행본이 존재하는 회차의 삭제 요청을 거절할지, 공개 중단과 별도 처리할지.
- 중간 회차 삭제를 허용할지, 번호 공백을 유지할지. 후속 회차의 발행·AI 대상 계산 영향.
- 삭제 번호 재사용 여부와 회차 ID 보존. 이전 요청·이미지가 새 회차로 연결되지 않도록 할 조건.
- 설정 공개 범위의 시작·종료 회차, Fork·체크포인트·AI 기록이 참조하는 회차의 보존 방식.
- 초안·저장 버전이 공유하는 이미지 원본의 보존 기간 및 고아 파일 정리 책임.
- 삭제 후 복구 제공 여부와 복구 가능 기간. 물리 삭제 시 복구 불가 안내.
- 순서 변경 후보 판정에서 발행 이력·설정 범위·이미지·Fork를 제한하는 기준. 이번 범위는 조회이며 실제 순서 변경은 제외.

## 구현 시 필요한 검증
- 소유권·상속 회차 보호, 요청 revision 검사.
- 삭제와 자동저장·복원·AI 반영·이미지 업로드의 경쟁 조건.
- 저장 버전만 남은 회차 조회, 삭제 후 빈 화면, 실패 시 입력 보존.
- 참조 데이터와 기존 migration 이력 보존.

## 삭제 후 호환성 보완
- 설정 공개 범위용 예약 회차는 실제 작성 회차의 다음 번호·후속 회차 판정·순서 후보에서 제외합니다. 이미 있는 예약 행에 초안을 연결할 때 ID와 설정 참조는 유지합니다.
- 작품 응답의 hasWritingEpisode가 false이면 /content는 편집기 대신 집필실 회차 생성 안내를 표시합니다.
- 이미지 기능 설정값만으로 삭제를 허용하지 않습니다. 이미지 저장소 Bean이 없거나 조회할 수 없으면 삭제를 거절합니다. 기능 비활성 상태에서 무조건 회차 삭제가 가능하다는 이전 임시 기준은 폐기합니다.
- 이미지 저장소를 조회할 수 있고 해당 회차 이미지가 없으면 다른 삭제 조건을 검사합니다. 이미지 업로드는 이미지 트랜잭션의 작품 행 잠금 이후 회차 존재를 재확인합니다. Core 삭제도 같은 DB의 같은 작품 행을 잠가 직렬화합니다. 두 영속성 컨텍스트를 중첩하여 같은 행 잠금을 중복 획득하지 않습니다. 분산 트랜잭션이나 파일 자동 정리는 추가하지 않습니다.
- 이 잠금 순서에 대한 실제 DB 동시성 검증은 CI 대상이며 로컬 단위 테스트로 완료를 주장하지 않습니다. 혼합 버전 서버 배포에서는 구버전 업로드 경로가 같은 계약을 지키는지 별도 확인해야 합니다.
- 이미지 참조 검증 누락 자체(이전 이식 회귀)는 이번 수정 범위에서 제외하며 별도로 해결해야 합니다.
