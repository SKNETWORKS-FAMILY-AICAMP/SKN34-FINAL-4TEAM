# 전체 세계관 지도

세계관 작업실의 `전체 세계관 지도`는 저장된 승인 설정을 react-force-graph-2d 1.29.2로 탐색하는 화면이다. 지도는 지연 로딩한다. 기존 설정 작성과 저장 흐름을 사용하며 지도 전용 API나 DB는 추가하지 않는다.

## 표시 규칙

- 입력은 `vm.saved.settings`이다. 저장 전 편집과 미승인 AI 후보는 제외한다.
- 인물·장소·조직·규칙·사건·관계·기타 설정을 구분한다. 관계 기록도 하나의 노드로 표시한다.
- 연결은 `relatedIds`, `afterId`, 관계의 `subjectId`/`targetId`에서만 만든다. 내용에서 관계를 추측하지 않는다.
- 부정 관계는 `적대 아님`처럼 표시한다. 사건 연결 상세는 선택 방향에 따라 `이전 사건`/`이후 사건`을 표시한다.
- 찾을 수 없는 연결 대상은 제외하고 개수를 알린다.
- ForceGraph가 수정하는 위치·연결 객체는 별도로 만든다. 저장 설정을 직접 전달하지 않는다.

검색·종류 필터·목록 선택·연결 상세·다시 펼치기·멈춤/재개·확대/축소·전체 보기를 제공한다. 캔버스를 조작하지 못해도 키보드로 목록과 상세를 사용할 수 있다. 움직임 감소 환경에서는 자동 움직임을 줄인다. 렌더러 실패 시 목록과 상세는 유지한다.

## 제한

읽기용 지도이며 선을 그어 관계를 편집하는 기능은 없다. 드래그한 위치는 저장하지 않는다. 세계관이나 저장 버전이 바뀌면 배치와 선택이 초기화된다. 운영 인증·권한 범위는 기존 작업실의 제한을 그대로 따른다.

## 로컬 검증 (2026-11-02)

- 지도 데이터·검색·선택·정본 불변성·미저장 편집 격리·저장 후 갱신·초기 캔버스 렌더링·시간선 양방향 표기를 Vitest로 확인했다.
- 프런트 프로덕션 빌드와 변경 파일 oxlint 통과. 기존 메인 번들의 500kB 경고는 남아 있다. 지도 렌더러는 별도 청크다.
- 전용 합성 DB/Core(8098)와 웹(5181)에서 Aside E2E: 관계 상세의 부정 표시, 검색 결과 없음과 초기화, 멈춤/다시 펼치기, 확대/전체 보기, 이전·이후 사건 탐색을 확인했다.
- 1440px/390px 화면을 확인했다. 모바일 지도 화면에 문서 가로 넘침이 없었다.
- 최초 렌더링 시 부모 DOM 참조가 아직 없는 오류와 이전 사건을 이후 사건으로 표시하던 오류를 발견해 회귀 테스트 후 수정했다. 리뷰에서 요청한 시간선 수정도 반영했다.
- 로컬 증거는 Git에서 제외한 `output/world-map/`에 있다. API 키·환경 파일·QA DB·로그·생성 그래프는 커밋하지 않는다.

Graphify 로컬 AST 분석은 233개 코드 파일에서 수행했다. Gemini 문서 분석은 별도 외부 전송 승인 대기이며 완료로 간주하지 않는다. 원격 Required CI 결과는 로컬 검증과 별도로 확인해야 한다.
