# 집필 AI 에이전트 구조 개편 제안 (미채택 이력)

**상태: 미채택 이력.** 현행 설계나 구현 지시가 아니다. 현행 구조는 [아키텍처](02-ai-architecture.md)를 본다.

- **제안(2026-11-12 이전):** 여섯 업무 Agent를 세 업무 역할(작품 분석 = Q&A + Review + World & Plot, 전개 기획, 문장 생성)과 공통 도구(Retrieval, 인물 시뮬레이션, 외부 사실 조사)로 묶는 구현 단위 통합안이었다. 사용자 기능·결과 종류·승인 경계는 그대로 두는 조건이었다.
- **결정:** 사용자가 채택하지 않았다(2026-11-12). 여섯 업무 Agent와 기존 기능 경계를 유지한다. 다중 인물 Simulation은 사용자의 명시적 실행 요청이 있을 때만 실행한다.
- **이후:** 실행 구조는 2026-11-17 사용자 결정(#473)으로 메인 에이전트 하나가 업무 Agent를 `ask_*` 서브 에이전트 도구로 부르는 구조가 됐다. 업무 Agent 경계는 유지됐고, 2026-11-18 사용자 결정으로 설정집 검토를 일곱 번째 업무 Agent로 더했다. 당시 표로 정리한 우선 연결(Retrieval → Q&A, Review → Writing 등)의 현재 지원 범위는 [작업 간 입력·출력](02-ai-architecture.md#작업-간-입력출력)과 [실행 사례](09-execution-scenarios.md)를 따른다.
