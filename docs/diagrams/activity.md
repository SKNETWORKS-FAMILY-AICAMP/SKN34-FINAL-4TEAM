# STORYFORK 활동 다이어그램
> [다이어그램 목차](./README.md) · [유스케이스 문서](../usecase.md) · [명세 목차](../usecase-spec/README.md)
여러 유스케이스에 걸친 처리 흐름을 정리합니다. 피드백 처리 흐름(UC-14~16)은 [유스케이스 문서 5절](../usecase.md#5-피드백-처리-흐름)에 있습니다.
## 1. 회차 발행과 자동 처리
회차가 발행될 때 이어지는 자동 처리입니다. 세계관 자동 업데이트(UC-04)는 **새 회차**일 때만 실행하고, 수정안 반영에 따른 재발행에서는 실행하지 않습니다(BR-11).
```mermaid
flowchart TD
  A{"발행 요청 출처"}
  A -->|"작가 발행 (UC-13)"| N1["새 회차 발행 요청"]
  A -->|"자율 연재 (UC-18)"| N2["AI가 생성한 새 회차 발행 요청"]
  A -->|"수정안 반영 (UC-16)"| R1["기존 회차 재발행 요청"]
  N1 --> C
  N2 --> C
  R1 --> C
  C{"UC-13 발행 확인<br/>권한 · Fork 원작 조건 · 권리 제한 · 2차 창작물 유료 불가"}
  C -->|"실패"| F1["발행하지 않음 · 초안 보관 · 소유자 알림"]
  C -->|"통과"| P["회차 상태: 발행됨"]
  P --> Q{"새 회차인가?"}
  Q -->|"아니오 · 수정안 재발행"| E1["종료 · 세계관 업데이트 없음"]
  Q -->|"예"| W{"작품 설정: 세계관 업데이트 자동?"}
  W -->|"수동"| E2["종료 · 작가가 필요할 때 UC-04 요청"]
  W -->|"자동"| K{"작품 소유자 크레딧 충분?"}
  K -->|"아니오"| E3["이번 회차 업데이트 건너뜀 · 소유자 알림"]
  K -->|"예"| X["UC-04 자동 추출 (해당 회차만)"]
  X -->|"AI 실패"| E4["즉시 실패 고지 · 운영자 경고"]
  X -->|"성공"| Y{"기존 설정과 충돌?"}
  Y -->|"예"| Y1["덮어쓰지 않고 '충돌 확인 필요'로 남김"]
  Y -->|"아니오"| Y2["설정집·인물관계도 반영 · 변경 이력 기록"]
  Y1 --> Z["소유자에게 변경 요약 알림"]
  Y2 --> Z
```
- 공개 전환(떡밥 공개)도 이 업데이트에서 함께 반영되며, 전환 회차를 이력에 남깁니다(BR-10).
- 자율 연재는 다음 실행 시점에 다시 처음부터 이 흐름을 탑니다.
## 2. Fork 생성과 고정 범위
Fork를 만들 때 무엇을 고정하는지 보여 줍니다(UC-08, BR-04).
```mermaid
flowchart TD
  S["독자가 분기 기준 회차 선택"] --> C1{"원작인가 (Fork 작품 아님)?<br/>이 독자가 이 원작에서 처음 Fork하는가?<br/>Fork 허용 회차?"}
  C1 -->|"아니오"| X1["생성하지 않음 · 사유 안내"]
  C1 -->|"예"| C2{"권리 제한 중인가?"}
  C2 -->|"예"| X2["생성하지 않음 (CE-06)"]
  C2 -->|"아니오"| H{"원작에 회차별 설정 이력이 있는가?"}
  H -->|"없음 · 일괄 등록"| WN["이후 회차 설정이 섞일 수 있다고 경고 · 동의"]
  WN --> G0["현재 공개 상태의 설정 고정"]
  G0 --> M
  H -->|"있음"| G1["기준 회차까지의 회차 원고 버전 고정"]
  G1 --> G2["분기 시점에 독자 공개된 설정집·인물관계도 항목만 고정"]
  G2 --> G3["비공개 항목·기준 회차 이후 내용 제외"]
  G3 --> M["Fork 작품 생성 · 독자를 소유자로 지정"]
  M -->|"실패"| X3["부분 생성물을 남기지 않음 · 성공으로 안내하지 않음"]
  M -->|"성공"| D["이후 회차·설정은 Fork 소유자가 수정"]
```
예를 들어 원작 10화 종료 시점에서 Fork하고, 원작이 30화에서 떡밥을 공개했다면 이렇게 됩니다.
| 항목 | 원작 | 10화 기준 Fork |
|---|---|---|
| 1~10화 원고 | 원작 소유자가 계속 수정 가능 | 분기 시점 버전으로 불변 |
| 10화 시점 공개 설정 | 이후 바뀔 수 있음 | 분기 시점 상태로 불변 |
| 10화 시점 비공개 설정 | 30화에서 공개로 전환 | 포함하지 않음. 30화의 공개 전환도 들어오지 않음 |
| 11화 이후 | 원작 전개 | Fork 소유자가 새로 창작 |
외부 2차 창작물도 Fork 원작이 될 수 있으며 같은 규칙을 따릅니다.
