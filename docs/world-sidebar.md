# 세계관 작업실 목록 접기

모든 작업실 탭에서 내 세계관 목록을 기본 펼침으로 유지한다. 인물 관계 편집·전체 지도 전용 외부 레이아웃 규칙을 제거하고 공통 페이지의 `listOpen` 상태로 제어한다. 사용자가 접거나 펼친 상태는 탭 이동 중 유지하며 새로 페이지를 열면 기본 펼침이다. DB와 관계 데이터는 변경하지 않는다.

데스크톱은 목록과 본문 사이의 세로 경계에 44px 버튼을 두고 스크롤 시 화면 가운데 높이에 유지한다. 목록을 접으면 버튼과 경계는 남고 본문이 여유 폭을 사용한다. 760px 이하는 기존 세로 배치를 유지해 목록 아래 경계에 버튼을 배치한다. 버튼은 세계관 목록 접기/펼치기 접근성 이름, aria-expanded, aria-controls, 기본 키보드 동작과 포커스 테두리를 제공한다.

## 로컬 검증

- 버튼이 없어 실패하는 회귀 테스트를 먼저 확인한 뒤 구현했다. 모든 7개 탭의 기본 펼침, 접은 상태 유지, 재펼침과 포커스를 자동 검사했다.
- 관련 테스트 2파일 2개, TypeScript 빌드 검사, 변경 영역 oxlint, Vite 빌드 통과. 기존 메인 번들 500kB 경고는 남는다.
- Aside CLI로 `http://127.0.0.1:5181/worlds/6f25bf17-15ac-4370-a6d9-6600ec3e34a5` 합성 세계관에서 설정 작성→관계 편집→접기→설정집→관계 편집→Enter 펼치기를 확인했다. 데이터 입력·저장은 하지 않았다.
- 실제 CSS 폭 1440/390px에서 목록과 경계 버튼 노출을 확인했다. 문서 clientWidth/scrollWidth는 각각 1421/1421, 371/371로 가로 넘침이 없었다. 증거는 로컬 `output/world-relations/sidebar-open-1440.png`, `sidebar-closed-1440.png`, `sidebar-open-390.png`에 있다.
- Ponytail 리뷰: 별도 저장소나 공통 상태 계층 없이 페이지 상태 하나와 공통 CSS만 사용한다. 카드 및 전체 지도는 기존 ResizeObserver로 남은 폭을 다시 측정한다. 숨긴 목록은 DOM에 유지하되 hidden으로 키보드·접근성 탐색에서 제외한다.

원격 Required CI는 미실행이다. 이번 변경은 공통 레이아웃 후속 패치이며 첫 PR 직접 작성·저장·재조회 분리 패치는 유지한다. 실제 PR 생성·병합·develop push는 하지 않는다.
