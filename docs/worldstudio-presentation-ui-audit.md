# WorldStudio 발표용 디자인 서비스 통합 점검

기준: 최신 develop `d3ec768`, 발표 PR #160 HEAD `d5385156` 및 현재 mockup 분기.
범위는 WorldStudio 목록/작성/탐색/관계 화면이다. 홈·독서·집필실 전체 재디자인은 포함하지 않는다.
AI 저장 구조 PR #219 및 후속 저장 작업과 별도다. 서비스 API/DB/Repository/목업 시드 변경 없음.

발표 PR 이후 변경 파일도 대조했다. RelationPairEditor, leave guard, 검토 대상 선택,
삭제 undo, 서비스 저장 안내 보완을 과거 발표 코드로 되돌리지 않는다.
기존 CharacterRelationshipEditor를 서비스로 단순 전환하면 장소 관계와 최신 relationRequest/이탈 보호를 잃을 수 있으므로,
현재 SettingsRelationshipEditor의 동작 위에 카드/스타일만 옮겼다. 인물 상세 편집은 기존 설정 카드 편집으로 이동한다.

## 보존 조건과 검증

- 동일 세계관 카드/관계 ID, HTTP 저장 payload, 초안/저장 구분은 불변.
- 카드 보드도 기존 confirmRelationDiscard/selectPair/editRelation 경로 사용. 기존 대상 선택·삭제 확인·undo 폼 유지.
- 지도 좌표는 화면 상태뿐이며 저장하지 않는다. 읽기용 카드에는 편집/연결 버튼이 없다.
- 입력 카드와 graph 객체 분리, 다중선 곡률, directed/symmetric, 원문 설명, 빈 이름·빈 결과 검증 유지.
- pure projection 실패 테스트를 먼저 확인한 뒤 인물→장소 연결을 추가했다.
- 선택 React 회귀에서 인물→장소 카드 선택·관계 작성·동일 ID 수정, 기존 입력 보호/삭제 검증을 실행한다.
- 요청에 따른 로컬 화면 검증은 mockup에서 수행한다. 배포 서버는 기존 QA 세계관 읽기만 하고 데이터를 변경하지 않는다.
- 배포 서버의 수정 전 지도에는 확대 보기 버튼이 없음을 확인했다. 수정 화면은 아직 배포되지 않았다.
- 새 디자인의 실제 HTTP 저장·PostgreSQL/Neo4j 영속성 검증은 수행하지 않으며 목업 성공으로 대체하지 않는다.

브라우저/CI 최종 결과는 PR 검증 항목에 기록한다. 무거운 백엔드 빌드·로컬 전체 테스트는 실행하지 않는다.
