# UC-24 작품 생성·관리

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
>
> **최신 세계관 방향:** 작품은 세계관 하나에 연결되고, 세계관은 동시에 최대 한 작품에만 연결됩니다. 기존 세계관 최대 5개를 조합해 새 세계관 하나를 만든 뒤 작품에 연결합니다. 원본에서 허용된 설정을 선택·복사하고 출처를 남기며 이후 원본 변경은 자동 반영하지 않습니다. Fork된 세계관은 조합 원본으로 선택할 수 없습니다. 관계·회차 상태의 상세 범위는 미정이며 원본의 권한·공개 범위를 지킵니다. 발행 후에도 소유자가 연결을 변경할 수 있습니다. 아래 직접 다중 연결 및 발행 후 변경 금지 문구는 과거 기획입니다.
>
> **MVP 세계관 범위:** 작품은 단일 세계관 방향이며 타인의 세계관을 작품 Fork 없이 직접 이용하는 기능은 MVP 이후입니다(DEC-35). 작품 Fork의 원작 세계관 참조·수정은 [UC-08](./UC-08.md)을 따릅니다. 등록 시 등록자에게 2차 창작 권리를 정확히 확인했는지 묻되, 플랫폼은 작품마다 권리까지 직접 확인하지 않습니다. 확인만으로 법적 권리가 생기지는 않습니다(DEC-38). 아래 여러 세계관 연결·타인 세계관 직접 이용 및 자동 처리 세부는 과거 기획입니다.

| 항목 | 내용 |
|---|---|

| 주 액터 | 창작자(작품 소유자) |
| 구분 | 핵심 |
| 관련 기능 ID | [F-WLD-03](../requirements.md#f-wld-03), [F-WLD-04](../requirements.md#f-wld-04), [F-WLD-08](../requirements.md#f-wld-08), [F-WRT-07](../requirements.md#f-wrt-07), [F-SET-01](../requirements.md#f-set-01), [F-SET-04](../requirements.md#f-set-04) |
| 근거 | 기획서 14·18·19쪽, 그림 9 |
| 관계 | UC-05가 extend. 연결할 세계관(UC-02 또는 UC-05)이 사전조건 |

- **목표:** 세계관에 연결된 작품을 만들고, 회차 구성과 작품별 자동 처리 설정을 관리합니다.
- **사전조건:** 로그인. 사용 권한이 있고 다른 작품에 연결되지 않은 세계관 하나가 있습니다. 기존 세계관을 최대 5개 조합해 새 세계관 하나를 만들 수 있습니다. 기존 작품 편집 시 작품 소유권이 필요합니다.
- **트리거:** 새 작품 만들기 또는 작품 설정 열기를 선택합니다.

**기본 흐름**
1. 창작자가 새 작품 만들기를 선택합니다.
2. 시스템이 연결할 수 있는 세계관(내 세계관, 이용이 허용된 공개 세계관)을 표시합니다.
3. 창작자가 작품에 연결할 세계관 하나를 선택합니다. 기존 세계관 최대 5개를 조합해 새 세계관을 만든 경우에도 작품에는 그 결과 세계관 하나만 연결합니다. 세계관 미선택 또는 다른 작품에 이미 연결된 세계관은 저장할 수 없습니다. 원고 없이 조합 과정의 충돌 검토를 제공할지는 미정입니다(UC-12).
4. 창작자가 제목·장르·소개를 입력하고 작품 유형(자체 창작, 외부 2차 창작물)을 선택합니다.
5. 시스템이 세계관 사용 권한을 확인하고 작품을 저장합니다.
6. 창작자가 회차를 추가하고 회차별 제목, 관련 장소·인물·사건을 등록합니다.
7. 창작자가 작품 설정에서 자동 처리 옵션을 선택합니다.
   - 세계관 업데이트: 수동(작가 요청 시, 기본값) 또는 자동(새 회차 발행마다). UC-04
   - 표기 오류 수정안: 작가 검토(기본값) 또는 자동 승인·발행. UC-16
   - AI 자율 연재: 끔(기본값) 또는 켬. UC-18
8. 시스템이 설정을 저장하고 결과를 표시합니다. 크레딧을 쓰는 자동 처리를 켜면 예상 비용과 부담 주체(작품 소유자)를 함께 안내하고 동의를 받습니다(UC-17).

**대안 흐름**
- A1 (2단계) 연결할 세계관 없음: UC-02로 이동해 세계관을 만든 뒤 돌아옵니다. 장르를 골라 플랫폼 기본 세계관에서 시작할 수도 있습니다(UC-02 A8).
- A2 (3단계) 공개 세계관 이용: UC-05로 진행합니다.
- A3 (1단계) 기존 작품 편집: 작품 정보·회차·설정을 수정합니다. 발행 후에도 권한을 확인한 뒤 연결 세계관을 하나의 다른 세계관으로 변경할 수 있습니다. 변경은 작가가 결정하며 기존 저장·발행 회차와 기존 Fork의 당시 기준은 보존합니다. 새 세계관은 이후 회차에 적용하며 과거 회차 변경은 작가가 별도로 결정합니다. 구체적인 이력 저장 방식은 미정입니다. 소유 세계관의 내용 수정은 UC-02에서 계속할 수 있습니다.
- A4 (4단계) 외부 2차 창작물: 시스템이 무료 공개만 가능하다는 점, 권리 책임이 등록자에게 있다는 점, 권리 문제가 제기되면 운영자가 빠르게 검토해 비공개 등 조치하고 소명 절차가 열린다는 점을 안내하고 동의를 받습니다(BR-09). 외부 2차 창작물도 Fork 허용 조건(UC-07)에 따라 Fork 원작이 될 수 있으며, AI 기능 크레딧은 일반 작품과 같이 별도로 청구합니다. 같은 외부 IP는 먼저 올린 작품이 플랫폼의 원본(2차 창작 원작)으로 인정되며, 다른 사용자도 같은 IP로 다른 작품을 올릴 수 있습니다. 등록자는 그 외부 IP가 허용하는 2차 창작 범위를 따라야 하며, 플랫폼은 그 범위를 직접 확인하지 않습니다.
- A5 (6단계) 기존 원고 가져오기: UC-03으로 진행합니다.
- A6 (1단계) Fork 작품: Fork 작품은 UC-08로 생성합니다. 원작의 허용된 회차·세계관·인물관계도를 이어받고 작품 운영 설정은 받지 않습니다. Fork 소유자가 설정과 비용을 담당합니다(BR-04, BR-08). Fork 작품은 별도 세계관 하나에 대응하며 독립 전 허용된 원본 내용을 추종합니다. 실제 참조·독립 전환 방식은 미정입니다.

**예외 흐름**
- E1 (3단계) 세계관 미선택: 작품을 저장하지 않습니다.
- E2 (5단계) 세계관 사용 권한 없음: CE-02.
- E3 (A4) 외부 2차 창작물 안내에 동의하지 않음: 작품을 만들지 않습니다.
- E4 (5·8단계) 저장 실패: CE-03.
- E5 (전 단계) 다른 곳에서 수정됨: CE-07.
- E6 (3단계·A3) 다른 작품에 연결된 세계관을 선택하거나 조합 원본을 6개 이상 선택: 저장하지 않고 사유를 안내합니다.

- **성공 보장:** 세계관에 연결된 작품과 회차 구성, 자동 처리 설정이 저장됩니다.
- **최소 보장:** 세계관이 없는 작품은 생기지 않습니다. 실패 시 기존 저장본이 유지됩니다.
- **업무 규칙:** 생성·저장만으로 공개되지 않습니다(UC-13). 작품에 일어난 사건·설정 변화는 해당 작품에만 저장합니다([F-WLD-08](../requirements.md#f-wld-08)). 외부 2차 창작물은 유료 공개할 수 없습니다(BR-09). 자동 처리 크레딧은 작품 소유자가 부담합니다(BR-08).
- **미정:** 장르 목록.
