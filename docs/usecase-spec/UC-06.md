# UC-06 캐릭터·관계·시점별 지식 관리

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자 |
| 구분 | 핵심 |
| 관련 기능 ID | F-CHR-01~06, F-OPS-02 |
| 근거 | 기획서 15쪽, 그림 10 |

- **목표:** 인물의 기본 특성과 회차 진행에 따른 관계·상태·지식을 일관되게 관리합니다.
- **사전조건:** 세계관(UC-02)과 작품(UC-24)이 있고 대상 정보의 편집 권한이 있습니다.
- **트리거:** 캐릭터 등록 또는 특정 회차 시점의 상태 편집을 선택합니다.

**기본 흐름**
1. 창작자가 캐릭터를 추가하고 성격·목표·기억·능력·역할 등 프로필을 입력합니다.
2. 창작자가 인물관계도에서 다른 인물과의 관계와 감정을 정의합니다.
3. 창작자가 기준 회차·사건 시점을 선택합니다.
4. 창작자가 그 시점의 관계·감정·보유 정보 변화를 기록합니다.
5. 창작자가 각 정보마다 두 속성을 따로 지정합니다.
   - 독자 공개 범위: 비공개, 또는 독자에게 공개되는 회차
   - 인물별 인지: 어떤 인물이 어느 시점부터 그 사실을 아는지

   두 속성은 독립적이므로 "독자는 알지만 주인공은 모르는 사실"과 "인물은 알지만 독자에게 아직 숨긴 사실"을 모두 표현할 수 있습니다.
6. 창작자가 인물의 행동 가능 범위(지식·목표·능력에서 오는 제약)를 정리합니다.
7. 시스템이 변경 내용을 확인하고 저장하며 변경 이력에 기록합니다.
8. 창작자가 회차 기준으로 인물의 상태 이력을 조회합니다.

**대안 흐름**
- A1 (1단계) 추출·시뮬레이션 결과 참고: UC-04 후보나 UC-09 선택 결과를 불러오되, 창작자가 채택한 항목만 반영합니다. 세계관 자동 업데이트가 켜진 작품은 UC-04가 반영한 변경도 이력에서 확인합니다.
- A2 (8단계) 특정 시점 비교: 두 시점의 상태 차이를 비교합니다.
- A3 (5단계) 떡밥 공개: 비공개였던 사실을 특정 회차부터 독자 공개로 전환하고, 시스템이 전환 회차를 기록합니다(BR-10).

**예외 흐름**
- E1 (4단계) 시점·근거 불명확: 과거 사실로 확정하지 않고 창작자 확인을 요청합니다.
- E2 (7단계) 저장 실패: CE-03.
- E3 (7단계) 다른 곳에서 수정됨: CE-07.

- **성공 보장:** 시점별 인물 정보가 이력과 함께 저장되어 집필·검토·시뮬레이션에서 해당 시점 기준으로 쓰입니다.
- **최소 보장:** 실패 시 기존 상태가 유지됩니다.
- **업무 규칙:** 한 인물에게 다른 인물의 비밀이나 미래 사건을 제공하지 않습니다(BR-02). 시뮬레이션의 임시 상태는 채택 없이 정본에 반영하지 않습니다(F-CHR-03). 갱신은 기본 수동입니다(UC-04).
- **미정:** 캐릭터 기본 정보와 작품별 상태의 분리 구조, 시점 단위(회차·사건·장면).
