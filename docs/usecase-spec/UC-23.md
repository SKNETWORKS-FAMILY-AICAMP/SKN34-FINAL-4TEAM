# UC-23 공유 저작물 원작 등록 · 테스트 전용

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
| 항목 | 내용 |
|---|---|
| 주 액터 | 플랫폼 운영자 |
| 구분 | 테스트 전용 |
| 관련 기능 ID | [F-RGT-04](../requirements.md#f-rgt-04), [F-RGT-05](../requirements.md#f-rgt-05) |
| 근거 | 기획서 22쪽 (저작권 만료 작품을 초기 Fork 검증용으로 활용) |
| 관계 | UC-07을 include. UC-02·UC-24·UC-03·UC-13 절차 사용 |
- **목표:** 개발·검증 환경에서 Fork·시뮬레이션을 시험할 원작으로, 저작권이 만료된 작품을 운영자가 등록합니다.
- **사용 범위:** 검증·테스트 환경 전용이며 운영 서비스 기능으로 제공하지 않습니다. 일반 사용자가 다른 플랫폼의 2차 창작물을 올리는 것은 이 유스케이스가 아니라 UC-24·UC-03(외부 2차 창작물)입니다.
- **사전조건:** 운영자 권한. 대상 작품의 보호기간 만료와 관련 권리(번역·편집본 권리 등)를 확인했습니다.
- **트리거:** 테스트 환경에서 공유 저작물 원작 등록을 선택합니다.
**기본 흐름**
1. 운영자가 대상 작품의 서지 정보와 권리 근거(보호기간 만료)를 입력합니다.
2. 운영자가 세계관(UC-02)과 작품(UC-24)을 만듭니다.
3. 운영자가 원고를 등록합니다(UC-03).
4. 운영자가 설정을 정리합니다(UC-04 또는 직접 입력).
5. 운영자가 공개·Fork 조건을 설정합니다(UC-07 포함).
6. 시스템이 작품을 "공유 저작물 원작(테스트)"으로 표시해 저장합니다.
7. 운영자가 회차를 발행합니다(UC-13).
**예외 흐름**
- E1 (1단계) 권리 근거 불충분: 등록하지 않습니다([F-RGT-05](../requirements.md#f-rgt-05)).
- E2 (6단계) 저장 실패: CE-03.
- **성공 보장:** 테스트 환경에서 열람·Fork할 수 있는 원작이 준비됩니다.
- **최소 보장:** 권리 확인이 안 된 작품은 Fork 대상으로 노출되지 않습니다.
- **미정:** 대상 작품 목록, 테스트 데이터 초기화 방식.
