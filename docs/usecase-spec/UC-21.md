# UC-21 처리 실패·지연 경고 확인

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 목표 서비스 책임(DEC-41) | 운영 — 경고·감시·조치 이력. 업무 실패 상태는 각 소유 서비스, 크레딧은 Core가 확정 |
| 주 액터 | 플랫폼 운영자 |
| 구분 | 지원 |
| 관련 기능 ID | [F-OPS-05](../requirements.md#f-ops-05), [F-ALT-01](../requirements.md#f-alt-01), [F-ALT-02](../requirements.md#f-alt-02) |
| 근거 | 기획서 13쪽 |
| 관계 | 권리 신고 대기 건은 UC-20으로 이동(A1, UML 관계 아님) |
- **목표:** 자동 처리의 실패·지연을 사용자에게 즉시 알리고, 운영자가 경고와 오류 로그로 원인을 확인해 고칩니다.
- **사전조건:** 운영자 권한.
- **트리거:** 시스템이 실패·지연 경고를 보내거나, 운영자가 운영 화면을 엽니다.
**기본 흐름**
1. AI 처리가 실패하거나 시간 초과되면 시스템이 요청한 사용자(창작자 또는 독자)에게 즉시 실패 사유와 가능한 다음 행동을 알립니다. 자율 연재는 작품 소유자에게 알립니다. 실패를 성공이나 무기한 대기로 표시하지 않습니다(CE-04).
2. 업무 소유 서비스가 오류·실패 상태를 기록하고 운영 대응이 필요한 장애 정보를 운영 서비스에 제공합니다. 운영 서비스가 별도의 운영 경고·조치 이력을 관리합니다. 제공사 연결 장애·반복 시간 초과·저장/발행 실패·신고 조치 실패나 검토 지연 등이 대상입니다. 잔액 부족·사용자 취소·입력 누락은 사용자에게 안내하되 매번 장애 경고로 올리지 않습니다. 구체적인 분류 기준은 미정입니다.
3. 운영자가 경고 목록(처리 실패, 시간 초과, 권리 신고 대기)을 확인합니다. 경고 발생·전달·확인·조치 결과는 구분합니다.
4. 운영자가 작업 식별자와 실패 단계·오류 내용·대상 기능을 확인합니다. 비공개 원고 전문과 비밀값은 로그에 남기지 않으며 접근은 필요한 권한으로 제한합니다.
5. 운영자가 원인(설정·연동 오류 등)을 확인하고 필요한 조치를 담당 서비스에 요청한 뒤 실제 결과를 운영 서비스에 기록합니다. 경고 확인만으로 해결된 것으로 표시하지 않습니다.
6. 자동 재처리는 하지 않으며 사용자는 작업을 다시 요청할 수 있습니다. 기존 실패와 새 실행 결과는 각각 기록합니다. 독자 피드백 AI 검토 실패 시 UC-15의 재검토 또는 작가 전달 선택을 따릅니다.
**대안 흐름**
- A1 (3단계) 권리 신고 대기 건: UC-20 처리로 이동합니다.
**예외 흐름**
- E1 (2단계) 경고 전달 실패: 로그는 남기고, 운영 화면에서 확인할 수 있게 합니다.
- **성공 보장:** 실패·지연이 사용자에게 즉시 알려지고, 운영자가 원인을 확인할 수 있습니다.
- **최소 보장:** 운영자가 실패를 성공으로 바꾸거나 정본·피드백 응답을 직접 작성하지 않습니다. 로그에 비공개 원고 전문이나 비밀값을 남기지 않습니다.
- **업무 규칙:** 실패한 작업의 크레딧은 UC-17 오류 복구 기준을 따르며, 사용자 동의 없이 다시 차감하지 않습니다. 작업별 시간 초과 기준은 질문·단순 오류 응대 2분, 집필 지원 3분, 시뮬레이션·자율 연재 회차 생성 10분이며 구현 단계에서 조정합니다. 권리 신고는 접수 후 24시간 안에 1차 검토하지 않으면 지연 경고를 냅니다(UC-20). 경고는 운영 화면의 경고 목록과 사이트 안 알림으로만 보내며 외부 채널(메일·메신저)은 범위 밖입니다. 기술 오류 로그는 90일 보관하고 사용자 작업 기록 및 운영 경고·조치 이력과 구분합니다. 운영 경고·조치 이력은 우선 1년 보관을 기준으로 하며 개인정보·법적 요구사항 검토 후 조정합니다. 정기 작업의 실행 실패·지연(UC-28)과 AI 지표 이상(UC-26)도 이 경고 목록으로 받습니다. 운영자 역할은 하나로 시작하고, 권리 담당·기술 담당 분리는 추후 과제입니다.
- **미정:** 경고의 세부 분류 기준과 1년 보관 기준의 법률·개인정보 검토 결과. 에이전트별 호출 수·실패율은 UC-26의 MVP 이후 LLMOps 범위이며, Langfuse 자체 UI 또는 운영 화면 API 통합은 미정입니다.
