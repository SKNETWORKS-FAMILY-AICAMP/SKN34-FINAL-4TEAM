# UC-13 회차 발행·공개 관리

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 작품 소유자 |
| 구분 | 핵심 |
| 관련 기능 ID | [F-PUB-02](../requirements.md#f-pub-02), [F-RGT-03](../requirements.md#f-rgt-03) |
| 근거 | 기획서 12·18·20쪽 |
| 관계 | UC-16 자동 처리와 UC-18이 자동 실행 |
- **목표:** 검토한 회차를 허용된 범위에서 독자에게 공개합니다.
- **사전조건:** 발행할 저장된 원고 버전과 공개 권한이 있고, Fork라면 원작의 Fork 작품 공개 조건을 충족합니다.
- **트리거:** 소유자가 발행 또는 공개 상태 변경을 선택하거나 예약 발행을 설정합니다. 또는 자동 발행(UC-16 표기 오류 자동 승인·발행, UC-18 자율 연재)이 요청됩니다.
**기본 흐름**
1. 소유자가 발행할 회차와 저장된 원고 버전을 선택합니다. 작업 초안을 발행하려면 먼저 저장해 새 버전을 만듭니다.
2. 시스템이 발행 미리보기와 공개 범위(무료·유료 공개 여부, 유료는 MVP 범위 밖)를 표시합니다.
3. 시스템이 공개 권한, Fork 원작 조건, 권리 제한 여부를 확인합니다. 외부 2차 창작물이면 유료 공개를 허용하지 않습니다(BR-09).
4. 소유자가 최종 발행을 확인합니다.
5. 시스템이 선택한 버전을 발행본으로 지정하고 독자 열람(UC-01)에 노출합니다.
6. 시스템이 실제 공개 결과를 안내합니다.
7. MVP에서는 발행만으로 세계관을 자동 갱신하지 않습니다. 작가가 UC-04를 수동 요청하고 추출 후보를 검토·채택합니다(DEC-24·26). 기존 전체 서비스 기획의 선택적 자동 모드는 MVP 이후이며, 유지 여부는 별도 확인합니다.
**대안 흐름**
- A1 (1단계) 비공개 유지: 초안으로만 보관합니다. 연재 작가에게 공개를 강제하지 않습니다.
- A2 (1단계) 공개 중단: 소유자가 회차 하나의 공개를 중단합니다. 작품 전체를 숨기려면 UC-07에서 작품을 비공개로 바꿉니다. 공개를 중단해도 기존 Fork는 유지하며, 중단된 회차는 새 Fork의 분기 기준으로 고를 수 없습니다(BR-04, UC-08).
- A3 (1단계) 발행본 수정: 새 초안 버전을 발행해 교체합니다. UC-16에서 승인·반영한 수정 초안도 이 경로로 발행합니다.
- A4 (트리거) 자동 발행: UC-16 자동 처리나 UC-18이 요청하면 1·4단계 없이 진행하되, 3단계 확인은 똑같이 거칩니다.
- A5 (트리거) 예약 발행: 소유자가 저장된 원고 버전과 발행 시각을 지정합니다. 예약 및 실제 발행 결과를 구분하며, 상세 변경·취소·실패 처리와 MVP 포함 여부는 미정입니다.
**예외 흐름**
- E1 (3단계) 권한·조건 미충족: CE-02. 발행하지 않습니다. 자동 발행이면 초안으로 보관하고 소유자에게 알립니다.
- E2 (3단계) 권리 제한: CE-06.
- E3 (5단계) 발행 실패: 완료로 안내하지 않고 이전 발행 상태를 유지합니다.
- **성공 보장:** 발행본과 작업 중 초안이 구분되어 독자에게 현재 공개된 발행본만 보입니다. 발행·발행본 교체·공개 중단·재공개 이력은 작품 소유자가 확인할 수 있으며, 이력 보관만으로 독자에게 과거 발행본을 공개하지 않습니다. 기존 Fork의 기준 버전은 공개 중단 후에도 보존합니다.
- **최소 보장:** 실패 시 기존 공개 상태가 바뀌지 않습니다.
- **업무 규칙:** AI 생성이나 수정안 승인만으로 발행본이 바뀌지 않습니다. 예외는 작품 소유자가 켠 자동 처리(표기 오류 자동 승인·발행, 자율 연재)이며, 그 설정을 사전 승인으로 봅니다(BR-01). 외부 연재 플랫폼에 자동 게시하지 않습니다.
- **미정:** 유료 열람·정산(MVP 범위 밖), 독자에게 발행 이력 노출 여부, 예약 발행의 상세 정책과 MVP 포함 여부, MVP 이후 세계관 자동 업데이트 유지 여부.
