# UC-25 캐릭터 챗

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 독자 |
| 보조 액터 | 외부 LLM API |
| 구분 | 후보 (채택 여부 미정) |
| 관련 기능 ID | 없음 (요구사항 정의서 미반영) |
| 근거 | 기획서 근거 없음. UI 프로토타입 U27에서 제안 ([UI 프로토타입 대응](../prototype-alignment.md)) |
| 관계 | UC-17을 include. UC-08로 이어질 수 있음(UML 관계 아님) |

- **목표:** 독자가 작품의 인물과 대화하며 작품을 더 깊이 즐기고, 떠오른 전개를 Fork로 이어 갈 수 있게 합니다.
- **사전조건:** 로그인. 대상 작품이 열람 가능하고(UC-01) 권리 제한 중이 아닙니다. 대상 인물이 독자가 볼 수 있는 회차에 등장했습니다.
- **트리거:** 독자가 작품과 인물을 골라 캐릭터 챗을 시작합니다.

**기본 흐름**
1. 독자가 작품을 선택합니다.
2. 시스템이 독자의 열람 기준 회차와, 그 회차까지 등장한 인물 목록을 표시합니다.
3. 독자가 대화할 인물을 선택합니다.
4. 시스템이 UC-17로 예상 크레딧을 안내하고 동의를 받습니다. 비용은 독자가 부담합니다.
5. 독자가 메시지를 보냅니다.
6. 시스템이 기준 회차 시점에 독자에게 공개된 정보와 그 인물이 그 시점에 아는 사실만으로 문맥을 준비해 AI에 응답을 요청합니다.
7. 시스템이 인물의 응답을 표시합니다.

**대안 흐름**
- A1 (7단계) Fork 안내: 대화 중 떠오른 전개를 쓰고 싶으면, Fork가 허용된 회차를 안내하고 독자가 선택하면 UC-08로 진행합니다.
- A2 (2단계) 기준 회차 변경: 독자가 더 읽으면 기준 회차와 대화 가능한 인물이 늘어납니다.

**예외 흐름**
- E1 (4단계) 크레딧 부족: CE-05.
- E2 (6단계) AI 실패·시간 초과: CE-04. 빈 응답이나 임의 응답으로 대체하지 않습니다.
- E3 (1단계) 권리 제한 작품: 캐릭터 챗을 제공하지 않습니다(CE-06).
- E4 (5단계) 기준 회차 이후 내용을 묻는 질문: 아직 공개되지 않은 내용을 답하지 않습니다.

- **성공 보장:** 독자가 기준 회차 시점의 인물과 대화한 응답을 받습니다.
- **최소 보장:** 대화는 원작·Fork·세계관 정본을 바꾸지 않습니다. 작가 비공개 정보와 기준 회차 이후 내용이 응답에 섞이지 않습니다.
- **업무 규칙:** AI에는 허용된 최소 문맥만 전달합니다(BR-02). 대화 응답은 작품의 공식 설정이 아닙니다(BR-01). AI 크레딧은 요청한 독자가 부담합니다(BR-08).
- **미정:** 채택 여부, 기준 회차를 독자가 읽은 회차로 할지 여부, 비용·무료 제공량, 대화 기록 보관, Fork 작품 인물 지원, 작품 소유자의 캐릭터 챗 허용 설정 위치.
