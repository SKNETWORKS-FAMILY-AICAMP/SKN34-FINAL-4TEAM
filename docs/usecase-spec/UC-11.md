# UC-11 AI 협업 집필

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
>
> **MVP 사용자 방향:** Fork 창작자는 원작 원고 옆 AI 채팅에서 소설을 어떻게 바꾸고 싶은지 설명할 수 있습니다. 설정 변경이면 해당 세계관·인물·관계의 위치로 안내합니다(DEC-29). 대화만으로 콘텐츠를 반영하거나 발행하지 않으며 AI 실행은 선택적입니다. 앱 크레딧의 기존 상세 정책은 [최신 MVP 설계](../design/design.md)에 따라 MVP 이후입니다.
>
> **대화·제안 기록 결정:** 창작자는 자신의 대화, 요청, 생성된 모든 제안과 선택·반영 상태를 다시 조회할 수 있으며, 기록은 소유자가 삭제하기 전까지 보관하고 플랫폼이 임의로 삭제하지 않습니다. 재생성은 기존 제안을 덮어쓰지 않습니다. 거절한 제안도 다시 열어 채택할 수 있으나 현재 원고가 기준과 달라졌다면 확인 후 반영합니다. 대화와 제안은 독자에게 자동 공개되지 않습니다.
>
> **기준 원문·이미지 결정:** 원고 수정 제안은 요청 당시 대상 원문과 제안을 보관해 나란히 확인합니다. 저장 버튼을 누르지 않은 작업 초안도 대상이 될 수 있으며, 구체적인 기준 원문 저장 범위·방식은 미정입니다. 생성된 일러스트는 채택 여부와 관계없이 소유자가 삭제하기 전까지 제안 기록으로 조회할 수 있고 채택한 것만 초안에 넣습니다. 저장된 원고 버전에 사용된 이미지는 제안 기록 삭제와 구분해 보존하여 해당 버전의 조회·복원을 보장합니다(UC-10). 발행은 별도입니다.

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자 |
| 보조 액터 | 외부 LLM API (이미지 생성 모델 포함) |
| 구분 | 핵심 |
| 관련 기능 ID | [F-WRT-02](../requirements.md#f-wrt-02)~[06](../requirements.md#f-wrt-06), [F-WRT-08](../requirements.md#f-wrt-08), [F-WRT-14](../requirements.md#f-wrt-14) |
| 근거 | 기획서 18쪽, 그림 13 (장면 제안·대화문 생성·문장 개선). 일러스트 생성은 기획서 근거 없음(팀 결정으로 추가) |
| 관계 | UC-10을 extend, UC-17을 include |

- **목표:** 자신이 정한 방향에 맞는 장면·대화·원고·문장 개선·일러스트 제안을 받습니다.
- **사전조건:** 편집 권한. 권리 제한 작품은 CE-06.
- **트리거:** 편집 중(UC-10) AI 지원을 요청합니다.

**기본 흐름**
1. 창작자가 지원 유형(장면 제안, 대화문 생성, 원고 초안, 문장 개선, 일러스트 생성)을 선택합니다.
2. 창작자가 대상 범위와 원하는 이야기 방향을 입력합니다.
3. 시스템이 UC-17로 비용을 안내하고 동의를 받습니다.
4. 시스템이 허용된 설정·기존 원고·선택한 시뮬레이션 결과 중 필요한 범위만 AI에 전달합니다.
5. 시스템이 AI 제안을 하나 이상 표시합니다.
6. 창작자가 제안을 검토하고 채택·일부 채택·수정·거절합니다.
7. 시스템이 채택한 내용만 편집 초안에 반영합니다.
8. 창작자가 초안을 저장합니다(UC-10 5단계).

**대안 흐름**
- A1 (6단계) 다시 생성: 3단계부터 별도 실행으로 진행합니다.
- A2 (6단계) 직접 집필로 복귀: 제안을 반영하지 않고 UC-10으로 돌아갑니다.
- A3 (1단계) 일러스트 생성 (MVP 범위 밖): 창작자가 원고에서 장면 범위를 지정하고 그림 방향(분위기·구도 등)을 입력합니다. 시스템은 지정한 장면 문장과, 등장인물 중 그 회차 기준으로 작가가 정리한 외형 설정만 이미지 생성 모델에 전달합니다. 생성된 이미지는 제안이며, 채택하면 UC-10 A6처럼 원고의 지정 위치에 들어갑니다. 채택하지 않은 이미지는 초안에 남지 않습니다.
- A4 (1~2단계) Fork 변경 방향 대화: 독자가 허용된 원작 원고를 보며 변경하고 싶은 내용을 설명합니다. 세계관·인물·관계 설정 변경이면 관련 설정 위치로 안내해 사용자가 직접 확인·수정하게 합니다. 실제 반영은 사용자 확인과 권한·기준 버전 검증 뒤 자기 Fork에만 수행합니다(UC-08·UC-02·UC-06, DEC-29).
- A5 (5~6단계) 기존 원고 수정 제안: 반영 전에 대상 원문과 AI 수정안을 비교하고, 채택·일부 채택·수정·거절합니다. 기존 원고가 없는 새 장면의 제안은 내용과 삽입 위치를 검토합니다. 고급 diff 편집기는 확정하지 않습니다.

**예외 흐름**
- E1 (3단계) 한도 부족: CE-05.
- E2 (4~5단계) AI 실패·중단: CE-04.
- E3 (7단계) 그사이 초안이 바뀜: CE-07.
- E4 (A3) 이미지 생성 모델의 안전 정책으로 생성 거부: 실패로 알리고 사유를 안내합니다. 빈 이미지나 대체 이미지를 넣지 않습니다(CE-04).

- **성공 보장:** 창작자가 고른 내용이 반영된 초안을 얻습니다.
- **최소 보장:** 기존 초안·발행본이 AI 출력으로 자동 교체되지 않습니다.
- **업무 규칙:** 생성 완료는 저장·발행 완료가 아닙니다(BR-01). 권리 제한(UC-20) 중인 작품·세계관에서는 일러스트 생성을 포함한 AI 지원을 실행하지 않습니다(CE-06). 일러스트 생성에는 업로드한 이미지를 참고 자료로 보내지 않습니다(BR-02). 채택한 일러스트는 저장 사용량(UC-19)에 포함됩니다. 일러스트 생성은 MVP 범위 밖입니다.
- **미정:** 지원 유형별 비용(일러스트 포함), 제안 개수, Fork 원고 옆 채팅의 세부 계약과 그 밖의 챗봇형 대화 지원 범위, 요청 당시 원문의 구체적인 보존 범위·방식, 생성 일러스트의 권리 귀속·유료 공개 이용 가능 여부와 AI 생성 표시, 그림체 일관성 유지(인물별 기준 이미지) 제공 여부.
