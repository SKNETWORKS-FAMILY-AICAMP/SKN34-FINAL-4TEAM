# UC-18 AI 자율 연재 설정·자동 발행

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
| 항목 | 내용 |
|---|---|
| 주 액터 | 작품 소유자(원작·Fork 모두) |
| 보조 액터 | 외부 LLM API |
| 구분 | 핵심 · 실행 주기 미정 |
| 관련 기능 ID | F-WRT-09, F-WRT-10, F-SET-01 |
| 근거 | 기획서 18쪽, 그림 13 |
| 관계 | UC-17을 include. 발행은 UC-13 확인 절차를 거침 |
- **목표:** 설정한 조건 안에서 AI가 다음 회차를 생성하고 자동으로 발행합니다.
- **사전조건:** 작품 소유자(원작이든 Fork든 무관). 작품의 AI 처리 권한이 있고, Fork라면 원작의 AI 처리·Fork 작품 공개 조건을 충족합니다.
- **트리거:** 작품 설정에서 자율 연재를 켜거나, 설정한 실행 시점이 됩니다.
**기본 흐름**
1. 소유자가 작품 설정(UC-24)에서 자율 연재를 켜고 조건(분량, 방향, 참고할 독자 반응 범위, 회당·기간별 사용 한도)을 정합니다.
2. 시스템이 UC-17로 회당 예상 크레딧과 한도를 안내하고 동의를 받습니다. 비용은 작품 소유자 크레딧에서 차감합니다.
3. 소유자가 자율 연재를 시작합니다.
4. 실행 시점마다 시스템이 세계관 설정과 허용된 독자 반응을 참고해 다음 회차 생성을 AI에 요청합니다.
5. 시스템이 생성된 회차를 UC-13 확인 절차(권한, Fork 원작 조건, 권리 제한)를 거쳐 자동 발행합니다.
6. 시스템이 발행 결과와 사용 크레딧을 소유자에게 알립니다.
**대안 흐름**
- A1 (3단계) 일시 중지·재개·종료: 소유자가 언제든 상태를 바꿉니다.
- A2 (6단계) 발행된 회차 수정: UC-10에서 수정한 뒤 UC-13으로 다시 발행합니다.
- A3 (1단계) Fork 작품: 같은 흐름으로 진행하며 비용은 Fork 소유자가 부담합니다.
**예외 흐름**
- E1 (2·4단계) 한도·크레딧 부족: 자율 연재를 멈추고 소유자에게 알립니다(CE-05).
- E2 (4단계) AI 실패: CE-04. 해당 회차를 발행하지 않고 건너뜁니다. 자율 연재는 실행 중을 유지하고 소유자에게 알립니다.
- E3 (5단계) 발행 확인 실패(권리 제한 등): 발행하지 않고 초안으로 보관한 뒤, 자율 연재를 `중단됨`으로 바꾸고 소유자에게 알립니다. 소유자가 원인을 해결한 뒤 재개합니다(CE-06).
- **성공 보장:** 조건에 맞는 다음 회차가 자동 발행되고 결과가 소유자에게 전달됩니다.
- **최소 보장:** 한도를 넘는 실행이나 권한·조건을 충족하지 않는 발행이 일어나지 않습니다.
- **업무 규칙:** 자율 연재를 켠 것을 사전 승인으로 봅니다(BR-01). 원작·Fork 구분 없이 작품 소유자가 설정하며 비용도 작품 소유자가 부담합니다(BR-08). 외부 연재 플랫폼에 자동 게시하지 않습니다.
- **미정:** 실행 주기·트리거, 독자 반응 반영 기준, 투표 기능, 스케줄러 도입(새 실행 계층이라 사전 공유 필요), 자동 중지 조건, 발행 전 소유자 확인 옵션 제공 여부(UI 프로토타입 U13에서 제안. 기본은 자동 발행).
