# UC-18 AI 자율 연재 설정·자동 발행

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 목표 서비스 책임(DEC-41) | 콘텐츠 서비스 — 콘텐츠 인가·정본·저장·발행의 소유자. Core는 회원·정산·알림, AI는 요청된 생성·검토만 담당 |
| 주 액터 | 작품 소유자(원작·Fork 모두) |
| 보조 액터 | 외부 LLM API |
| 구분 | 핵심 |
| 관련 기능 ID | [F-WRT-09](../requirements.md#f-wrt-09), [F-WRT-10](../requirements.md#f-wrt-10), [F-SET-01](../requirements.md#f-set-01) |
| 근거 | 기획서 18쪽, 그림 13 |
| 관계 | UC-17을 include. 발행은 UC-13 확인 절차를 거침 |
- **목표:** 설정한 조건 안에서 AI가 다음 회차를 생성하고 자동으로 발행합니다.
- **사전조건:** 작품 소유자(원작이든 Fork든 무관). 권리 제한 중이 아니고, Fork라면 원작의 Fork 작품 공개 조건을 충족합니다.
- **트리거:** 작품 설정에서 자율 연재를 켜거나, 소유자가 정한 실행 일정(요일·시각)이 됩니다.
**기본 흐름**
1. 소유자가 작품 설정(UC-24)에서 자율 연재를 켜고 조건을 정합니다: 실행 일정(요일·시각, 주 1~7회, 하루 최대 1회), 1회 분량(기본값: 최근 회차 평균 분량), 방향, 독자 반응 참고 여부, 자율 연재 비용 상한. 상한의 회당·월간 적용 범위와 초과 방지 방식은 미정입니다.
2. 시스템이 UC-17로 예상 비용과 소유자가 설정한 자율 연재 비용 상한을 안내하고 동의를 받습니다. 비용은 작품 소유자 크레딧에서 차감하며 예상 상한을 미리 예약하지 않습니다.
3. 소유자가 자율 연재를 시작합니다.
4. 실행 일정마다 콘텐츠 서비스가 현재 권한·기준을 확인하고 세계관 설정과, 소유자가 켠 경우 허용된 독자 반응을 참고해 다음 회차 생성을 AI에 요청합니다.
5. 콘텐츠 서비스가 생성된 회차를 유해 콘텐츠 1차 필터와 UC-13 확인 절차(권한, Fork 원작 조건, 권리 제한)를 거쳐 자동 발행합니다.
6. 시스템이 발행 결과와 사용 크레딧을 소유자에게 알립니다.
**대안 흐름**
- A1 (3단계) 일시 중지·재개·종료: 소유자가 언제든 상태를 바꿉니다. 일시 중지는 다음 예정 실행부터 막고 이미 진행 중인 작업은 계속합니다. 소유자는 현재 작업 중단을 별도로 선택할 수 있습니다. 중단 시 비용 처리는 UC-17의 미정 사항입니다.
- A2 (6단계) 발행된 회차 수정: UC-10에서 수정한 뒤 UC-13으로 다시 발행합니다.
- A3 (1단계) Fork 작품: 같은 흐름으로 진행하며 비용은 Fork 소유자가 부담합니다.
**예외 흐름**
- E1 (2·4단계) 설정된 비용 상한 도달·크레딧 부족: 실행하지 않고 자율 연재를 `중단됨`으로 바꾼 뒤 소유자에게 알립니다(CE-05).
- E2 (4단계) AI 실패: CE-04. 해당 회차를 발행하지 않고 건너뜁니다. 자율 연재는 실행 중을 유지하고 소유자에게 알립니다. 연속 3회 실패하면 `중단됨`으로 바꿉니다.
- E3 (5단계) 발행 확인 실패(권리 제한 등): 발행하지 않고 초안으로 보관한 뒤, 자율 연재를 `중단됨`으로 바꾸고 소유자에게 알립니다. 소유자가 원인을 해결한 뒤 재개합니다(CE-06).
- E4 (5단계) 유해 콘텐츠 판정: 발행하지 않고 초안으로 보관한 뒤 소유자에게 알립니다. 자율 연재는 실행 중을 유지합니다.
- E5 (4단계) 실행 시점 지연(서버 중단 등): 예정 시각에서 1시간 넘게 지났으면 실행하지 않고 건너뛴 뒤 소유자에게 알립니다. 연속 실패 횟수에는 넣지 않습니다(UC-28 E2).
- **성공 보장:** 조건에 맞는 다음 회차가 자동 발행되고 결과가 소유자에게 전달됩니다. 실행 당시의 조건·시각·성공/실패/건너뜀 사유·사용량과 생성된 회차의 초안·발행 결과를 구분해 기록합니다. 소유자는 실행 기록을 삭제하기 전까지 조회할 수 있고 플랫폼은 임의로 삭제하지 않습니다. 실행 기록을 삭제해도 발행된 원고 버전은 보존합니다.
- **최소 보장:** 한도를 넘는 실행이나 권한·조건을 충족하지 않는 발행, 필터를 통과하지 않은 발행이 일어나지 않습니다.
- **업무 규칙:** 자율 연재를 켠 것을 사전 승인으로 봅니다(BR-01). 원작·Fork 구분 없이 작품 소유자가 설정하며 비용도 작품 소유자가 부담합니다(BR-08). 외부 연재 플랫폼에 자동 게시하지 않습니다. 실행은 일정으로만 시작하며 독자 반응 수 같은 조건 트리거는 두지 않습니다. 독자 반응은 직전 회차 발행 이후 필터를 통과한 공개 댓글과 제안만 쓰고, 작성자 정보는 AI에 보내지 않으며, 단순 오류·스토리 오류 제보는 쓰지 않습니다(BR-02). 투표 기능은 범위 밖입니다. 실행 일정은 한국 시간(KST) 기준이며, 콘텐츠 서비스가 일정 실행·중복 방지·발행·복구를 소유합니다. 운영 서비스는 상태 감시·재실행 요청만 관리하고 크레딧 정산은 Core가 확정합니다. 중앙 스케줄러·별도 worker·큐를 DEC-41만으로 추가하지 않습니다.
- **미정:** 자율 연재 비용 상한의 적용 범위와 초과 방지 방식, 서버 여러 대로 늘릴 때의 중복 실행 방지, 현재 작업 중단 시 비용 처리(UC-17).
