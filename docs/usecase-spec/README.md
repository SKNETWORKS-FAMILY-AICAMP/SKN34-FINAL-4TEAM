# STORYFORK 유스케이스 명세서

> **문서 상태: 기획 기반 초안 v4 — 업무 기능 미구현**
> [유스케이스 문서](../usecase.md)의 UC-01~24를 상세화한 명세입니다. 사전조건·흐름은 목표 업무 계약이며 구현이나 정책 확정을 뜻하지 않습니다. 정해지지 않은 값(형식, 한도, 요금, 상태 코드)은 `미정`으로 남깁니다.

## 0. 작성 규칙

### 0.1 명세 항목

| 항목 | 의미 |
|---|---|
| 주 액터 / 보조 액터 | 목표를 가진 액터 / 처리에 참여하는 외부 액터 |
| 관계 | include·extend ([usecase.md 2.7절](../usecase.md#27-유스케이스-간-관계)) |
| 관련 기능 ID | [요구사항 정의서](../SKN34-final-4Team_요구사항정의서.xlsx)의 기능 ID |
| 사전조건 | 시작 전 참이어야 하는 조건 |
| 트리거 | 유스케이스를 시작시키는 사건 |
| 기본 흐름 | 가장 일반적인 성공 경로. `사용자`·`시스템` 주어를 명시 |
| 대안 흐름 | `An (m단계)`: m단계에서 갈라지는 다른 성공·선택 경로 |
| 예외 흐름 | `En (m단계)`: m단계에서 목표를 이루지 못하는 경로 |
| 성공 보장 / 최소 보장 | 성공 시 상태 / 실패해도 지켜지는 상태 |
| 업무 규칙 | 이 유스케이스에 적용되는 규칙 (`BR-xx`는 0.3절 공통 규칙) |
| 미정 | 구현 전 합의가 필요한 항목 |

`시스템`은 STORYFORK 전체(Frontend·Core API·AI Service)를 뜻합니다. 권한·정본·발행·크레딧의 최종 판단은 Core API가 합니다.

### 0.2 공통 예외 흐름

각 명세에서 `CE-xx`로 참조합니다.

| ID | 상황 | 처리 |
|---|---|---|
| CE-01 | 미인증·토큰 만료 | 요청을 처리하지 않고 로그인(UC-22)으로 안내. 작성 중 입력은 가능한 범위에서 보존 |
| CE-02 | 권한 없음 | 요청을 거부하고 사유를 안내. 대상의 비공개 정보·존재 여부를 노출하지 않음 |
| CE-03 | 저장 실패 | 완료로 표시하지 않고 미저장 상태를 안내. 기존 저장본 보존 |
| CE-04 | AI 실패·시간 초과·중단 | 대기 상태로 두지 않고 즉시 사용자에게 실패를 알림. 실패를 성공·빈 결과로 대체하지 않으며 부분 결과를 확정 결과로 반영하지 않음. 오류 로그와 운영자 경고를 남김(UC-21). 크레딧 처리는 UC-17 오류 복구 기준을 따름 |
| CE-05 | 비용·한도 부족 | AI 작업을 시작하지 않고 필요한 조건을 안내(UC-17) |
| CE-06 | 이용 제한 대상 | 권리 제한(UC-20) 중인 콘텐츠는 해당 기능(공개·AI·Fork)을 수행하지 않음 |
| CE-07 | 대상 버전 변경 | 작업 기준 버전이 바뀌었으면 묵시적으로 덮어쓰지 않고 재확인을 요청 |

### 0.3 공통 업무 규칙

| ID | 규칙 |
|---|---|
| BR-01 | AI 결과(추출 후보·시뮬레이션·초안·검토 의견·수정안)는 제안이다. 사용자 선택·승인과 실제 저장·공개는 별도 단계다. 단, 작품 소유자가 자동 처리(세계관 자동 업데이트, 표기 오류 자동 승인·발행, AI 자율 연재)를 켠 경우 그 설정을 사전 승인으로 보며, 자동 반영 내용은 모두 변경 이력에 남겨 되돌릴 수 있게 한다 |
| BR-02 | AI에는 작업에 허용된 최소 문맥만 전달한다. 작가 비공개 정보·독자 공개 범위·인물별 지식을 섞지 않는다 |
| BR-03 | 원고 보유·등록·공개 사실만으로 AI 처리·재공개·Fork·유료 공개 권한을 추정하지 않는다 |
| BR-04 | Fork는 분기 기준 회차까지의 회차 원고와 분기 시점의 세계관·인물관계도를 불변으로 고정한다. 분기 시점에 독자에게 공개된 항목만 포함하고 비공개 항목은 제외한다. 원작의 후속 변경(공개 전환 포함)은 기존 Fork에 반영하지 않는다. 분기 이후의 회차·설정은 Fork 소유자가 수정할 수 있다 |
| BR-05 | 처리 상태(접수·처리 중·실패·검토 대기·승인·반영 성공/실패)를 구분하고, 미완료를 완료로 표시하지 않는다 |
| BR-06 | 실패·권한 거부·한도 초과를 이유로 기존 원고·확정 설정을 덮어쓰거나 자동 삭제하지 않는다 |
| BR-07 | 권한은 계정 유형이 아니라 대상 작품·세계관별 소유권·이용 권한으로 판단한다 |
| BR-08 | AI 크레딧은 작업을 요청하거나 자동 실행을 설정한 사용자에게 청구한다. 피드백 분석은 제보자, 자율 연재·세계관 자동 업데이트는 작품 소유자, 그 밖의 AI 기능은 요청자가 부담한다. Fork 생성·직접 집필·댓글은 무료다 |
| BR-09 | 다른 플랫폼에서 가져온 외부 2차 창작물은 무료 공개만 허용한다. 권리 확인 책임은 등록자에게 있으며, 외부 2차 창작물도 Fork 원작이 될 수 있다. 원작자·저작권 문제가 제기되면 운영자가 빠르게 검토해 비공개 등 필요한 조치를 하고 소명 절차를 연다(UC-20). 조치의 상세 절차는 검토 예정이다 |
| BR-10 | 세계관·인물관계도는 변경 이력을 저장한다. 비공개 항목의 독자 공개 전환(떡밥 공개)은 공개되는 회차와 함께 기록한다 |
| BR-11 | 독자 피드백과 수정안은 세계관을 바꾸지 않는다. 피드백 분석은 공개 근거를 대조하는 검증일 뿐이며, 수정안 반영에 따른 재발행은 세계관 자동 업데이트(UC-04)를 실행하지 않는다. 세계관 자동 업데이트는 작가나 자율 연재가 새 회차를 발행할 때만 실행한다 |
