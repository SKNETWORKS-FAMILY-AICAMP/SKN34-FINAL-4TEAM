# UC-19 저장 사용량 확인·정리·확장 · 조건부

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자 |
| 구분 | 조건부 |
| 관련 기능 ID | F-STO-01 |
| 근거 | 기획서 20~21쪽 |

- **목표:** 저장 한도와 사용량을 확인하고 공간 관리 방법을 고릅니다.
- **사전조건:** 로그인.
- **트리거:** 저장 공간 화면을 열거나 한도 도달 안내를 받습니다.

**기본 흐름**
1. 시스템이 기본 용량, 현재 사용량, 항목별 사용량을 표시합니다.
2. 한도에 가까우면 시스템이 사전 안내합니다.
3. 창작자가 정리 또는 확장을 선택합니다.
4. 정리를 선택하면 창작자가 삭제할 항목을 고르고 시스템이 삭제 전 확인을 받은 뒤 처리합니다.
5. 시스템이 처리 결과와 변경된 사용량을 표시합니다.

**대안 흐름**
- A1 (3단계) 확장: 확장 옵션을 안내하고, 결제 정책이 확정된 뒤 처리합니다.

**예외 흐름**
- E1 (4단계) 삭제 실패: 삭제 완료로 표시하지 않습니다.
- E2 (A1) 확장 결제 실패: 용량이 늘어난 것으로 안내하지 않습니다.
- E3 (2단계) 한도 초과: 새 저장을 제한하되 기존 작품을 자동 삭제하지 않습니다(BR-06).

- **성공 보장:** 창작자가 선택한 방식으로 공간이 정리되거나 확장됩니다.
- **최소 보장:** 확인 없는 삭제가 없습니다.
- **미정:** 용량·계산 단위, 확장 요금, 삭제 보관·복원, 결제 방식.
