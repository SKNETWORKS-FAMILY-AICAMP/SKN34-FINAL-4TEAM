# UC-19 저장 사용량 확인·정리·확장 · 조건부

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 목표 서비스 책임(DEC-41) | 콘텐츠 서비스 — 콘텐츠 인가·정본·저장·발행의 소유자. Core는 회원·정산·알림, AI는 요청된 생성·검토만 담당 |
| 주 액터 | 창작자 |
| 구분 | 조건부 · MVP 제외 |
| 관련 기능 ID | [F-STO-01](../requirements.md#f-sto-01) |
| 근거 | 기획서 20~21쪽 |
| 관계 | — |

- **목표:** 저장 한도와 사용량을 확인하고 공간 관리 방법을 고릅니다.
- **사전조건:** 로그인.
- **트리거:** 저장 공간 화면을 열거나 한도 도달 안내를 받습니다.

**기본 흐름**
1. 시스템이 기본 용량과 원고·세계관 설정 문서의 현재 사용량을 항목별로 표시합니다. AI 대화·시뮬레이션 기록은 이 한도에 포함하지 않습니다. 이미지와 과거 버전의 계산 범위는 미정입니다.
2. 한도에 가까우면 시스템이 사전 안내합니다.
3. 창작자가 정리 또는 확장을 선택합니다.
4. 정리를 선택하면 창작자가 삭제할 항목을 고르고 시스템이 삭제 전 확인을 받은 뒤 처리합니다.
5. 시스템이 처리 결과와 변경된 사용량을 표시합니다.

**대안 흐름**
- A1 (3단계) 확장: 확장 옵션을 안내하고, 결제 정책이 확정된 뒤 처리합니다.

**예외 흐름**
- E1 (4단계) 삭제 실패: 삭제 완료로 표시하지 않습니다.
- E2 (A1) 확장 결제 실패: 용량이 늘어난 것으로 안내하지 않습니다.
- E3 (2단계) 한도 도달: 새 작품·새 원고·새 Fork 생성을 제한하되 기존 작품을 자동 삭제하지 않습니다(BR-06). 기존 원고의 수정·자동저장 제한 여부는 미정이며, 저장 실패는 성공으로 표시하지 않습니다.

- **성공 보장:** 창작자가 선택한 방식으로 공간이 정리되거나 확장됩니다.
- **최소 보장:** 확인 없는 삭제가 없습니다.
- **업무 규칙:** 한도 초과·정리 실패를 이유로 기존 원고·설정을 자동 삭제하지 않습니다(BR-06). 삭제는 창작자가 고르고 확인한 항목만 처리하며, 확정 설정 이력과 저장된 원고 버전에서 사용 중인 이미지는 각 보존 규칙으로 보호합니다.
- **사용량과 Fork:** 원본을 참조 중인 세계관 설정 문서는 원본 소유자의 사용량에만 계산합니다. Fork 창작자의 원고와 독립한 세계관은 해당 창작자의 사용량에 계산합니다. 원본 세계관 삭제는 소프트 삭제이므로 참조 중인 작품 Fork는 원본 참조를 유지하고 독립 복사하지 않습니다(DEC-42, UC-02).
- **미정:** 용량·계산 단위, 이미지·과거 버전의 계산 범위, 확장 요금, 소프트 삭제된 데이터의 사용량 계산 여부, 결제 방식. 삭제는 소프트 삭제이고 복구 화면은 MVP 범위 밖입니다(DEC-42).
