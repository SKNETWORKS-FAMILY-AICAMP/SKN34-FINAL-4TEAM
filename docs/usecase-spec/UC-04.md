# UC-04 설정 추출·세계관 업데이트

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자(작품 소유자) |
| 보조 액터 | 외부 LLM API |
| 구분 | 핵심 |
| 관련 기능 ID | F-WLD-06, F-WLD-07, F-SET-03 |
| 근거 | 기획서 14~15쪽, 그림 9 |
| 관계 | UC-03을 extend, UC-17을 include |

- **목표:** 회차 원고에서 세계관·인물·관계·사건·규칙과 공개 전환을 추출해 설정집·인물관계도를 갱신합니다.
- **왜 필요한가:** 예를 들어 1화에서 "카일은 18세"라고 썼는데 30화에서 "17세"라고 쓰면 독자는 오류로 느낍니다. 나이 같은 설정을 설정집에 기록해 두면 집필·검토·피드백 분석이 모두 같은 기준을 씁니다. 이 유스케이스는 이미 쓴 회차에서 그런 설정을 뽑아 설정집에 넣습니다.
- **실행 방식 (작품 설정, UC-24):**
  - 수동(기본값): 작가가 요청할 때만 실행합니다. 결과는 후보로 제시하며, 작가가 채택한 항목만 반영합니다.
  - 자동: 새 회차가 발행될 때마다 그 회차를 대상으로 실행하고 결과를 세계관에 반영합니다. 반영 내용은 변경 이력에 남고 작가가 확인·되돌릴 수 있습니다(BR-01).
- **사전조건:** 대상 회차 원고가 있고, 작품 소유자이며, 대상 범위의 AI 처리 권한이 있습니다.
- **트리거:** 작가가 추출을 요청합니다(수동). 또는 작가나 자율 연재가 새 회차를 발행합니다(자동, UC-13·UC-18). 피드백 수정안 반영에 따른 재발행은 트리거가 아닙니다(BR-11).

**기본 흐름 (수동)**
1. 창작자가 추출할 회차 범위와 항목(장소, 인물, 관계, 사건·규칙)을 선택합니다.
2. 시스템이 UC-17로 필요한 비용·한도를 안내하고 실행 동의를 받습니다.
3. 시스템이 허용된 범위의 원고만 AI에 전달해 추출을 요청합니다.
4. 시스템이 진행 상태를 표시합니다.
5. 시스템이 추출 후보를 항목별로 제시합니다. 각 후보의 근거 원고 위치, 불명확·상충 항목, 해당 회차에서 드러난 비공개 설정(공개 전환 후보)을 구분해 표시합니다.
6. 창작자가 후보를 수정하고 채택·제외를 선택합니다.
7. 창작자가 확정을 선택합니다.
8. 시스템이 채택한 항목만 작가 소유 세계관의 설정집·인물관계도에 저장하고 변경 이력에 기록합니다. 다른 사람 세계관에는 저장하지 않습니다(BR-12). 연결된 세계관 중 작가 소유가 없으면 작품 이름으로 새 세계관을 만들어 연결합니다(5개 제한에 포함).

**대안 흐름**
- A1 (트리거) 자동 모드: 새 회차 발행 직후 시스템이 해당 회차로 3~5단계를 실행하고, 6~7단계 없이 결과를 반영해 변경 이력에 기록한 뒤 작품 소유자에게 변경 요약을 알립니다. 비용은 자동 모드를 켤 때 받은 동의에 따라 작품 소유자 크레딧에서 차감합니다.
- A2 (5단계) 기존 설정과 충돌: 수동 모드는 기존 값과 추출 값을 나란히 보여 주고 창작자가 고르게 합니다. 자동 모드는 기존 값을 덮어쓰지 않고 "충돌 확인 필요" 항목으로 남겨 소유자에게 알립니다. 다른 사람 세계관 항목과 충돌하면 원본은 그대로 두고, 작가가 고치기로 하면 자기 세계관으로 편입해 고칩니다(BR-12).
- A3 (5단계) 근거 부족 항목: 미확정 상태로 남기거나 창작자가 직접 보완합니다.
- A4 (7단계) 나중에 확정: 후보를 검토 대기 상태로 보관합니다.

**예외 흐름**
- E1 (2단계) 크레딧·한도 부족: 수동은 CE-05. 자동은 해당 회차의 업데이트를 건너뛰고 소유자에게 알립니다.
- E2 (3~4단계) AI 실패·시간 초과: CE-04. 원고 등록·발행 상태와 구분해 안내합니다.
- E3 (8단계) 저장 실패: CE-03.

- **성공 보장:** 수동은 채택한 항목만, 자동은 반영 내용이 변경 이력과 함께 설정집·인물관계도에 저장됩니다.
- **최소 보장:** 추출 실패가 원고나 기존 확정 설정을 바꾸지 않습니다(BR-06). 자동 모드도 충돌 항목은 덮어쓰지 않습니다.
- **업무 규칙:** 매 회차 자동 갱신은 기본값이 아닙니다. STORYFORK는 세계관을 먼저 연결한 뒤 쓰는 방식이고 세계관은 이름만으로 시작해 나중에 보완할 수 있으므로, AI 비용이 드는 매 회차 갱신은 작가가 켤 때만 합니다(BR-13). 공개 전환은 해당 회차와 함께 기록합니다(BR-10). Fork에 고정된 분기 전 세계관에는 반영하지 않습니다(BR-04).
- **미정:** 추출 항목 구조, 후보 보관 기간, 자동 모드의 회당 예상 비용.
