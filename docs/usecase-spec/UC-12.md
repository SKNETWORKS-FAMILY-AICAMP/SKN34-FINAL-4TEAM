# UC-12 설정 충돌·개연성 검토

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 목표 서비스 책임(DEC-41) | 콘텐츠 서비스 — 콘텐츠 인가·정본·저장·발행의 소유자. Core는 회원·정산·알림, AI는 요청된 생성·검토만 담당 |
| 주 액터 | 창작자 |
| 보조 액터 | 외부 LLM API |
| 구분 | 핵심 |
| 관련 기능 ID | [F-REV-01](../requirements.md#f-rev-01)~[04](../requirements.md#f-rev-04), [F-SIM-09](../requirements.md#f-sim-09) |
| 근거 | 기획서 12쪽 시나리오 2.2, 15~18쪽 |
| 관계 | UC-10을 extend, UC-17을 include |

- **목표:** 원고가 기존 설정·인물 지식·사건 이력과 어긋나는지 확인합니다.
- **사전조건:** 검토할 원고와 비교 기준에 접근할 수 있습니다. 권리 제한 작품은 CE-06.
- **트리거:** 편집 중 또는 발행 전에 검토를 요청합니다.

**기본 흐름**
1. 창작자가 검토할 회차·범위와 비교 기준 시점을 선택합니다.
2. 시스템이 UC-17로 비용을 안내하고 동의를 받습니다.
3. 세계관·설정 검토 에이전트가 원고를 인물의 기억·지식, 관계, 수치, 사건 선후관계와 대조합니다.
4. 시스템이 결과를 충돌 의심, 창작적 해석이 필요한 부분, 문맥 한계로 나눠 표시하고 각 항목의 근거 회차·설정을 연결합니다.
5. 창작자가 항목마다 오류 수정, 설정 보완, 의도한 변화 유지 중 하나를 고릅니다.
6. 시스템이 항목별 판단을 기록합니다. 창작자는 나중에 판단을 변경할 수 있으며 이전 판단도 이력으로 남습니다.
7. 검토 당시의 대상 원고와 각 항목에 연결된 하나 이상의 근거 회차·설정을 나중에 확인할 수 있습니다.

**대안 흐름**
- A1 (5단계) 원고 수정: UC-10 또는 UC-11로 이동해 반영합니다.
- A2 (5단계) 설정 보완: UC-06 또는 UC-02로 이동합니다.
- A3 (4단계) Fork 작품: 원작과 다르다는 이유만으로 오류로 표시하지 않고 Fork 기준 이후의 설정과 비교합니다.
- A4 (3단계) 세계관 조합 검토: 기존 세계관 최대 5개를 조합하는 과정에서 원본 설정 사이의 충돌을 확인할 수 있는지는 미정입니다. 작품에 여러 세계관을 직접 연결하는 과거 흐름은 적용하지 않습니다(UC-02·UC-24).

**예외 흐름**
- E1 (2단계) 한도 부족: CE-05.
- E2 (3단계) AI 실패: CE-04. "충돌 없음"으로 대체하지 않습니다.
- E3 (3단계) 비교 문맥 부족: 검토 한계로 표시합니다.

- **성공 보장:** 검토 한 건의 개별 발견 사항, 각 항목의 근거와 창작자 판단 및 판단 변경 이력이 남습니다. 창작자는 자신의 검토 결과를 삭제하기 전까지 다시 조회할 수 있으며 플랫폼은 임의로 삭제하지 않습니다.
- **최소 보장:** 검토나 판단만으로 원고·설정이 자동 수정되지 않습니다. 창작자가 검토 후 별도로 수정·반영하며 저장과 발행도 구분합니다.
- **업무 규칙:** 검토는 작가가 골라 쓰는 도구이며 발행 전 필수 단계가 아닙니다(BR-13). 직접 쓴 회차는 AI 비용 없이 발행할 수 있습니다.
- **미정:** 당시 원고·근거의 구체적인 보존 범위와 저장 방식, 원고 없이 세계관 조합 단계에서 충돌 검토를 제공할지 여부.
