# UC-20 권리 침해 신고·비공개·소명

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
| 항목 | 내용 |
|---|---|
| 주 액터 | 권리 신고자·소명자, 플랫폼 운영자 |
| 구분 | 지원 · 절차 일부 미정 |
| 관련 기능 ID | F-RPT-01~03, F-SET-04 (F-RGT-01~05와 관련) |
| 근거 | 기획서 20·22쪽 |
| 관계 | 조치 적용 실패는 UC-21 경고로 전달. UC-21 경고 목록에서 진입 가능(UML 관계 아님) |
- **목표:** 권리 침해·유해 콘텐츠 신고를 접수하면 운영자가 빠르게 조치하고, 소명 절차를 거쳐 공개 여부를 결정합니다.
- **사전조건:** 신고자가 로그인한 회원이며(UC-22) 대상 콘텐츠와 근거를 제시할 수 있습니다. 검토자는 운영자 권한을 가집니다.
- **트리거:** 권리 침해 또는 회차 본문의 유해 콘텐츠(인격권 침해 포함) 신고를 접수합니다. 댓글·제보의 유해 콘텐츠 신고는 UC-14 A6에서 처리합니다.
**기본 흐름**
1. 신고자가 대상 작품·회차와 침해 근거, 연락처를 제출합니다.
2. 시스템이 접수 번호와 접수 결과를 안내합니다.
3. 시스템이 운영자에게 신고를 바로 알립니다. 운영자가 접수 후 24시간 안에 검토해 비공개, 관련 AI·Fork 기능 중지 등 필요한 조치를 하고, 작품 소유자에게 신고 사실과 소명 절차를 알립니다. 조치한 회차는 "신고 조치 중"이 됩니다.
4. 작품 소유자가 소명 자료를 제출합니다.
5. 운영자가 신고 근거와 소명을 검토합니다.
6. 운영자가 재공개 또는 비공개 유지를 결정합니다.
7. 시스템이 결정을 적용하고 신고자·소유자에게 실제 상태를 안내합니다.
**대안 흐름**
- A1 (1단계) 대상·근거 누락: 접수하지 않고 보완을 요청합니다.
- A2 (4단계) 기한 내 소명 없음: 소명 기한은 통지 후 7일이며 소유자가 요청하면 한 번 7일 연장합니다. 기한 안에 소명이 없으면 비공개를 유지합니다.
- A3 (6단계) 소명 인정: 원래 공개 상태와 기능을 복원합니다. 함께 조치한 Fork도 복원합니다.
- A4 (3단계) 원작 작가 확인: 신고자가 원작 작가(권리자)임이 확인되면 운영자 검토를 기다리지 않고 대상 작품을 즉시 비공개로 돌린 뒤 소명 절차를 엽니다. 확인은 운영자가 출판사·플랫폼 공식 채널, 이메일 도메인 등으로 직접 교차 확인합니다.
- A5 (1단계) 유해 콘텐츠 신고(회차 본문): 시스템이 유해 콘텐츠 판정 모델로 다시 검사한 결과를 붙여 운영자 확인 목록에 올립니다. 오판 위험이 있어 회차는 자동으로 숨기지 않으며, 운영자가 3단계부터 같은 절차로 조치합니다.
- A6 (6단계) 허위 신고 판단: 운영자가 신고를 허위로 판단하면 신고자 기록에 남깁니다. 허위 신고가 3회 쌓이면 30일 동안 신고 기능을 제한합니다.
**예외 흐름**
- E1 (3·7단계) 조치 적용 실패: 적용되지 않았음을 표시하고 운영자에게 경고합니다(UC-21).
- E2 (3단계) 24시간 안에 1차 조치하지 못함: 지연 경고를 운영자에게 보냅니다(UC-21).
- **성공 보장:** 신고·조치·소명·결정이 기록되고 콘텐츠에 실제 상태가 적용됩니다.
- **최소 보장:** 신고만으로 원고를 삭제하지 않습니다. AI가 법적 결론을 내리지 않습니다.
- **업무 규칙:** 외부 2차 창작물의 권리 책임은 등록자에게 있습니다(BR-09). 신고 대상이 작품이면 그 작품의 Fork에도 같은 조치를 적용하고, Fork 소유자에게 원작 조치 사실을 알립니다(신고자 정보는 알리지 않음, BR-04). 신고 대상이 세계관이면, 시스템이 출처 기록으로 그 세계관을 연결한 작품과 세계관 Fork 목록을 운영자에게 보여 줍니다. 관련 작품·Fork에는 자동으로 함께 조치하지 않고 운영자가 건별로 판단하며, 관련 작품·세계관 소유자에게는 원본 세계관이 권리 검토 중이라는 경고를 보냅니다(신고자 정보는 알리지 않음). 플랫폼은 비공개 조치와 소명 절차를 제공합니다. 신고·조치·소명 기록은 1년 보관하며 법률 검토 후 조정합니다.
- **미정:** 증빙 기준(다른 플랫폼의 권리 침해 신고 증빙 요구 방식을 조사한 뒤 반영), 플랫폼 면책 범위(이용약관·법률 검토 필요).
