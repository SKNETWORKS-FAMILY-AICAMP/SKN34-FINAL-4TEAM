# UC-09 다중 인물 시뮬레이션 실행·결과 선택

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자 (A5는 독자) |
| 보조 액터 | 외부 LLM API |
| 구분 | 핵심 |
| 관련 기능 ID | F-SIM-01~11, F-OPS-03 |
| 근거 | 기획서 16쪽, 그림 11, 12쪽 시나리오 2.1·2.2 |
| 관계 | UC-17을 include |

- **목표:** 사건 조건에 따른 인물의 행동과 인과관계를 탐색하고, 집필에 쓸 전개를 고릅니다.
- **사전조건:** 작품·기준 시점·인물 정보가 있고 대상 작품(자기 작품 또는 자기 Fork)의 편집 권한이 있습니다. 권리 제한 작품은 CE-06.
- **트리거:** 시뮬레이션 실행을 선택합니다.

**기본 흐름**
1. 창작자가 작품과 기준 회차·시점을 선택합니다.
2. 창작자가 장소, 참여 인물, 발생시킬 사건·상황, 원하는 전개 방향을 입력합니다.
3. 시스템이 UC-17로 인물 수·진행 범위에 따른 비용을 안내하고 실행 동의를 받습니다.
4. 시스템이 기준 시점의 세계관·사건 이력과 인물별 성격·목표·기억·보유 정보를 구분해 준비합니다.
5. 스토리 계획 에이전트가 사건과 환경을 구성하고 진행 흐름을 관리합니다.
6. 인물 에이전트가 자신의 정보 범위 안에서 행동·대화하고 다른 인물과 상호작용합니다.
7. 시스템이 진행 기록(행동, 대화, 사건 전개)을 표시합니다.
8. 시스템이 전개 후보와 사건 인과관계, 기존 설정과의 충돌 의심 지점을 함께 제시합니다.
9. 창작자가 후보를 선택·수정하거나 폐기합니다.
10. 시스템이 선택한 결과를 집필 재료로 저장합니다.

**대안 흐름**
- A1 (8단계) 대안 후보: 같은 상황에서 다른 전개 후보를 추가 생성해 비교합니다. 3단계 비용 확인을 다시 거칩니다.
- A2 (9단계) 조건 변경 재실행: 2단계로 돌아갑니다.
- A3 (10단계) 집필 연결: 선택 결과를 가지고 UC-10 또는 UC-11로 이동합니다.
- A4 (9단계) 인물 상태 반영: 창작자가 원하면 결과의 상태 변화를 UC-06에서 채택합니다.
- A5 (1단계) 독자의 스토리 오류 검증(UC-14 A1): 독자가 제보할 회차·구절과 의심하는 모순을 입력합니다. 기준 시점은 독자가 본 회차의 끝이며, 그 시점까지 독자에게 공개된 원고·설정·인물 정보만 씁니다. 작가 비공개 설정과 인물의 비공개 지식은 쓰지 않습니다. 비용은 독자가 부담합니다(3단계). 시스템은 8단계에서 전개 후보 대신 오류 가능성 판정, 신뢰도, 근거 회차·구절을 제시하며, 결과는 집필 재료로 저장하지 않고 독자가 제보하면 제보에만 붙습니다. 권리 제한 작품이면 실행하지 않고 검증 없이 제보할 수 있다고 안내합니다(CE-06).

**예외 흐름**
- E1 (3단계) 한도 부족: CE-05.
- E2 (5~6단계) AI 실패·시간 초과·중단: CE-04. 일부만 생성된 결과를 완료로 표시하지 않습니다.
- E3 (4단계) 인물 정보 부족: 부족한 항목을 안내하고 진행 여부를 묻습니다.

- **성공 보장:** 창작자가 고른 결과가 집필 재료로 남습니다.
- **최소 보장:** 시뮬레이션의 임시 기억·관계 변화는 원작·Fork 정본에 자동 반영되지 않습니다. 폐기한 실행 데이터가 다른 실행에 섞이지 않습니다(F-OPS-04).
- **업무 규칙:** 인물 에이전트에는 해당 인물이 그 시점에 아는 사실만 제공합니다(BR-02).
- **미정:** 인물 수·진행 횟수·분량 한도, 취소 방식, 부분 결과·실행 기록 보관 정책.
