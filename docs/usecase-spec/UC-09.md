# UC-09 다중 인물 시뮬레이션 실행·결과 선택

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자 (A5는 독자) |
| 보조 액터 | 외부 LLM API |
| 구분 | 핵심 |
| 관련 기능 ID | [F-SIM-01](../requirements.md#f-sim-01)~[11](../requirements.md#f-sim-11), [F-OPS-03](../requirements.md#f-ops-03) |
| 근거 | 기획서 16쪽, 그림 11, 12쪽 시나리오 2.1·2.2 |
| 관계 | UC-17을 include |

- **목표:** 사건 조건에 따른 인물의 행동과 인과관계를 탐색하고, 집필에 쓸 전개를 고릅니다.
- **사전조건:** 작품·기준 시점·인물 정보가 있고 대상 작품(자기 작품 또는 자기 Fork)의 편집 권한이 있습니다. 권리 제한 작품은 CE-06.
- **트리거:** 시뮬레이션 실행을 선택합니다.

**기본 흐름**
1. 창작자가 작품과 기준 회차·시점을 선택합니다.
2. 창작자가 장소, 참여 인물, 발생시킬 사건·상황, 원하는 전개 방향을 입력하고 전체 생성 결과의 분량을 선택합니다. 임시 분량 설정은 최소 3,000자, 기본 5,000자, 최대 10,000자이며 대화·행동·사건 전개를 합산합니다.
3. 시스템이 UC-17로 인물 수·진행 범위에 따른 비용을 안내하고 실행 동의를 받습니다.
4. 시스템이 기준 시점의 세계관·사건 이력과 인물별 성격·목표·기억·보유 정보를 구분해 준비합니다.
5. 스토리 계획 에이전트가 사건과 환경을 구성하고 진행 흐름을 관리합니다.
6. 인물 에이전트가 자신의 정보 범위 안에서 행동·대화하고 다른 인물과 상호작용합니다.
7. 시스템이 진행 기록(행동, 대화, 사건 전개)을 표시합니다.
8. 시스템이 전개 후보와 사건 인과관계, 기존 설정과의 충돌 의심 지점을 함께 제시합니다.
9. 창작자가 후보를 선택·수정하거나 폐기합니다.
10. 시스템이 선택·수정한 결과를 대화·행동·사건 전개와 함께 집필 재료로 저장합니다. 실행 기록과 선택하지 않은 전개 후보도 다시 조회할 수 있도록 보관합니다.

**대안 흐름**
- A1 (8단계) 대안 후보: 같은 상황에서 다른 전개 후보를 추가 생성해 비교합니다. 3단계 비용 확인을 다시 거칩니다.
- A2 (9단계) 조건 변경 재실행: 2단계로 돌아갑니다.
- A3 (10단계) 집필 연결: 선택 결과를 참고해 UC-10에서 직접 소설을 작성하거나 UC-11에서 AI와 협업해 소설로 작성합니다.
- A4 (9단계) 인물 상태 반영: 창작자가 원하면 결과의 상태 변화를 UC-06에서 채택합니다.
- A5 (1단계) 독자의 스토리 오류 검증(UC-14 A1): 독자가 제보할 회차·구절과 의심하는 모순을 입력합니다. 기준 시점은 독자가 본 회차의 끝이며, 그 시점까지 독자에게 공개된 원고·설정·인물 정보만 씁니다. 작가 비공개 설정과 인물의 비공개 지식은 쓰지 않습니다. 비용은 독자가 부담합니다(3단계). 시스템은 8단계에서 전개 후보 대신 오류 가능성 판정, 신뢰도, 근거 회차·구절을 제시합니다. 결과는 집필 재료가 아닌 독자 본인의 검증 기록으로 남기며, 독자가 제보하면 검증 결과와 근거를 제보에 함께 첨부합니다. 제보하지 않아도 독자는 자신의 검증 기록을 다시 조회할 수 있으며, 제보 전 기록을 작가에게 제공하지 않습니다. 권리 제한 작품이면 실행하지 않고 검증 없이 제보할 수 있다고 안내합니다(CE-06).

**예외 흐름**
- E1 (3단계) 한도 부족: CE-05.
- E2 (5~6단계) AI 실패·시간 초과·중단: CE-04. 생성된 부분 기록을 보관하고 미완료로 표시하며 그 아래에 중단 이유를 안내합니다. 부분 결과를 완료된 결과나 확정 설정으로 표시·반영하지 않습니다. 독자 검증 실패 시 독자는 재검토하거나 실패 사실을 표시해 작가에게 제보할 수 있습니다. 작가에게 전달하기 전 독자가 중단하면 제보는 전달하지 않습니다(UC-14 A5).
- E3 (4단계) 인물 정보 부족: 부족한 항목을 안내하고 진행 여부를 묻습니다.

- **성공 보장:** 창작자가 고른 결과가 집필 재료로 남습니다.
- **최소 보장:** 시뮬레이션의 임시 기억·관계 변화는 원작·Fork 정본에 자동 반영되지 않습니다. 폐기한 실행 데이터가 다른 실행에 섞이지 않습니다([F-OPS-04](../requirements.md#f-ops-04)).
- **기록 보관:** 시뮬레이션·검증 기록은 소유자가 삭제하기 전까지 다시 조회할 수 있도록 보관하며 플랫폼이 임의로 삭제하지 않습니다. 삭제는 기록 소유자가 결정합니다. 조회는 각 사용자의 권한과 공개 범위에 따릅니다. 세계관·설정·상태·관계의 확정 이력은 삭제 대신 이력을 보존하는 되돌리기 규칙을 따릅니다(DEC-33).
- **업무 규칙:** 인물 에이전트에는 해당 인물이 그 시점에 아는 사실만 제공합니다(BR-02).
- **미정:** 분량 선택의 구체 단위와 글자 수 계산 방식, 취소 방식의 세부 구현. 이미 제출된 검증 첨부는 독자 개인 기록 삭제 후에도 보존합니다(UC-14). 인물 수·진행 횟수의 별도 고정 한도는 두지 않는 방향이며, 분량 설정은 임시값입니다.
