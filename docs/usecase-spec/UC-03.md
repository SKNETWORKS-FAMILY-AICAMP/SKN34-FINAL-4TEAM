# UC-03 기존 원고 등록

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자(대표: 연재 작가) |
| 구분 | 핵심 |
| 관련 기능 ID | F-WLD-05 |
| 근거 | 기획서 14쪽, 그림 9, 연재 작가 정의 |
| 관계 | UC-04가 extend. 대상 작품(UC-24) 필요 |

- **목표:** 보유한 기존 소설을 STORYFORK의 작품 회차로 등록해 창작 지원에 사용할 수 있게 합니다.
- **입력 방식:** `.txt` 파일 업로드, 또는 STORYFORK 에디터에 직접 입력·붙여넣기만 지원합니다.
- **사전조건:** 로그인. 대상 작품(UC-24)의 소유자. 등록할 원고를 STORYFORK에 저장할 권한을 갖추었습니다. AI 처리 권한은 설정 추출(UC-04)을 실행할 때 따로 확인합니다.
- **트리거:** 작품에서 기존 원고 등록을 선택합니다.

**기본 흐름**
1. 창작자가 원고를 등록할 작품을 선택합니다.
2. 시스템이 권리 확인 항목(본인 저작물 여부, 계약상 제한 여부)을 안내하고 확인을 받습니다. 외부 2차 창작물이면 BR-09 고지를 함께 확인합니다.
3. 창작자가 `.txt` 파일을 올리거나 에디터에 원고를 입력합니다.
4. 시스템이 읽은 내용, 회차 구분과 순서를 미리보기로 제시합니다.
5. 창작자가 누락·순서·회차 구분을 확인하고 필요하면 조정합니다.
6. 창작자가 등록할 범위를 확정합니다.
7. 시스템이 원고를 작품의 회차로 저장하고, 성공 항목과 실패 항목을 구분해 안내합니다.
8. 시스템이 설정 추출(UC-04) 진행 여부를 묻습니다.

**대안 흐름**
- A1 (6단계) 일부 회차만 등록: 이후 추출·검토 문맥이 등록 범위로 제한됨을 안내합니다.
- A2 (8단계) 추출 생략: 창작자가 UC-02·UC-06에서 설정을 직접 정리합니다.
- A3 (8단계) 추출 진행: UC-04로 진행합니다. 세계관 업데이트가 자동으로 설정된 작품이라도 기존 원고를 한꺼번에 등록할 때는 전체 추출 비용을 안내하고 동의를 받은 뒤 실행합니다.

**예외 흐름**
- E1 (2단계) 권리 확인 거부: 등록을 진행하지 않습니다.
- E2 (3~4단계) 지원하지 않는 파일 형식(`.txt` 외)·읽기 실패: 해당 파일을 등록하지 않고 사유를 안내합니다.
- E3 (7단계) 일부 회차 저장 실패: 실패 회차를 구분 표시하며 전체 성공으로 안내하지 않습니다.
- E4 (7단계) 동일 원고 재등록: 기존 원고를 묵시적으로 덮어쓰지 않습니다.

- **성공 보장:** 확인한 원고가 회차 순서와 함께 저장되어 창작 지원의 입력으로 준비됩니다.
- **최소 보장:** 실패 항목은 저장되지 않고, 기존 원고·설정은 그대로입니다.
- **업무 규칙:** 등록은 STORYFORK 공개, 외부 플랫폼 동기화, AI 학습 동의가 아닙니다(BR-03). 외부 플랫폼 로그인·스크래핑은 제공하지 않습니다. 외부 2차 창작물은 무료 공개만 가능합니다(BR-09).
- **미정:** 크기·회차 수 한도, 회차 구분 규칙, 지원 인코딩, 중복·재등록 정책.
