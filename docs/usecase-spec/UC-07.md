# UC-07 공개·Fork 허용 조건 설정

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 작품·세계관 소유자 |
| 구분 | 핵심 |
| 관련 기능 ID | F-RGT-01~03, F-FRK-01 |
| 근거 | 기획서 14·17·20쪽, 그림 9 |
| 관계 | UC-23이 include |

- **목표:** 다른 이용자에게 허용할 사용 범위를 정합니다.
- **사전조건:** 해당 콘텐츠를 관리하고 이용을 허락할 권한이 있습니다.
- **트리거:** 공개·이용·Fork 조건 설정을 선택합니다.

**기본 흐름**
1. 소유자가 대상 작품 또는 세계관을 선택합니다.
2. 시스템이 현재 조건을 표시합니다.
3. 소유자가 공개 범위(비공개 또는 공개)를 선택합니다.
4. 소유자가 대상에 맞는 권한 항목을 각각 정합니다.
   - 작품: AI 처리, 작품 Fork 생성, Fork 작품 공개, 유료 공개. 독자 열람 여부는 3단계 공개 범위로 정합니다.
   - 세계관: 이용, 세계관 Fork, AI 처리, 이 세계관을 쓴 작품의 유료 공개 허용. 세계관 Fork는 이용과 따로 허용합니다(BR-12). 세계관 자체의 판매는 범위 밖입니다.
5. 대상이 작품이면 소유자가 작품 Fork 허용 범위(허용 안 함, 특정 회차 이후, 회차별 선택, 전체 회차 허용)를 정합니다. 전체 회차 허용은 앞으로 발행할 회차에도 적용됩니다.
6. 시스템이 외부 IP 이용 권한 확인 문구를 안내하고 확인을 받습니다.
7. 시스템이 조건을 저장하고 이용자에게 표시될 안내 내용을 보여 줍니다.

**대안 흐름**
- A1 (4단계) 열람만 허용: Fork·AI 처리를 허용하지 않는 조합으로 저장합니다.
- A2 (1단계) Fork 창작자: 자신의 Fork에 대해 공개 조건을 설정합니다. Fork 작품은 다시 Fork할 수 없으므로 Fork 허용 항목은 없습니다(BR-14). Fork 작품의 공개 조건은 원작에서 물려받지 않고 Fork 소유자가 정하되, 원작이 허용한 범위(AI 처리, Fork 작품 공개, 유료 공개)를 넘을 수 없습니다(BR-04).

**예외 흐름**
- E1 (1단계) 소유·허락 권한 없음: CE-02.
- E2 (6단계) 권리 확인 거부: 공개·Fork 허용을 저장하지 않습니다.
- E3 (7단계) 저장 실패: CE-03.
- E4 (3단계) 권리 제한 중: CE-06.

- **성공 보장:** 이후 열람·AI·Fork·공개 요청이 저장된 조건으로 판단됩니다.
- **최소 보장:** 실패 시 이전 조건이 유지됩니다.
- **업무 규칙:** 등록자의 확인만으로 외부 IP의 적법한 권한이 보장되지 않습니다(BR-03). Fork 허용과 유료 공개 허용은 별개입니다. 작품을 비공개로 바꾸면 발행된 모든 회차를 바로 숨기고, 다시 공개하면 이전에 발행돼 있던 회차만 돌아옵니다. 회차 하나만 숨기려면 UC-13의 공개 중단을 씁니다.
- **미정:** 조건 항목·문구, 회차별 선택과 특정 회차 이후 중 기본 제공 방식, 허용 철회·조건 변경이 기존 Fork에 미치는 영향, 유료 공개·배분 조건.
