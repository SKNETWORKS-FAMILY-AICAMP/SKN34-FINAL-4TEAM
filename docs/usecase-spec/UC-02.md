# UC-02 세계관 생성·관리

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자(세계관 소유자) |
| 구분 | 핵심 |
| 관련 기능 ID | F-WLD-01, F-WLD-02, F-RGT-01 |
| 근거 | 기획서 14쪽, 그림 9 |
| 관계 | UC-24의 선행 조건(작품은 세계관이 있어야 생성) |

- **목표:** 작품과 별도로 세계관을 만들고, 설정집과 인물관계도를 관리합니다.
- **사전조건:** 로그인. 기존 세계관 편집 시 해당 세계관의 수정 권한.
- **트리거:** 새 세계관 만들기 또는 기존 세계관 편집을 선택합니다.

**기본 흐름**
1. 창작자가 새 세계관 만들기를 선택합니다.
2. 창작자가 세계관 이름과 설명을 입력합니다.
3. 창작자가 설정집 항목(장소, 시대/역사, 세력/조직, 설정 규칙, 주요 사건, 참고 자료)을 추가합니다.
4. 창작자가 인물관계도에 등장인물과 인물 간 관계를 등록합니다. 인물별 시점 상태는 UC-06에서 관리합니다.
5. 창작자가 항목마다 독자 공개 여부(공개 또는 비공개)를 지정합니다. 비공개 항목에는 공개로 전환할 회차를 미리 지정할 수 있습니다.
6. 시스템이 세계관을 저장하고 변경 이력에 기록합니다.
7. 시스템이 세계관 공개 범위 설정(UC-07)과 작품 만들기(UC-24)를 안내합니다.

**대안 흐름**
- A1 (1단계) 기존 세계관 편집: 세계관을 선택해 항목을 수정합니다. 저장할 때마다 변경 이력이 추가됩니다.
- A2 (5단계) 떡밥 공개: 작품이 진행되어 비공개 항목이 드러나면, 창작자가 해당 회차부터 공개로 전환합니다. 시스템은 전환 회차를 함께 기록합니다. 작품의 세계관 자동 업데이트(UC-04)가 실행될 때도 같은 방식으로 공개 전환이 반영됩니다.
- A3 (6단계) 이력 확인·되돌리기: 변경 이력에서 이전 상태를 확인하고 되돌립니다. 되돌린 결과도 새 이력으로 남습니다.
- A4 (1단계) 기존 원고에서 시작: 이름·설명만 넣어 세계관을 만든 뒤, UC-24 → UC-03 → UC-04로 설정을 채웁니다.

**예외 흐름**
- E1 (6단계) 저장 실패: CE-03.
- E2 (6단계) 다른 곳에서 수정됨: CE-07.
- E3 (A1) 연결된 작품이 있는 세계관 삭제 요청: 삭제하지 않고 연결된 작품을 안내합니다.

- **성공 보장:** 설정집과 인물관계도가 저장되고 변경 이력이 남습니다.
- **최소 보장:** 실패 시 직전 버전이 유지됩니다.
- **업무 규칙:** 세계관 생성만으로 다른 사용자에게 공개되거나 Fork가 허용되지 않습니다(UC-07). 설정집·인물관계도 갱신은 기본 수동이며, 작품의 세계관 자동 업데이트(UC-04)를 켠 경우에만 자동으로 갱신됩니다. 변경 이력은 BR-10을 따릅니다.
- **미정:** 세계관 필수 항목, 한 세계관에 연결 가능한 작품 수, 세계관 삭제 정책, 변경 이력 보관 기간.
