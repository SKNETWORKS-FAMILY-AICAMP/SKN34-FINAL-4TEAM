# UC-02 세계관 생성·관리

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자(세계관 소유자) |
| 구분 | 핵심 |
| 관련 기능 ID | F-WLD-01, F-WLD-02, F-RGT-01, F-SET-02, F-SET-03 |
| 근거 | 기획서 14쪽, 그림 9 |
| 관계 | UC-24의 선행 조건(작품은 세계관이 있어야 생성) |

- **목표:** 작품과 별도로 세계관을 만들고, 설정집과 인물관계도를 관리합니다.
- **사전조건:** 로그인. 기존 세계관 편집 시 해당 세계관의 수정 권한.
- **트리거:** 새 세계관 만들기 또는 기존 세계관 편집을 선택합니다.

**기본 흐름**
1. 창작자가 새 세계관 만들기를 선택합니다.
2. 창작자가 세계관 이름(필수)과 설명을 입력합니다.
3. 창작자가 설정집 항목(장소, 시대/역사, 세력/조직, 설정 규칙, 주요 사건, 참고 자료)을 추가합니다.
4. 창작자가 인물관계도에 등장인물과 인물 간 관계를 등록합니다. 인물별 시점 상태는 UC-06에서 관리합니다.
5. 창작자가 항목마다 독자 공개 여부(공개 또는 비공개)를 지정합니다. 비공개 항목을 몇 화부터 공개할지는 세계관이 아니라 연결된 작품에서 작품별로 정합니다(A2, BR-10).
6. 시스템이 세계관을 저장하고 변경 이력에 기록합니다.
7. 시스템이 세계관 공개 범위 설정(UC-07)과 작품 만들기(UC-24)를 안내합니다.

**대안 흐름**
- A1 (1단계) 기존 세계관 편집: 세계관을 선택해 항목을 수정합니다. 저장할 때마다 현재 HEAD 위에 새 버전이 추가됩니다(BR-10). 이 세계관을 쓰는 자신의 작품이 여럿이면, 시스템이 저장 전에 함께 반영될 작품 목록을 안내합니다. 원고와의 충돌 확인은 선택 기능인 UC-12로 합니다.
- A2 (5단계) 떡밥 공개: 작품이 진행되어 비공개 항목이 드러나면, 창작자가 그 작품의 해당 회차부터 공개로 전환합니다(UC-06 A3). 시스템은 전환 회차를 작품별로 기록합니다. 작품의 세계관 자동 업데이트(UC-04)가 실행될 때도 같은 방식으로 공개 전환이 반영됩니다.
- A3 (6단계) 이력 확인·되돌리기: 변경 이력에서 이전 상태를 확인하고 되돌립니다. 되돌린 결과도 새 이력으로 남습니다.
- A4 (1단계) 기존 원고에서 시작: 이름만 넣어 세계관을 만든 뒤, UC-24 → UC-03 → UC-04로 설정을 채웁니다.
- A5 (1단계) 세계관 삭제: 연결된 작품이 없을 때만 삭제합니다(E3).
- A6 (1단계) 기존 세계관 조합: 플랫폼 기본 세계관, 자신의 세계관, 이용이 허용된 공개 세계관을 여러 개 골라 필요한 항목만 복사해 새 세계관을 만듭니다. 새 세계관은 작가 소유입니다. 플랫폼 기본 세계관만 쓰면 원본 관계가 없는 새 세계관이고, 다른 사용자의 세계관이 하나라도 섞이면 세계관 Fork로 보고 출처를 기록합니다(BR-12).
- A7 (4단계) 인물관계도만 새로 만들기: 인물관계도는 세계관의 일부입니다. 세계관은 마음에 들지만 인물관계도를 바꾸고 싶다면, 기존 세계관은 그대로 연결하고 인물관계도만 담은 새 세계관을 만들어 함께 연결합니다. 소유·권한·버전·연결 제한은 세계관 규칙을 따르며, 같은 인물이 겹치면 UC-12로 확인합니다.
- A8 (1단계) 장르 기본 세계관에서 시작: 창작자가 장르를 고르면 시스템이 플랫폼이 제공하는 기본 세계관을 복사해 작가 소유의 새 세계관으로 만듭니다. 원본 관계가 없으며, 플랫폼이 기본 세계관을 바꿔도 반영되지 않습니다.
- A9 (1단계) 연결한 다른 사용자 세계관 수정: 창작자가 작품에 연결한 다른 사용자 세계관을 고치려 하면, 시스템이 이후 원본 변경이 반영되지 않는다는 점을 안내하고 확인을 받은 뒤 그 시점 HEAD의 공개 항목만 세계관 Fork로 복사하고(비공개 항목·원작 작품의 회차 기록은 제외) 작품의 연결을 Fork로 교체합니다(BR-12). 연결 수는 그대로이며 첫 회차 발행 후에도 할 수 있습니다(UC-24 A3).

**예외 흐름**
- E1 (6단계) 저장 실패: CE-03.
- E2 (6단계) 다른 곳에서 수정됨: CE-07.
- E3 (A5) 연결된 작품이 있는 세계관 삭제 요청: 삭제하지 않고 연결된 작품을 안내합니다.
- E4 (A9) 원본 소유자가 세계관 Fork를 허용하지 않음: 복사하지 않고, 원본을 그대로 참조해야 한다는 점을 안내합니다(UC-07).

- **성공 보장:** 설정집과 인물관계도가 저장되고 변경 이력이 남습니다.
- **최소 보장:** 실패 시 직전 버전이 유지됩니다.
- **업무 규칙:** 세계관 생성만으로 다른 사용자에게 공개되거나 Fork가 허용되지 않습니다(UC-07). 설정집·인물관계도 갱신은 기본 수동이며, 작품의 세계관 자동 업데이트(UC-04)를 켠 경우에만 자동으로 갱신됩니다. 변경 이력은 BR-10을 따르며 무기한 보관합니다. 인물 정보를 포함한 세계관 전체를 Gitea에 저장합니다. 한 세계관에 연결할 수 있는 작품 수는 제한하지 않습니다.
- **미정:** 장르 기본 세계관의 장르 목록·제공 범위·관리 주체, 세계관 Fork의 원본 변경 알림·원하는 항목만 골라 가져오기.
