# UC-05 허용된 공개 세계관 이용

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자(세계관 이용자) |
| 구분 | 핵심 |
| 관련 기능 ID | F-WLD-03, F-WLD-08, F-RGT-03 |
| 근거 | 기획서 14쪽, 그림 9 |
| 관계 | UC-24를 extend |

- **목표:** 이용이 허용된 다른 사용자의 세계관을 자신의 작품에 연결합니다.
- **사전조건:** 로그인. 대상 세계관이 공개 상태입니다(UC-07).
- **트리거:** 작품 생성(UC-24) 중 공개 세계관 사용을 선택합니다.

**기본 흐름**
1. 창작자가 공개 세계관 목록을 엽니다.
2. 시스템이 이용 가능한 세계관과 각 세계관의 허용 범위(이용, 세계관 Fork, 이 세계관을 쓴 작품의 유료 공개 허용)를 표시합니다. 이용자 비노출 항목은 보여 주지 않습니다(UC-02 5단계).
3. 창작자가 세계관 내용과 허용 범위를 확인하고 선택합니다.
4. 시스템이 해당 사용자·작업의 이용 가능 여부를 확인합니다.
5. 시스템이 작품에 세계관을 이용 관계로 연결하고 UC-24로 돌아갑니다.

**대안 흐름**
- A1 (3단계) 조건 불일치: 다른 세계관을 고르거나 UC-02에서 새 세계관을 만듭니다.

**예외 흐름**
- E1 (4단계) 요청 작업에 필요한 권한 없음(예: 세계관 Fork를 허용하지 않은 세계관의 수정): 해당 사용을 허용하지 않고 범위를 안내합니다.
- E2 (5단계) 저장 실패: CE-03.
- E3 (4단계) 권리 제한 세계관: CE-06.

- **성공 보장:** 작품이 공개 세계관을 참조하고, 작품의 사건·변화는 작품에만 저장됩니다.
- **최소 보장:** 타인 세계관의 정본은 변경되지 않습니다.
- **업무 규칙:** 공개 세계관 이용은 정본 수정 권한이 아닙니다. 이용자는 이용자 노출 항목만 사용하며, 비노출 항목은 소유자가 노출로 바꾼 뒤에만 사용할 수 있습니다. 고치지 않고 쓰면 원본을 그대로 참조해 소유자의 이후 변경(최신 공개본)을 따릅니다. 고치려면 세계관 전체를 작가 소유의 세계관 Fork로 복사한 뒤 고치며, 작품의 연결은 Fork로 교체됩니다(UC-02 A9). 세계관 Fork는 원본 업데이트를 받지 않고 출처(원본 세계관·원작자)를 기록하며, 소유자가 세계관 Fork를 허용한 경우에만 만들 수 있습니다(BR-12, UC-07). 원본에서 새로 들어오거나 다른 작품에서 공개된 항목도 이 작품에는 작가만 보는 독자 비공개 상태로 들어오고, 작가가 이 작품의 회차 기준으로 공개 전환해야 독자에게 보입니다(BR-10). 이용 허가가 철회되어도 이미 연결된 작품의 연결은 끊지 않으며, 철회 시점 상태로 고정하고 이후 변경은 반영하지 않습니다. 새 연결만 막습니다. 소유자가 세계관을 비공개로 바꾸는 것도 이용 허가 철회와 같이 처리하며, 이때 새 세계관 Fork도 막습니다. 이미 만든 세계관 Fork는 영향을 받지 않습니다.
- **미정:** 없음. 사용 중인 세계관이 바뀌면(자동 반영 포함) 이용 작품 소유자에게, 원본 세계관이 바뀌면 세계관 Fork 소유자에게 알립니다(UC-27). 세계관 Fork는 원본 변경을 가져오지 않습니다(BR-12).
