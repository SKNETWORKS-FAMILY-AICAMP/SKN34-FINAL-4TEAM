# UC-05 허용된 공개 세계관 이용

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 창작자(세계관 이용자) |
| 구분 | 핵심 |
| 관련 기능 ID | F-WLD-03, F-WLD-08, F-RGT-03 |
| 근거 | 기획서 14쪽, 그림 9 |
| 관계 | UC-24를 extend |

- **목표:** 이용이 허용된 다른 사용자의 세계관을 자신의 작품에 연결합니다.
- **사전조건:** 로그인. 대상 세계관이 공개 상태입니다(UC-07).
- **트리거:** 작품 생성(UC-24) 중 공개 세계관 사용을 선택합니다.

**기본 흐름**
1. 창작자가 공개 세계관 목록을 엽니다.
2. 시스템이 이용 가능한 세계관과 각 세계관의 허용 범위(작품 창작, AI 처리, 유료 공개 등)를 표시합니다. 세계관의 비공개 항목은 보여 주지 않습니다.
3. 창작자가 세계관 내용과 허용 범위를 확인하고 선택합니다.
4. 시스템이 해당 사용자·작업의 이용 가능 여부를 확인합니다.
5. 시스템이 작품에 세계관을 이용 관계로 연결하고 UC-24로 돌아갑니다.

**대안 흐름**
- A1 (3단계) 조건 불일치: 다른 세계관을 고르거나 UC-02에서 새 세계관을 만듭니다.

**예외 흐름**
- E1 (4단계) 요청 작업에 필요한 권한 없음(예: AI 처리 불허): 해당 사용을 허용하지 않고 범위를 안내합니다.
- E2 (5단계) 저장 실패: CE-03.
- E3 (4단계) 권리 제한 세계관: CE-06.

- **성공 보장:** 작품이 공개 세계관을 참조하고, 작품의 사건·변화는 작품에만 저장됩니다.
- **최소 보장:** 타인 세계관의 정본은 변경되지 않습니다.
- **업무 규칙:** 공개 세계관 이용은 정본 수정 권한이 아닙니다. 이용자는 공개 항목만 사용하며, 소유자의 비공개 항목은 공개로 전환된 뒤에만 사용할 수 있습니다.
- **미정:** 세계관 소유자의 이후 변경을 이용 작품에 반영하는 방식, 이용 허가 철회의 영향.
