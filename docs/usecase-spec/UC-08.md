# UC-08 원작 회차 기반 Fork 생성

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
| 항목 | 내용 |
|---|---|
| 주 액터 | 독자 |
| 구분 | 핵심 |
| 관련 기능 ID | F-FRK-01~07, F-OPS-04 |
| 근거 | 기획서 12쪽 시나리오 2.1, 17쪽 |
| 관계 | UC-01을 extend |
- **목표:** 허용된 원작의 특정 회차 이후를 독립적으로 창작할 작품을 만듭니다.
- **사전조건:** 로그인. 대상 회차를 열람할 수 있고, 해당 시점의 Fork가 허용되어 있으며, 원작의 세계관이 공개 상태입니다(UC-07). 대상은 원작이어야 하며(Fork 작품은 다시 Fork할 수 없음), 독자가 이 원작에서 아직 Fork를 만들지 않았어야 합니다(BR-14).
- **트리거:** 원작 회차 열람(UC-01) 중 Fork를 선택합니다.
**기본 흐름**
1. 독자가 원작에서 Fork 가능한 회차를 확인합니다.
2. 독자가 분기 기준 회차(해당 회차 종료 시점)를 선택합니다.
3. 시스템이 원작의 이용 조건(AI 처리, Fork 작품 공개, 유료 공개 허용 여부)을 안내합니다.
4. 독자가 조건을 확인하고 Fork 작품의 제목과 바꿀 전개 방향(한 줄)을 입력합니다.
5. 시스템이 Fork 권한과 기준 회차의 허용 여부를 다시 확인합니다.
6. 시스템이 기준 회차까지의 회차 원고 버전과 분기 시점의 세계관·인물관계도(연결된 세계관 모두)를 불변으로 고정합니다. 분기 시점까지 이 원작에서 독자에게 공개된 항목(원작의 작품별 공개 회차 기준, BR-10)만 포함하고 비공개 항목은 제외합니다. 원작에 회차별 설정 이력이 없으면(기존 원고 일괄 등록 등) 회차 시점을 구분할 수 없으므로, 현재 공개 상태의 세계관·인물관계도를 고정합니다. 이때 이후 회차의 설정(예: 1화에서 분기해도 61화 기준 설정)이 섞일 수 있다고 독자에게 경고하고 동의를 받습니다.
7. 시스템이 기준 원작·회차와 연결된 Fork 작품을 만들고 독자를 소유자로 지정합니다.
8. 시스템이 Fork 작품 화면을 열고 다음 행동(새 전개 입력, 시뮬레이션, 직접 집필, 작품 설정)을 안내합니다.
9. 독자가 새로운 사건과 전개 방향을 입력합니다. Fork 작품은 기준 회차의 다음 회차부터 작성합니다.
**대안 흐름**
- A1 (8단계) 시뮬레이션: UC-09로 진행합니다.
- A2 (8단계) 직접 집필: UC-10으로 진행합니다. AI 없이 무료로 진행할 수 있습니다.
- A3 (8단계) 작품 설정: UC-24 7단계에서 세계관 업데이트·표기 오류 처리·자율 연재를 설정합니다.
- A4 (1단계) 피드백 응대에서 진입: UC-15의 Fork 안내로 들어오면 2단계부터 진행합니다.
- A5 (8단계) 인물관계도 새로 정리: 고정된 세계관은 그대로 두고, 인물관계도만 담은 Fork 작품 전용 세계관을 만들어 다음 회차부터 씁니다(UC-02 A7, UC-06). 분기 시점 기록은 그대로 남습니다.
**예외 흐름**
- E1 (5단계) 허용되지 않은 회차·비공개 세계관·조건 변경: 생성하지 않고 사유를 안내합니다.
- E2 (5단계) 권리 제한 원작: CE-06.
- E3 (6단계) 기준 정보 불완전: 생성하지 않으며 성공으로 안내하지 않습니다.
- E4 (7단계) 생성 실패: CE-03. 부분 생성된 Fork를 남기지 않습니다.
- E5 (5단계) Fork 작품을 Fork하려 하거나, 이미 이 원작에서 Fork를 만든 독자: 생성하지 않고 사유를 안내합니다.
- **성공 보장:** 원작과 분리된 Fork 작품이 고정된 기준 정보와 함께 생성됩니다.
- **최소 보장:** 원작 데이터는 어떤 경우에도 변경되지 않습니다.
- **업무 규칙:** BR-04를 따릅니다. 분기 이후 회차·설정은 Fork 소유자가 수정할 수 있습니다. 원작에서 나중에 공개로 전환된 항목은 기존 Fork에 들어가지 않습니다. 외부 2차 창작물도 Fork 원작이 될 수 있습니다. 한 독자는 한 원작에서 Fork를 1번만 만들 수 있고, Fork 작품을 다시 Fork할 수는 없습니다(BR-14). Fork 생성은 무료입니다. Fork는 원작의 회차·세계관·인물관계도만 받고, 작품 운영 설정(세계관 업데이트·표기 오류 처리·자율 연재)과 공개 조건은 받지 않습니다. Fork 소유자가 기본값부터 정합니다(BR-04, UC-24 A6). 분기 이후 설정 수정은 Fork 작품 전용 세계관으로 저장되며 다른 작품에 연결하거나 공개할 수 없습니다. 원작이 다른 작가의 세계관을 빌려 쓰면, 그 항목은 원래 작가가 세계관 Fork를 허용했을 때만 고칠 수 있고 그 작가의 제한(AI 처리·유료 공개 금지 등)도 Fork에 적용됩니다. 새 설정 추가는 언제나 가능합니다.
- **미정:** 고정 수단(분기 시점 버전을 참조하는 원칙은 확정, Gitea 브랜치·커밋 참조 등 구현 수단은 미정), 원작 삭제 시 Fork 처리, 기준 회차까지 읽어야 Fork할 수 있는지(UI 프로토타입 U04에서 제안).
