# UC-08 원작 회차 기반 Fork 생성

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
>
> **문서 상태:** 최신 MVP 방향을 반영한 목표 명세이며, 현재 `core-api`에 콘텐츠 구현 일부가 있으나 이 목표 명세 전체와 서비스 분리 완료를 뜻하지 않습니다. 이 명세와 과거 문구가 충돌하면 [최신 결정](../design/decisions.md#결정-목록)과 아래 현재 명세를 우선합니다.

## 현재 MVP 명세

| 항목 | 내용 |
|---|---|
| 목표 서비스 책임(DEC-41) | 콘텐츠 서비스 — 콘텐츠 인가·정본·저장·발행의 소유자. Core는 회원·정산·알림, AI는 요청된 생성·검토만 담당 |
| 주 액터 | 독자(Fork 생성 후에는 해당 Fork의 창작자) |
| 구분 | 핵심 |
| 관련 기능 ID | [F-FRK-01](../requirements.md#f-frk-01)~[07](../requirements.md#f-frk-07), [F-OPS-04](../requirements.md#f-ops-04) |
| 근거 | 기획서 12쪽 시나리오 2.1, 17쪽; DEC-29·32~38 |
| 관계 | UC-01을 extend |

- **목표:** 허용된 원작의 특정 회차를 기준으로 독자 자신의 Fork 작품을 만들고 이후 이야기를 창작합니다.
- **사전조건:** 로그인하고 대상 원작과 기준 회차를 열람할 수 있으며 해당 회차의 Fork 생성이 허용되어 있습니다. 기존 규칙상 한 독자는 한 원작에서 작품 Fork를 한 번만 만들 수 있고, Fork 작품은 다시 Fork할 수 없습니다(BR-14).
- **트리거:** 원작 회차를 읽다가 Fork를 선택합니다(UC-01).

### 기본 흐름

1. 독자가 원작에서 Fork 가능한 회차를 확인하고 기준 회차의 종료 시점을 선택합니다. 공개 중단된 회차는 새로운 Fork의 기준으로 선택할 수 없습니다.
2. 시스템이 원작의 Fork 생성·Fork 작품 공개 조건과 허용 회차 범위를 안내하고, 기준 회차까지의 원작 내용에 관한 스포일러 경고를 표시합니다. 독자가 해당 회차까지 읽었는지 확인하지 않습니다. 허용 회차 범위는 전체 공개 회차·특정 회차 이후·회차별 선택을 나타내는 방향입니다(UC-07).
3. 독자가 안내된 조건을 확인하고 자신의 Fork 작품 제목을 입력합니다. 바꿀 전개 방향은 선택적으로 입력하거나 집필하며 정할 수 있습니다.
4. 시스템이 로그인·열람 권한, 원작의 현재 Fork 생성 조건과 기준 회차의 허용 여부, 기존 Fork 횟수 및 원작 여부를 확인합니다. 조건이 확인 이후 바뀌었다면 새 조건을 안내하고 다시 확인받습니다.
5. 시스템이 원작·기준 회차·원고 버전과 당시 허용된 자료의 **기준 기록**을 보존하고, 독자를 소유자로 하는 작품 Fork를 만듭니다. 기준 기록의 구체적 저장·검증 방식은 미정입니다.
6. 작품 Fork는 각 작품에 대응하는 세계관 하나를 가지며 기준 회차에 공개되고 창작자에게 허용된 **원작 세계관 전체**를 이어받습니다. 인물의 기본 설정과 그 회차의 상태·지식·인물관계도도 포함됩니다. 독립 전에는 이 Fork의 세계관이 허용된 원본 내용을 참조하고 기준 회차에 영향을 주는 변경을 따릅니다. 작품이 원본 세계관에 직접 공동 연결된다는 뜻은 아니며 실제 참조 모델은 미정입니다(DEC-32·33·37).
7. 시스템이 생성된 Fork 작품과 창작 경로를 안내합니다. 창작자는 직접 집필하거나(UC-10) 선택적으로 원작 원고 옆 AI 대화·시뮬레이션을 이용하고, 필요하면 관련 설정·인물·관계로 이동할 수 있습니다. 설정 목록 선택이나 AI 사용을 강제하지 않습니다.

### 생성 이후 세계관과 원본 변경

- **독립 전:** 창작자가 세계관을 수정하기 전에는 기준 회차에 영향을 주는 원본의 공개 변경을 따라갑니다. 예를 들어 원작자가 10화 작업 중 내용을 추가했더라도 그 변경이 5화에 적용·공개되면 5화에서 만든 Fork에 반영됩니다. 최초 기준 기록과 현재 원본 참조는 구분합니다.
- **최초 수정:** 창작자가 설정·인물·관계를 처음 수정하면, 기준 회차에 공개되고 허용된 세계관 전체를 인물 상태·지식·인물관계도와 함께 창작자 소유로 독립 복사한 뒤 수정합니다. 이어받은 설정은 항목별 제한 없이 수정할 수 있으며 원작은 수정하지 않습니다(DEC-37·38).
- **독립 후:** 기준 회차에 영향을 주는 원본 변경을 창작자에게 알리고 반영 여부를 선택하게 합니다. 선택하기 전에는 자동 반영하지 않고, 거절한 변경도 나중에 반영할 수 있습니다. 반영 시 권한을 확인하고 기존 이력을 보존합니다(DEC-34·37, UC-27).
- **집필과 공개:** 창작자는 기준 이후의 이야기를 직접 작성하거나 AI 제안·시뮬레이션을 선택적으로 활용합니다. AI 대화·제안만으로 콘텐츠를 저장·반영하거나 발행하지 않습니다. 채택·저장과 공개·발행은 별개입니다.

### 대안 흐름

- **A1 (7단계) — AI 보조·시뮬레이션:** 창작자가 원할 때 대화·생성 보조 또는 시뮬레이션을 이용하고 결과를 검토·선택하거나 거절합니다. 원고 수정안은 원문과 비교해 채택·수정·거절할 수 있습니다(UC-09·UC-11).
- **A2 (7단계) — 설정 수정:** 창작자가 집필 전이나 중에 세계관·인물·관계를 수정합니다. 첫 수정이면 위의 세계관 전체 독립을 거칩니다(UC-02·UC-06).
- **A3 (1단계) — 피드백에서 진입:** 작품에 대한 제안 이후 Fork 안내에서 진입한 경우에도 원작·회차·조건을 동일하게 확인합니다(UC-14).

### 예외 흐름

- **E1 (1·4단계) — 미인증·권한 부족:** 요청을 처리하지 않고 로그인 또는 권한 부족을 안내하며 비공개 정보나 존재 여부를 노출하지 않습니다(CE-01·02).
- **E2 (4단계) — 회차·조건 불허 또는 변경:** 허용되지 않은 회차는 Fork하지 않습니다. 확인 뒤 조건이 달라지면 현재 조건을 다시 안내하고 재확인하며, 허용되지 않으면 생성하지 않습니다.
- **E3 (4단계) — 권리 제한:** 해당 기능의 이용 제한을 적용합니다. 권리 침해 신고·법적 제한은 일반적인 조건 철회와 별도로 처리합니다(CE-06·UC-20).
- **E4 (4·5단계) — 기준 정보 불완전·버전 충돌:** 기준 회차에 필요한 정보와 권한을 확인할 수 없거나 기준 버전이 변경되면 Fork 생성 성공으로 표시하지 않고 확인·조치가 필요함을 알립니다. 최신 내용을 과거의 확정 상태로 가장하지 않습니다(CE-07).
- **E5 (5단계·생성 이후) — 저장·복사·AI 실패:** 실패를 알리고 완료로 표시하지 않으며 기존 원작과 확정 내용을 보존합니다(CE-03·04). 불완전하게 생성된 Fork는 완성된 작품으로 노출하지 않습니다. 부분 처리의 정리·복구 방식은 구현 전 결정합니다.
- **E6 (4단계) — 중복 Fork 또는 Fork의 Fork:** 기존 횟수 제한을 넘거나 Fork 작품을 다시 Fork하려 하면 생성하지 않고 사유를 안내합니다(BR-14).

### 보장과 업무 규칙

- **성공 보장:** 원작과 구별되는 Fork 작품이 기준 기록과 함께 생성되고, 창작자는 자기 작품의 소유 권한을 가집니다. 세계관의 원본 참조와 독립은 위 흐름을 따릅니다.
- **최소 보장:** 창작자의 Fork 작업은 원작을 수정하지 않습니다. 실패를 성공으로 표시하지 않고 기존 원작과 확정 내용을 보존합니다.
- **공개와 철회:** 작품의 Fork 생성 허용과 Fork 작품 공개 허용은 별개이며 변경 이력은 보존합니다. 생성 허용을 철회하면 새 Fork만 막고 기존 Fork 창작은 유지합니다. 공개 허용을 철회해도 이미 공개한 Fork는 계속 공개·발행할 수 있으며, 미공개 Fork의 새 공개는 제한합니다. 공개 Fork에는 원작과 원작자를 표시합니다(DEC-38·UC-07).
- **원작 비공개·공개 중단:** 기존 기획에서 원작이 비공개로 전환되거나 회차 공개가 중단되어도 기존 Fork와 이미 공개된 상태는 유지합니다. 비공개 원작이나 공개 중단된 회차를 기준으로 새 Fork를 만들 수 없으며, 원작이 비공개일 때 원작 링크는 ‘비공개 원작’으로 표시합니다(UC-07·BR-04). 독립 전 원본 참조 자료의 접근·처리 세부는 아래 미정 사항을 따릅니다.
- **원작 삭제·탈퇴:** 원작 삭제는 소프트 삭제이며(DEC-42) Fork는 원작 행을 그대로 참조하고 원작 링크를 ‘삭제된 원작’으로 표시합니다. 원작 삭제 또는 작가 탈퇴 시 Fork 독자에게 기준 회차까지의 원작 원고를 보여 주지 않으며, 그 원고는 Fork 창작자의 참고·허용된 AI 문맥에만 쓰고 숨긴 본문이 AI 출력·발행 원고에 길게 그대로 나타나지 않도록 합니다(BR-04). 원본을 따라가던 Fork는 원작 삭제 시점의 상태로 고정되며 이후 원본 변경 알림은 없습니다.
- **허용 범위:** 설정은 항목별 공개·비공개와 회차별 공개 범위를 따릅니다. 참조·복사·알림·AI 입력에서 미발행 원고, 비공개·권한 밖 정보와 인물별로 허용되지 않은 지식을 노출하지 않습니다(DEC-36·37, BR-02).
- **비용·범위:** 기존 기획에서 작품 Fork 생성과 직접 집필은 무료입니다(BR-08). 유료 공개는 MVP 이후이며, 작품 Fork와 무관한 타인 세계관 직접 이용도 MVP 이후입니다(DEC-22·23·35).
- **설정과 공개:** Fork 창작자가 설정·인물·관계를 추가하거나 수정할 때 원작을 변경하지 않습니다. Fork 작품의 공개 조건은 원작 설정을 그대로 물려받지 않고 창작자가 정합니다. 최초 공개는 원작의 Fork 공개 허용을 따르며, 이미 공개한 Fork는 위 철회 규칙을 따릅니다(BR-04·UC-07·DEC-38). 설정 변경 이력은 이전 내용을 지우지 않고 남깁니다(DEC-33).
- **원작의 권리:** 원작 등록·공개나 등록자의 확인만으로 2차 창작의 법적 권리가 생기지는 않습니다. 권리 확인은 등록자 책임이며 플랫폼이 각 작품의 권리를 직접 검증하지 않습니다(DEC-38). 외부 2차 창작물도 권한과 조건을 충족하면 Fork 원작이 될 수 있다는 기존 기획을 유지하되, 플랫폼 내 Fork 작품의 재Fork 금지는 그대로 적용합니다(BR-09·14).

### 미정 사항

- 기준 이전 원고·장면을 Fork에서 편집할 수 있는 범위와 구체적인 창작 화면 진입 시점.
- 기준 회차의 공개 원고·설정·인물 상태·지식·관계에 대한 실제 접근 판정과 기준 기록의 완전성·저장 방식. 인물별 지식과 공개의 세부 관리 방식은 팀 논의가 필요합니다.
- 독립 복사와 선택 반영의 충돌 처리, 그래프와 다른 저장소 사이의 동기화·실패 복구, 알림 전달 방식.
- Fork 허용 회차의 상세 경계와 입력 방식, 조건 재확인 화면 및 기록의 물리 표현. [Fork ERD](../design/erd/core/fork-and-checkpoint.md)는 논리 후보입니다.
- 원작 삭제·탈퇴 시 Fork의 원본 참조 유지는 DEC-42로 확정했습니다. 공개 중단 시 기존 Fork 접근의 세부는 미정입니다. 권리 제한을 일반적인 허용 철회와 혼동하지 않습니다.

## 과거 상세 명세 원문

아래는 비교를 위해 보존한 이전 기획 원문입니다. 최초 생성 시 전체 복사, 이후 원본 변경 미반영, 현재 내용의 과거 대체, 유료 공개와 여러 세계관 연결 등 **현재 결정과 충돌하는 부분은 과거 기획**입니다. 충돌하지 않는 규칙은 위 현재 명세와 관련 최신 결정을 따릅니다.

- **목표:** 허용된 원작의 특정 회차 이후를 독립적으로 창작할 작품을 만듭니다.
- **사전조건:** 로그인. 대상 회차를 열람할 수 있고, 해당 시점의 Fork가 허용되어 있습니다(UC-07). 원작 세계관의 세계관 공개 여부는 따지지 않습니다(BR-04). 대상은 원작이어야 하며(Fork 작품은 다시 Fork할 수 없음), 독자가 이 원작에서 아직 Fork를 만들지 않았어야 합니다(BR-14).
- **트리거:** 원작 회차 열람(UC-01) 중 Fork를 선택합니다.
**기본 흐름**
1. 독자가 원작에서 Fork 가능한 회차를 확인합니다.
2. 독자가 분기 기준 회차(해당 회차 종료 시점)를 선택합니다.
3. 시스템이 원작의 이용 조건(Fork 작품 공개, 유료 공개 허용 여부)을 안내하고, 기준 회차까지의 내용이 Fork 작품에 포함된다는 스포일러 경고를 보여 줍니다. 독자가 기준 회차까지 읽었는지는 확인하지 않습니다.
4. 독자가 조건을 확인하고 Fork 작품의 제목과 바꿀 전개 방향(한 줄)을 입력합니다.
5. 시스템이 Fork 권한과 기준 회차의 허용 여부를 다시 확인합니다.
6. 시스템이 기준 회차까지의 회차 원고 버전과 분기 시점의 세계관·인물관계도(연결된 세계관 모두)를 불변으로 고정합니다. 분기 시점에 공개된 세계관·인물관계도 항목의 내용은 Fork 전용 세계관의 첫 갱신 기록으로, 기준 회차 시점의 원작 작품별 회차 기록은 Fork 작품의 기록으로 같은 트랜잭션에서 복사합니다(DEC-20). 분기 시점까지 이 원작에서 독자에게 공개된 항목(원작의 작품별 공개 회차 기준, BR-10)만 포함하고 비공개 항목은 제외합니다. 원작에 회차별 설정 이력이 없으면(기존 원고 일괄 등록 등) 회차 시점을 구분할 수 없으므로, 현재 공개 상태의 세계관·인물관계도를 고정합니다. 이때 이후 회차의 설정(예: 1화에서 분기해도 61화 기준 설정)이 섞일 수 있다고 독자에게 경고하고 동의를 받습니다.
7. 시스템이 기준 원작·회차와 연결된 Fork 작품을 만들고 독자를 소유자로 지정합니다.
8. 시스템이 Fork 작품 화면을 열고 다음 행동(새 전개 입력, 시뮬레이션, 직접 집필, 작품 설정)을 안내합니다.
9. 독자가 새로운 사건과 전개 방향을 입력합니다. Fork 작품은 기준 회차의 다음 회차부터 작성합니다.

**대안 흐름**
- A1 (8단계) 시뮬레이션: UC-09로 진행합니다.
- A2 (8단계) 직접 집필: UC-10으로 진행합니다. AI 없이 무료로 진행할 수 있습니다.
- A3 (8단계) 작품 설정: UC-24 7단계에서 세계관 업데이트·표기 오류 처리·자율 연재를 설정합니다.
- A4 (1단계) 피드백에서 진입: UC-14의 제안 등록 후 Fork 안내로 들어오면 2단계부터 진행합니다.
- A5 (8단계) 인물관계도 새로 정리: 고정된 세계관은 그대로 두고, 인물관계도만 담은 Fork 작품 전용 세계관을 만들어 다음 회차부터 씁니다(세계관 연결 수 5개에 포함, UC-24 A6)(UC-02 A7, UC-06). 분기 시점 기록은 그대로 남습니다.
**예외 흐름**
- E1 (5단계) 허용되지 않은 회차·조건 변경: 생성하지 않고 사유를 안내합니다.
- E2 (5단계) 권리 제한 원작: CE-06.
- E3 (6단계) 기준 정보 불완전: 생성하지 않으며 성공으로 안내하지 않습니다.
- E4 (7단계) 생성 실패: CE-03. 부분 생성된 Fork를 남기지 않습니다.
- E5 (5단계) Fork 작품을 Fork하려 하거나, 이미 이 원작에서 Fork를 만든 독자: 생성하지 않고 사유를 안내합니다.
- **성공 보장:** 원작과 분리된 Fork 작품이 고정된 기준 정보와 함께 생성됩니다.
- **최소 보장:** 원작 데이터는 어떤 경우에도 변경되지 않습니다.
- **업무 규칙:** BR-04를 따릅니다. 분기 이후 회차·설정은 Fork 소유자가 수정할 수 있습니다. 원작에서 나중에 공개로 전환된 항목은 기존 Fork에 들어가지 않습니다. 외부 2차 창작물도 Fork 원작이 될 수 있습니다. 한 독자는 한 원작에서 Fork를 1번만 만들 수 있고, Fork 작품을 다시 Fork할 수는 없습니다(BR-14). Fork 생성은 무료입니다. Fork는 원작의 회차·세계관·인물관계도만 받고, 작품 운영 설정(세계관 업데이트·표기 오류 처리·자율 연재)과 공개 조건은 받지 않습니다. Fork 소유자가 기본값부터 정합니다(BR-04, UC-24 A6). 분기 이후 설정 수정은 Fork 작품 전용 세계관으로 저장되며 다른 작품에 연결하거나 공개할 수 없습니다. 원작이 다른 작가의 세계관을 빌려 쓰면, 그 항목은 원래 작가가 세계관 Fork를 허용했을 때만 고칠 수 있고 그 작가의 제한(유료 공개 금지 등)도 Fork에 적용됩니다. 새 설정 추가는 언제나 가능합니다. 기존 Fork는 고정본을 가지므로 원작이 삭제되어도 유지하며, 원작 링크는 "삭제된 원작"으로 표시합니다. 원작 작품이 권리 신고로 조치되면 Fork에도 같은 조치를 적용합니다(UC-20). 원작의 조건 철회·비공개 전환·회차 공개 중단은 기존 Fork를 바꾸지 않고 새 행위만 막습니다(BR-04, UC-07). 공개 중단된 회차는 새 Fork의 분기 기준으로 고를 수 없습니다. 원작이 삭제되거나 원작 작가가 탈퇴하면 Fork 독자에게 분기 전 회차 본문을 보여 주지 않으며, 고정본은 Fork 소유자의 집필 참고와 AI 문맥으로만 씁니다. 이때 AI 출력은 숨긴 분기 전 본문을 길게 그대로 옮기지 않으며(허용 길이는 구현 시 결정), 이 제한은 Fork 소유자가 채택·발행하는 원고에도 적용됩니다. 원작에서 받은 고정 세계관도 세계관 연결 수(최대 5개)에 포함하므로, 원작이 이미 5개를 연결했으면 Fork에서 세계관을 추가할 수 없습니다.
- **미정:** 복사 테이블 구조 등 구현 세부(구현 시 Flyway로 결정).
