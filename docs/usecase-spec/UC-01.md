# UC-01 작품·회차 열람

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 독자 |
| 구분 | 지원 |
| 관련 기능 ID | F-PUB-01, F-PUB-03, F-PUB-04 |
| 근거 | 기획서 12·20쪽 |
| 관계 | UC-08·UC-14가 이 유스케이스를 extend |

- **목표:** 허용된 작품·회차를 읽고 공개 설정·Fork 가능 여부를 확인합니다.
- **사전조건:** 대상 작품·회차가 공개 상태이고 독자에게 열람 조건이 충족됩니다. 공개 회차 열람과 작품 탐색은 비회원도 할 수 있습니다(UC-22).
- **트리거:** 작품 목록이나 검색 결과에서 작품을 선택합니다.

**기본 흐름**
1. 독자가 작품 목록을 엽니다.
2. 시스템이 열람 가능한 작품을 원작과 Fork 작품으로 구분해 표시합니다.
3. 독자가 작품을 선택합니다.
4. 시스템이 작품 정보, 공개 회차 목록과 순서, 회차별 Fork 허용 여부를 표시합니다.
5. 독자가 회차를 선택합니다.
6. 시스템이 열람 권한을 확인하고 발행본 원고를 표시합니다.
7. 독자가 이전·다음 회차로 이동하며 읽습니다.

**대안 흐름**
- A1 (6단계) Fork: Fork가 허용된 회차이면 Fork 선택지를 표시하고, 독자가 선택하면 UC-08로 진행합니다.
- A2 (6단계) 피드백: 독자가 질문·오류 제보를 선택하면 UC-14로 진행합니다.
- A3 (2단계) Fork 작품 열람: Fork 작품은 기준 원작·기준 회차 정보를 함께 표시합니다.
- A4 (1단계) 이어 읽기: 로그인한 독자에게 마지막으로 읽은 회차를 표시하고, 독자가 선택하면 그 회차로 바로 이동합니다.
- A5 (6단계) 보기 설정: 독자가 배경·글자 크기·배경 움직임을 바꿉니다. 원고 내용과 공개 범위는 바뀌지 않습니다.
- A6 (1단계) 탐색: 독자가 검색어(제목·작가·태그), 장르, 해시태그로 작품을 찾거나 원작별 Fork 작품 모음을 엽니다. 결과에는 열람 가능한 작품만 표시합니다(E1).
- A7 (4·7단계) 관심 표시: 독자가 작품을 관심 소설에 담거나 회차 끝에서 감정 반응을 남깁니다. 저장·노출 방식은 미정입니다.

**예외 흐름**
- E1 (6단계) 비공개·삭제·접근 불가 회차: 원고를 표시하지 않습니다. 비공개 회차 내용을 목록·미리보기에 노출하지 않습니다.
- E2 (6단계) 권리 제한 콘텐츠: CE-06.
- E3 (6단계) 유료 회차: 열람 조건을 안내하며, 결제 방식이 정해지기 전에는 결제 처리를 수행하지 않습니다.

- **성공 보장:** 독자가 허용된 발행본을 읽습니다.
- **최소 보장:** 편집 중 초안·비공개 설정·기준 시점 이후 비공개 내용은 노출되지 않습니다.
- **업무 규칙:** 열람했다는 사실로 Fork·수정 권한을 얻지 않습니다(BR-03).
- **미정:** 유료 열람·결제, 작품 검색·정렬 기준, 장르·해시태그 운영 방식, 좋아요·관심 소설·감정 반응의 저장과 공개 여부, 이어 읽기 기록 보관. 인기순 추천·랭킹은 확정 범위 밖입니다([usecase.md 7.2절](../usecase.md#72-이번-문서에서-구현확정하지-않는-것)).
