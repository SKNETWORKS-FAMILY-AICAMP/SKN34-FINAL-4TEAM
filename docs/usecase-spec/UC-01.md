# UC-01 작품·회차 열람

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)

| 항목 | 내용 |
|---|---|
| 주 액터 | 독자 |
| 구분 | 지원 |
| 관련 기능 ID | F-PUB-01, F-PUB-03, F-PUB-04 |
| 근거 | 기획서 12·20쪽 |
| 관계 | UC-08·UC-14가 이 유스케이스를 extend |

- **목표:** 허용된 작품·회차를 읽고 공개 설정·Fork 가능 여부를 확인합니다.
- **사전조건:** 대상 작품·회차가 공개 상태이고 독자에게 열람 조건이 충족됩니다. 공개 회차 열람과 작품 탐색은 비회원도 할 수 있습니다(UC-22).
- **트리거:** 작품 목록이나 검색 결과에서 작품을 선택합니다.

**기본 흐름**
1. 독자가 작품 목록을 엽니다.
2. 시스템이 열람 가능한 작품을 원작과 Fork 작품으로 구분해 표시합니다.
3. 독자가 작품을 선택합니다.
4. 시스템이 작품 정보, 공개 회차 목록과 순서, 회차별 Fork 허용 여부를 표시합니다.
5. 독자가 회차를 선택합니다.
6. 시스템이 열람 권한을 확인하고 발행본 원고를 표시합니다.
7. 독자가 이전·다음 회차로 이동하며 읽습니다.

**대안 흐름**
- A1 (6단계) Fork: Fork가 허용된 회차이면 Fork 선택지를 표시하고, 독자가 선택하면 UC-08로 진행합니다.
- A2 (6단계) 피드백: 독자가 댓글·제보를 선택하면 UC-14로 진행합니다.
- A3 (2단계) Fork 작품 열람: Fork 작품은 기준 원작·기준 회차 정보를 함께 표시합니다.
- A4 (1단계) 이어 읽기: 로그인한 독자에게 작품별로 마지막으로 읽은 회차와 위치를 표시하고, 독자가 선택하면 그 위치로 바로 이동합니다. 비회원은 기록하지 않습니다.
- A5 (6단계) 보기 설정: 독자가 배경·글자 크기·배경 움직임을 바꿉니다. 원고 내용과 공개 범위는 바뀌지 않습니다.
- A6 (1단계) 탐색: 독자가 검색어(작품 제목·작가 닉네임·해시태그·장르)로 작품을 찾거나, 장르·해시태그 모음, 원작별 Fork 작품 모음을 엽니다. 결과는 최신 발행순(기본)·좋아요순·조회순으로 정렬할 수 있으며, 열람 가능한 작품만 표시합니다(E1). 본문 전문은 검색하지 않습니다.
- A7 (4단계) 관심 표시: 로그인한 독자가 작품에 좋아요를 누르거나 관심 소설에 담습니다. 좋아요 수는 공개하고 누른 사람은 공개하지 않습니다. 관심 소설 목록은 본인만 보며, 담은 작품에 새 회차가 발행되면 사이트 안 알림을 받습니다. 회차별 감정 반응은 두지 않습니다.

**예외 흐름**
- E1 (6단계) 비공개·삭제·접근 불가 회차: 원고를 표시하지 않습니다. 비공개 회차 내용을 목록·미리보기에 노출하지 않습니다.
- E2 (6단계) 권리 제한 콘텐츠: CE-06.
- E3 (6단계) 유료 회차: 열람 조건을 안내하며, 결제 방식이 정해지기 전에는 결제 처리를 수행하지 않습니다.

- **성공 보장:** 독자가 허용된 발행본을 읽습니다.
- **최소 보장:** 편집 중 초안·비공개 설정·기준 시점 이후 비공개 내용은 노출되지 않습니다.
- **업무 규칙:** 열람했다는 사실로 Fork·수정 권한을 얻지 않습니다(BR-03). 장르는 플랫폼이 고정 목록(기본 세계관 장르와 같은 목록)을 관리하고 작품당 1~2개를 고릅니다. 해시태그는 작가가 작품당 최대 10개까지 자유롭게 붙이며 유해 콘텐츠 1차 필터를 통과해야 등록됩니다(UC-14). 조회수는 회원·비회원 모두 집계하되 같은 사용자의 같은 회차는 하루 1회로 세고, 작품 상세에 공개합니다. 이어 읽기 기록은 열람 이력이므로 본인만 보며 탈퇴하면 삭제합니다(UC-22). 검색은 Elasticsearch로 처리할 예정이며, 새 외부 구성요소이므로 구현 착수 전에 팀에 공유합니다. 검색 색인에는 공개된 작품 정보만 넣고 초안·비공개 회차·비공개 설정은 넣지 않습니다. 인기순 추천·랭킹은 확정 범위 밖입니다([usecase.md 7.2절](../usecase.md#72-이번-문서에서-구현확정하지-않는-것)).
- **미정:** 유료 열람·결제, 장르 목록 구성, 한국어 검색 분석 방식(형태소 분석기 등, 구현 시 결정). 인기순 추천·랭킹은 확정 범위 밖입니다([usecase.md 7.2절](../usecase.md#72-이번-문서에서-구현확정하지-않는-것)).
