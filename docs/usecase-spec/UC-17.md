# UC-17 AI 이용 비용·한도 확인

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
| 항목 | 내용 |
|---|---|
| 주 액터 | 회원 |
| 구분 | 지원 · 금액 정책 미정 |
| 관련 기능 ID | F-CRD-01~03 |
| 근거 | 기획서 20~21쪽 |
| 관계 | UC-04, UC-09, UC-11, UC-12, UC-15, UC-18에 include됨 |
- **목표:** AI 실행 전에 필요한 비용·한도를 확인하고 실행 여부를 고릅니다.
- **사전조건:** 로그인. AI 작업 요청이 있거나 이용 현황 조회를 선택했습니다.
- **트리거:** AI 작업 실행을 요청하거나, 자동 처리를 켜거나, 크레딧 현황을 엽니다.
**기본 흐름**
1. 시스템이 요청한 작업의 범위(작업 유형, 인물 수, 진행 횟수, 생성 분량)를 정리합니다.
2. 시스템이 필요한 크레딧, 부담할 사용자, 현재 잔여 크레딧·한도를 표시합니다.
3. 회원이 실행에 동의합니다.
4. 시스템이 동의 결과를 호출한 유스케이스로 돌려줍니다. AI 실행은 호출한 유스케이스가 수행합니다.
5. 호출한 유스케이스의 AI 작업이 끝나면 시스템(Core API)이 실제 사용량과 결과 상태를 사용 내역에 기록합니다.
**대안 흐름**
- A1 (3단계) 범위 조정: 인물 수·분량 등을 줄여 1단계로 돌아갑니다.
- A2 (1단계) 현황 조회: 사용 내역과 잔여 크레딧만 확인합니다.
- A3 (3단계) 취소: 호출한 유스케이스에 취소를 돌려주고 AI를 실행하지 않습니다.
- A4 (1단계) 자동 실행: UC-04 자동 모드와 UC-18은 설정할 때 회당 예상 비용에 한 번 동의하고, 실행할 때마다 작품 소유자 크레딧에서 차감합니다. 부족하면 실행을 건너뛰고 소유자에게 알립니다.
**예외 흐름**
- E1 (2단계) 크레딧·한도 부족: 실행하지 않고 안내합니다.
- E2 (5단계) 서비스 오류로 미완료: 성공과 구분하고 재처리 또는 크레딧 복구 기준에 따라 처리합니다.
- **성공 보장:** 동의한 범위 안에서만 AI가 실행되고 사용량이 기록됩니다.
- **최소 보장:** 동의 없는 차감이 없습니다.
- **업무 규칙:** 크레딧은 BR-08에 따라 청구합니다(피드백 분석은 제보자, 자율 연재·세계관 자동 업데이트는 작품 소유자, 그 밖은 요청자). Fork 생성·직접 집필은 무료입니다. 작품 구매는 AI 무제한 이용권이 아닙니다. 재생성·재시뮬레이션은 별도 사용입니다.
- **미정:** 가격, 무료 제공량, 차감 시점(선차감·후정산), 오류 복구, 충전·결제, 보상 크레딧 구분.
