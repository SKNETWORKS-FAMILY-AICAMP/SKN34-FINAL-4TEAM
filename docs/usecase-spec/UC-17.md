# UC-17 AI 이용 비용·한도 확인

> [명세 목차·공통 규칙(CE·BR)](./README.md) · [유스케이스 문서](../usecase.md)
| 항목 | 내용 |
|---|---|
| 주 액터 | 회원 |
| 구분 | 지원 · 금액 정책 미정 |
| 관련 기능 ID | F-CRD-01~03 |
| 근거 | 기획서 20~21쪽. 구독·추가 구매 구조는 팀 결정(Kiro 요금 구조 참고) |
| 관계 | UC-04, UC-09, UC-11, UC-12, UC-18, UC-25(후보)에 include됨 |
- **목표:** AI 실행 전에 예상 비용·한도를 확인하고 실행 여부를 고르며, 실행 후 실제 사용량만큼 크레딧이 차감됩니다.
- **사전조건:** 로그인. AI 작업 요청이 있거나 이용 현황 조회를 선택했습니다.
- **트리거:** AI 작업 실행을 요청하거나, 자동 처리를 켜거나, 크레딧 현황을 엽니다.

**크레딧 종류**

| 구분 | 종류 | 지급 | 소멸 |
|---|---|---|---|
| 무료 | 가입 체험 | 가입할 때 1회 | 가입 후 30일 |
| 무료 | 보상·이벤트 | 피드백 반영 보상(UC-14), 이벤트 | 지급한 달의 월간 초기화 시점 |
| 유료 | 구독 | 구독 플랜에 따라 매달 | 매달 초기화(이월 없음) |
| 유료 | 추가 구매 | 구독 회원이 구독 크레딧을 다 쓴 뒤 구매 | 구매 후 12개월. 다 쓸 때까지 매달 이월 |

**기본 흐름**
1. 시스템이 요청한 작업의 범위(작업 유형, 인물 수, 진행 횟수, 생성 분량)를 정리합니다.
2. 시스템이 예상 크레딧 범위(상한 포함), 부담할 사용자, 종류별 잔여 크레딧, 요청 속도 한도를 표시합니다.
3. 회원이 실행에 동의합니다. 이 동의는 표시한 상한까지의 차감에 대한 동의입니다.
4. 시스템이 동의 결과를 호출한 유스케이스로 돌려줍니다. AI 실행은 호출한 유스케이스가 수행합니다.
5. 호출한 유스케이스의 AI 작업이 끝나면 시스템(Core API)이 실제 사용한 토큰을 크레딧으로 환산해 차감하고, 사용량·차감 크레딧 종류·결과 상태를 사용 내역에 기록합니다. 차감액은 3단계에서 동의한 상한을 넘지 않습니다.

**대안 흐름**
- A1 (3단계) 범위 조정: 인물 수·분량 등을 줄여 1단계로 돌아갑니다.
- A2 (1단계) 현황 조회: 종류별 잔여 크레딧, 소멸 예정일, 사용 내역만 확인합니다.
- A3 (3단계) 취소: 호출한 유스케이스에 취소를 돌려주고 AI를 실행하지 않습니다. AI 작업은 `취소됨`이 되며 크레딧을 차감하지 않습니다.
- A4 (1단계) 자동 실행: UC-04 자동 모드와 UC-18은 설정할 때 회당 예상 상한에 한 번 동의하고, 실행할 때마다 실제 사용량을 작품 소유자 크레딧에서 차감합니다. 실행 전 잔액이 회당 상한보다 적으면 실행을 건너뛰고 소유자에게 알립니다.
- A5 (5단계) 실행 중 중단: 시뮬레이션처럼 오래 걸리는 작업만 실행 중 중단할 수 있습니다. 사용자가 중단하면 `취소됨`으로 기록하고, 중단 시점까지 사용한 토큰만 차감합니다. 부분 결과는 확정하지 않습니다(CE-04).
- A6 (A2) 추가 구매: 구독 회원이 구독 크레딧을 다 쓰면 추가 크레딧을 구매할 수 있습니다. 구독하지 않은 회원은 추가 구매할 수 없습니다.

**예외 흐름**
- E1 (2단계) 크레딧 부족: 잔여 크레딧이 예상 상한보다 적으면 실행하지 않고 안내합니다(CE-05).
- E2 (5단계) 서비스 오류·시간 초과로 미완료: 성공과 구분하고 크레딧을 차감하지 않습니다. 이미 쓴 토큰 비용은 플랫폼이 부담합니다.
- E3 (4단계) 요청 속도 한도 초과: AI를 호출하지 않고 다시 시도할 수 있는 시점을 안내합니다. 크레딧을 차감하지 않습니다(CE-05).

- **성공 보장:** 동의한 범위 안에서만 AI가 실행되고, 실제 사용량만큼만 차감·기록됩니다.
- **최소 보장:** 동의 없는 차감, 동의한 상한을 넘는 차감, 실패한 작업의 차감이 없습니다.
- **업무 규칙:**
  - 크레딧은 BR-08에 따라 청구합니다(피드백 등록은 무료, 독자가 고른 스토리 오류 검증 시뮬레이션은 독자, 자율 연재·세계관 자동 업데이트는 작품 소유자, 그 밖은 요청자). 단순 오류 수정안·질문 답변·1차 필터는 플랫폼이 부담합니다. 작품 Fork·세계관 Fork 생성과 직접 집필은 무료입니다. 작품 구매는 AI 무제한 이용권이 아닙니다. 재생성·재시뮬레이션은 별도 사용입니다.
  - 차감 순서는 소멸이 빠른 크레딧부터입니다: 보상·이벤트 → 가입 체험 → 구독 → 추가 구매(구매가 오래된 것부터).
  - 요청 속도 제한: Core API가 토큰 버킷 방식으로 사용자별 분당 요청 수와 분당 토큰 수를 제한하고, 한도는 플랜별로 다르게 둡니다. 플랫폼 전체 OpenAI 사용 한도를 보호하는 전체 한도도 둡니다. 플랫폼 부담 작업(단순 오류·질문 응대, 1차 필터)도 같은 방식으로 제한합니다.
  - 구독하지 않은 회원은 가입 체험·보상·이벤트 크레딧만 씁니다. 매달 주는 무료 크레딧은 없습니다.
  - 현재 단계에서는 실결제를 하지 않고, 운영자가 지급하는 테스트 크레딧으로 구독·추가 구매를 대신합니다.
- **미정:** 구독 플랜 구성과 가격, 플랜별 월 크레딧·속도 한도 값, 모델별 토큰→크레딧 환산 비율, 가입 체험·추가 구매 단위, 월간 초기화 기준일(가입일 또는 매월 1일), 플랜 변경·해지 시 처리, 탈퇴 시 남은 크레딧, 결제사 연동, 속도 제한 상태 저장 방식(구현 시 결정).
