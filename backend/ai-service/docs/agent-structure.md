# AI Agent 구현 경계

## 현재

현재 실행 코드는 Health와 이어쓰기 제안 생성입니다. `openai-agents` 기반 Agent·다중 에이전트 오케스트레이션은 없지만 **모델 호출까지 미구현인 것은 아닙니다.**

- `app/main.py → health/router.py → HealthResponse`: 내부 상태를 반환합니다. Health에서 OpenAI 키를 요구하거나 모델 클라이언트를 생성하지 않습니다.
- `app/main.py → generation/router.py → generate → OpenAI.responses.create`: `POST /internal/v1/proposals`에서 `X-Internal-Token`을 검증하고 전달받은 문맥·요청으로 이어쓰기 제안을 생성합니다. 키·모델은 생성 요청 시 읽고 클라이언트는 요청 후 닫습니다. 미설정·제공사 실패는 503이며 모델·응답 ID·사용량을 결과에 포함합니다.
- `app/intent/routing.py → route`: 작가 요청을 등록된 7개 기능의 실행 순서·확인 질문·차단 중 하나로 분류합니다(#55). UI가 고른 operation은 모델 없이 우선하며, 범위·권한은 Content가 확정한 값만 씁니다. 아직 HTTP 엔드포인트·호출자는 없습니다. [Router 계약](../../../docs/writing-ai-architecture/02-ai-architecture.md#intent-router와-입력-가드레일-55)
- 현재 호출자는 분리 전 `core-api`의 `content/client/GenerationClient.kt`입니다. 콘텐츠 코드가 문맥·권한·기준 버전과 제안 채택·저장을 관리하고 AI는 DB 정본을 직접 변경하지 않습니다. Health 성공은 실제 모델 접근 검증이 아닙니다.

[최신 설계](../../../docs/design/design.md)의 최종 모델·제공사·에이전트 프레임워크는 미정입니다. 현재 `openai` SDK 구현과 남아 있는 `openai-agents` 의존성을 전체 기술 선정 완료로 해석하지 않습니다.

## 목표 소유 경계 (DEC-41)

[4개 서비스 구조](../../../docs/design/service-boundaries.md)에 따라 Core는 회원·인증·크레딧·회원 알림, 콘텐츠는 창작·독서 정본·콘텐츠 인가·채택·발행, 운영은 문의·공지·신고 사건·운영 판단·감사·작업 감시, AI는 허용된 모델 실행을 소유합니다. 콘텐츠·운영은 별도 Kotlin/Spring Boot 앱으로 분리할 목표이며 현재 앱·실행 명령은 없습니다. Python AI 앱과 현재 `core-api` 호출은 유지하고 업무별 호출·인증·정산·알림 계약을 후속 설계합니다.

LLMOps는 운영 영역입니다. Langfuse는 MVP 이후 도입 시 별도 제품으로 배포하며 자체 UI와 운영 화면 API 통합 중 방식은 미정입니다. Spring에서 제품 전체를 재구현하지 않으며 AI 계측·버전 적용·평가 실행 위치는 연동 계약에서 정합니다. 현재 Langfuse 연동은 없습니다.

## AI 역할을 확장할 때

- 기존 생성 구현을 재사용하고 선정한 모델·프레임워크에 필요한 책임만 추가합니다. 과거 LangChain·LangGraph는 후보입니다.
- 기능별 구조화 입출력·timeout·안전한 오류 처리를 두고 요청에 허용된 최소 문맥만 사용합니다.
- 설정 추출·인물 판단·집필·피드백 역할은 실제 입력·출력·책임이 다를 때만 나눕니다.
- 인물별 문맥을 같은 구현에 주입하며 인물마다 클래스나 서버를 만들지 않습니다.
- 인물의 허용 지식과 다른 인물만 아는 사실·미발행 원고를 혼합하지 않습니다. 세계관 설정의 항목별 공개·비공개와 회차별 공개 범위를 적용합니다(DEC-36).
- 제안 생성과 사용자 승인·정본 반영은 별개입니다. 콘텐츠 서비스가 콘텐츠 권한과 기준 버전을 검증하며 현재는 `core-api`의 콘텐츠 코드가 수행합니다. 크레딧 정산은 Core, 운영 목적 검사·평가 작업은 운영 책임으로 구분합니다.
- tool·handoff·오케스트레이터·큐·worker는 현재 없고 미리 만들지 않습니다.
- 외부 실패를 임의 결과로 숨기지 않습니다. 실제 OpenAI를 호출하지 않은 검증은 구분해 보고합니다.

세부 정책과 금액·실행 한도·자동 발행 조건은 [루트 기획 목표](../../../README.md)에 남아 있습니다.
